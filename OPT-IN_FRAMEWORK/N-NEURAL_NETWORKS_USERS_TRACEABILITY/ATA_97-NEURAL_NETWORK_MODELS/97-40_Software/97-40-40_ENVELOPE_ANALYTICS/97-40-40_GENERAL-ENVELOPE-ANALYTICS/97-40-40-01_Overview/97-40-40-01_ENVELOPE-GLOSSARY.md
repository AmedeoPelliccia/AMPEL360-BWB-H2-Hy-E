## Terms and Definitions

### A

**Advisory Level**
: A classification of the current envelope state (NORMAL, CAUTION, WARNING, CRITICAL) used to prioritize crew notifications.

**Alpha (α)**
: Angle of attack - the angle between the chord line of the wing and the relative wind direction.

**Alpha Margin**
: The difference between the current angle of attack and the maximum permissible angle of attack (stall angle).

### B

**Bank Angle Limit**
: Maximum permissible roll angle based on current flight conditions and aircraft configuration.

**Boil-off Rate**
: The rate at which liquid hydrogen evaporates due to heat ingress into the cryogenic tank.

### C

**CBOR (Concise Binary Object Representation)**
: A binary data serialization format used for OFEC message encoding.

**Ceiling**
: Maximum operational altitude based on aircraft performance and atmospheric conditions.

### D

**DAL (Design Assurance Level)**
: A measure of the rigor required in software development based on failure severity (A=highest, E=lowest).

### E

**Envelope**
: The range of operational parameters within which the aircraft can safely operate.

**Exceedance**
: An event where a flight parameter exceeds its defined limit.

### F

**Flight Phase**
: A discrete segment of flight operations (GROUND, TAXI, TAKEOFF, CLIMB, CRUISE, DESCENT, APPROACH, LANDING).

### G

**G-load (Load Factor)**
: The ratio of lift to weight, expressed in multiples of gravitational acceleration.

### H

**H₂-Specific Constraints**
: Envelope limitations unique to hydrogen fuel systems, including tank pressure and fuel temperature limits.

### L

**Load Factor Margin**
: The difference between current G-load and the structural limit of the aircraft.

### M

**Margin**
: The difference between a current parameter value and its corresponding limit.

**mTLS (Mutual TLS)**
: A security protocol requiring both client and server authentication for OFEC communications.

### O

**OFEC (Operational Flight Envelope Channel)**
: The telemetry channel for transmitting envelope data from aircraft to ground/regional systems.

### P

**Phase-Aware Publishing**
: Adjusting telemetry transmission rate based on current flight phase.

**Predictive Dynamics**
: Analysis techniques for forecasting future envelope states based on current trends.

### S

**Speed Margin**
: The difference between current speed and the minimum/maximum permissible speed.

**Stall Warning**
: An alert indicating the aircraft is approaching the stall angle of attack.

### T

**Trend Analysis**
: Evaluation of parameter changes over time to predict future values.

### V

**V-speeds**
: Reference speeds for aircraft operations:
- **Vmin**: Minimum safe operating speed
- **Vmax**: Maximum operating speed (Vmo/Mmo)
- **Vs**: Stall speed
- **Vne**: Never exceed speed
