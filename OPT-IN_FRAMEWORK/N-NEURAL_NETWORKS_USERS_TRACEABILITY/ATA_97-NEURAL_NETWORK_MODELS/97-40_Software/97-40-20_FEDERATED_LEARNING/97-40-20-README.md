## Purpose

This subsystem contains all **model-side logic** for the CFLF-GRAD (Collaborative Federated Learning Fabric – Gradient) system. It covers:

- **Differential Privacy** (DP-SGD) implementation
- **Privacy budget** (ε, δ) tracking and enforcement
- **Model compression** (sparsification, quantization)
- **Local training** protocols on aircraft
- **Aggregation algorithms** (FedAvg, FedAdam)
- **Model governance** (policies, kill switches)
- **Evaluation** (drift detection, fairness, benchmarks)
- **Model definitions** (H₂, PredMaint, ANCHORS)

> **Transport & protocols** are handled in **L2-LINKS (ATA 23-95)**.  
> See [`23-95_COMM_NN`](../../../../T-TECHNOLOGY_AMEDEOPELLICCIA-ON_BOARD_SYSTEMS/L2-LINKS/ATA_23-COMMUNICATIONS/23-95_COMM_NN/23-95-README.md).
