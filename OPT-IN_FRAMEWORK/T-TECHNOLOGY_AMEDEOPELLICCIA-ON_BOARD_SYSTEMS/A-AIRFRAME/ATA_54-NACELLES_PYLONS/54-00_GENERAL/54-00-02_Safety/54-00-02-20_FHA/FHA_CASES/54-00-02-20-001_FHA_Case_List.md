## 4. Severity Classification Key

Severity classifications SHALL be assigned per:
- [`../../54-00-02-10_HAZARD_ANALYSIS/54-00-02-10-004_Hazard_Classification.md`](../../54-00-02-10_HAZARD_ANALYSIS/54-00-02-10-004_Hazard_Classification.md)

| Severity | Definition (per ARP4761 / program policy) |
|----------|-------------------------------------------|
| Catastrophic | Failure conditions which would prevent continued safe flight and landing |
| Hazardous | Failure conditions which would reduce aircraft capability or crew ability to cope with adverse conditions |
| Major | Failure conditions which would significantly reduce aircraft capability or crew ability to cope |
| Minor | Failure conditions which would not significantly reduce aircraft capability |
| No Safety Effect | Failure conditions with no effect on safety |
