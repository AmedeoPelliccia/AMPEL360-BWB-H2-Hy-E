# 54-00-02-70-007 — ATA 71/72 Impact (Powerplant / Propulsors)

## 1. Purpose

Document the **safety interface impact** between **ATA 54 (Nacelles / Pylons)** and **ATA 71/72 (Powerplant / Propulsors)** for AMPEL360 AIR-T.

## 2. Interface Description

ATA 71/72 powerplant/propulsor systems interface with ATA 54 through:
- engine/propulsor mounting to nacelle structure,
- thrust load transfer through pylon,
- vibration transmission,
- engine control signal routing,
- auxiliary systems interfaces (bleed, power take-off).

## 3. Safety Concerns

| Concern ID | Description | Potential Consequences |
|------------|-------------|------------------------|
| SC-71-001 | Engine/propulsor separation | Catastrophic, loss of aircraft |
| SC-71-002 | Mounting failure/degradation | Vibration, misalignment, separation |
| SC-71-003 | Excessive vibration transmission | Fatigue, routed item damage |
| SC-71-004 | Engine fire affecting nacelle | Fire propagation, structural damage |
| SC-71-005 | Uncontained engine failure | Projectile damage, fire |
| SC-71-006 | Control signal loss | Loss of engine control |
