# 54-00-02-70-004 — ATA 28 Impact (Fuel / H₂)

## 1. Purpose

Document the **safety interface impact** between **ATA 54 (Nacelles / Pylons)** and **ATA 28 (Fuel / H₂)** for AMPEL360 AIR-T.

## 2. Interface Description

ATA 28 fuel/hydrogen systems interface with ATA 54 through:
- fuel line routing through pylon structure,
- hydrogen distribution (if applicable for H₂-powered variant),
- fuel shutoff valves at pylon interface,
- leak detection/drainage provisions.

## 3. Safety Concerns

| Concern ID | Description | Potential Consequences |
|------------|-------------|------------------------|
| SC-28-001 | Fuel/H₂ leak in pylon volume | Fire, explosion, structural damage |
| SC-28-002 | Fuel line chafing/fatigue failure | Leak, fire |
| SC-28-003 | Inadequate leak detection | Undetected leak, delayed response |
| SC-28-004 | Fuel shutoff valve failure | Unable to isolate fuel flow |
| SC-28-005 | Hydrogen accumulation (if applicable) | Explosion risk |
| SC-28-006 | Fuel contamination of structural materials | Material degradation, corrosion |
