# 54-00-02-70-003 — ATA 26 Impact (Fire Protection)

## 1. Purpose

Document the **safety interface impact** between **ATA 54 (Nacelles / Pylons)** and **ATA 26 (Fire Protection)** for AMPEL360 AIR-T.

## 2. Interface Description

ATA 26 fire protection systems interface with ATA 54 through:
- fire detection loops routed through nacelle volumes,
- fire suppression agent distribution,
- fire zone boundaries defined within nacelle,
- thermal insulation/barriers.

## 3. Safety Concerns

| Concern ID | Description | Potential Consequences |
|------------|-------------|------------------------|
| SC-26-001 | Fire detection loop failure | Undetected fire, delayed response |
| SC-26-002 | Inadequate fire zone segregation | Fire propagation to adjacent zones |
| SC-26-003 | Suppression agent distribution failure | Ineffective fire suppression |
| SC-26-004 | Thermal barrier degradation | Increased fire spread rate |
| SC-26-005 | False fire detection | Unnecessary shutdown, operational impact |
