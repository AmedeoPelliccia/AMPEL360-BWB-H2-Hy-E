## Purpose

This document establishes the repair philosophy and design criteria for the AMPEL360 BWB fuselage structure, ensuring repairs restore structural capability while maintaining airworthiness.

## Scope

This document covers:
- Repair design philosophy
- Damage classification
- Repair classification system
- Design criteria for repairs
- Approval requirements

## Repair Philosophy

### Guiding Principles

1. **Restore Original Capability**: Repairs must restore static strength, fatigue life, and damage tolerance
2. **Minimize Weight Penalty**: Use efficient repair designs
3. **Maintainability**: Repairs should not impede access or inspection
4. **Standardization**: Use standard repairs where possible

### Repair Hierarchy

| Priority | Approach |
|----------|----------|
| 1st | Use SRM standard repair |
| 2nd | Use OEM-developed repair |
| 3rd | Develop engineering repair |
| 4th | Component replacement |

## Damage Classification

### Damage Categories

| Category | Description | Action |
|----------|-------------|--------|
| Negligible | Within allowable damage limits | No repair required |
| Minor | Exceeds limits, standard repair exists | Apply SRM repair |
| Major | Exceeds SRM limits | Engineering disposition |
| Severe | Extensive damage | Component replacement |

### Allowable Damage Limits (CFRP)

| Damage Type | Allowable Size | Notes |
|-------------|----------------|-------|
| Dent (no BVID) | ≤ 2 mm depth | Visual inspection |
| Scratch | ≤ 0.25 mm depth | Surface only |
| Delamination | ≤ 25 mm diameter | Non-pressurized areas |
| Impact (BVID) | ≤ 6 mm diameter | Pressurized areas |

### Allowable Damage Limits (Metallic)

| Damage Type | Allowable Size | Notes |
|-------------|----------------|-------|
| Scratch | ≤ 0.2 mm depth | Polish out |
| Dent | ≤ 3 mm depth, ≤ 25 mm dia | Smooth contour |
| Corrosion | ≤ 10% thickness | Blend out |
| Crack | None | Must repair |

## Repair Classification

| Class | Strength Restoration | Approval |
|-------|---------------------|----------|
| Class 1 | 100% original | Minor repair - SRM |
| Class 2 | 90-100% original | Engineering approval |
| Class 3 | < 90% original | DAH approval + limitations |

## Design Criteria

### Static Strength

| Criterion | Requirement |
|-----------|-------------|
| Ultimate strength | ≥ 100% of parent structure |
| Repair weight | Minimize, document penalty |
| Fastener bearing | MS ≥ 0.15 |
| Net section | MS ≥ 0.10 |

### Fatigue and Damage Tolerance

| Criterion | Requirement |
|-----------|-------------|
| Fatigue life | ≥ Remaining life of parent structure |
| Damage tolerance | Meet original DT requirements |
| Inspection | Define post-repair inspection requirements |

### Composite-Specific

| Criterion | Requirement |
|-----------|-------------|
| Patch material | Same or equivalent to parent |
| Layup sequence | Match parent or equivalent |
| Cure temperature | ≤ 200°F for in-situ repairs |
| Bond strength | ≥ 40 MPa shear |

## Approval Requirements

| Repair Class | Authority | Documentation |
|--------------|-----------|---------------|
| Class 1 | Certified mechanic | Work order, NDI report |
| Class 2 | Stress engineer | Engineering order, stress report |
| Class 3 | DAH/DER | Major repair data, STC if required |
