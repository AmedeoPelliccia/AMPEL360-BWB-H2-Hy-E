## Purpose

This document defines the pressure relief valve specifications for storage system overpressure protection.

## Scope

This specification covers:
- Relief valve types and applications
- Performance requirements
- Qualification requirements
- Installation standards

### Performance

| Parameter | Requirement | Reference |

| Leak rate (closed) | Zero bubble tight | REQ-PRV-012 |
| Response time | ≤ 100 ms | REQ-PRV-013 |
