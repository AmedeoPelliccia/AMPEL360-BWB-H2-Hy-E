## Aerogel Overview

### Material Description

Aerogel is a highly porous, low-density material with exceptional thermal insulation properties. For storage system applications, silica-based aerogel blankets are used.

### Key Properties

| Property | Value | Benefit |
|----------|-------|---------|
| Thermal conductivity | 0.015 W/m·K | Superior insulation |
| Density | 150 kg/m³ | Lightweight |
| Porosity | 95-99% | Air entrapment |
| Hydrophobic | Yes | Moisture resistance |
| Temperature range | -200 to +650°C | Wide application |

## Application Procedures

### Material Preparation

| Step | Action | Notes |
|------|--------|-------|
| 1 | Inspect material | Check for damage |
| 2 | Cut to size | Use sharp blade |
| 3 | Minimize compression | Reduces effectiveness |
| 4 | Plan seams | Minimize gaps |

### Installation

| Step | Action | Notes |
|------|--------|-------|
| 1 | Clean surface | Remove oil, debris |
| 2 | Apply adhesive (if used) | Compatible type |
| 3 | Position blanket | Smooth, no wrinkles |
