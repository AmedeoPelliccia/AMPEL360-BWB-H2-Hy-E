# ATA 53 Drawing Standards

## 1. Purpose

This document defines the drawing standards applicable to the AMPEL360 BWB fuselage structure.

---

## 2. Drawing Numbering

### 2.1 Format

```text
53-ZZ-NNNN
```

Where:
- `53` = ATA chapter (Fuselage)
- `ZZ` = Zone (10, 20, 30, 40, 50, 60)
- `NNNN` = Sequential number

### 2.2 Examples

| Drawing Number | Description |
|----------------|-------------|
| 53-10-0000 | Zone 100 Assembly |
| 53-10-1000 | Forward Pressure Bulkhead |
| 53-40-1000 | Forward Wing Spar |

## 4. Title Block Requirements

| Field | Description |
|-------|-------------|
| Drawing Number | Per section 2.1 |
| Title | Descriptive title |
| Revision | Letter (A, B, C, etc.) |
| Date | YYYY-MM-DD |
| Drawn By | Author initials |
| Checked By | Checker initials |
| Approved By | Approver initials |
| Scale | As stated |

---

## 5. Revision Control

### 5.1 Revision Letters

- Initial release: No letter (or "–")
- First revision: A
- Subsequent: B, C, D, etc. (skip I, O, Q, S, X, Z)

### 5.2 Change Documentation

All changes must be recorded in the revision block with:
- Revision letter
- Date
- Description of change
- Approval
