# Material Call-Out Standards

## Material Specification Format

All material callouts must follow this format:

```
MATERIAL: [Specification] - [Alloy/Grade] - [Temper/Condition]
```

## Common Materials

### Aluminum Alloys
- **2024-T3**: High strength, good fatigue resistance
  - Callout: `AL 2024-T3 per AMS 4037`
- **7075-T6**: Very high strength
  - Callout: `AL 7075-T6 per AMS 4045`
- **2014-T6**: Forging alloy
  - Callout: `AL 2014-T6 per AMS 4152`

### Titanium Alloys
- **Ti-6Al-4V**: General purpose titanium
  - Callout: `TI 6Al-4V per AMS 4911`

### Steel
- **300M**: Ultra-high strength landing gear steel
  - Callout: `STEEL 300M per AMS 6417`
- **15-5 PH**: Precipitation hardening stainless
  - Callout: `CRES 15-5PH H1025 per AMS 5659`

### Composites
- **Carbon Fiber/Epoxy**: Advanced composite
  - Callout: `CFRP T800/Epoxy per AMPEL360-CSPEC-001`

## Surface Treatment

- Anodize: `ANODIZE per MIL-A-8625 Type II Class 2`
- Alodine: `CHEM FILM per MIL-DTL-5541 Class 1A`
- Primer: `PRIMER per MIL-PRF-23377 Type I Class C2`
