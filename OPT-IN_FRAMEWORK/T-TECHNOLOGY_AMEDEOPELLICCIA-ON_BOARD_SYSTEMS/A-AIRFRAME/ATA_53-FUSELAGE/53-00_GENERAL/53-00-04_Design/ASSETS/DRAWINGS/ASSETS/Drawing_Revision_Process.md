# Drawing Revision Process

## Revision Levels

- **-**: Preliminary/concept (not released)
- **A**: First official release
- **B, C, D...**: Subsequent revisions

## Revision Procedure

### 1. Request for Change
- Initiate Engineering Change Request (ECR)
- Obtain approval from Engineering Authority

### 2. Drawing Update
- Make required changes to drawing
- Add revision cloud around changed areas
- Update revision block in title block

### 3. Review and Approval
- Technical review by Engineering
- Quality review by QA
- Final approval by Authority

### 4. Register Update
- Update zone register CSV
- Update master register CSV
- Document reason for change

### 5. Distribution
- Release updated drawing to stakeholders
- Archive previous revision
- Update related documentation

## Revision Documentation

Each revision must include:
- Revision level (letter)
- Date of revision
- Description of change
- Approval signatures
- Affected zones (in revision block)

## Change Types

### Minor Changes (same revision letter)
- Spelling corrections
- Note additions that don't affect design
- Cosmetic improvements

### Major Changes (new revision letter)
- Dimensional changes
- Material changes
- Configuration changes
- Anything affecting fit, form, or function
