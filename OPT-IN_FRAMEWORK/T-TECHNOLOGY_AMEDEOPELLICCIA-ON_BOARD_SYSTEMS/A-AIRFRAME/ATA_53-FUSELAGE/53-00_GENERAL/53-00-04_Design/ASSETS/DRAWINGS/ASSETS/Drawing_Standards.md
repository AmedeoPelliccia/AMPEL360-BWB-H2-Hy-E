# Drawing Standards

## Purpose

This document defines the drawing standards for all AMPEL360 BWB ATA 53 fuselage drawings.

## General Requirements

1. **Format**: All drawings must be in SVG format for version control
2. **Units**: Millimeters (mm) unless otherwise noted
3. **Projection**: Third-angle projection per ISO 5456
4. **Scale**: Clearly indicated on each drawing (NTS for Not To Scale)

## Line Standards

- **Visible lines**: Solid black, 0.5-0.7mm width
- **Hidden lines**: Dashed gray, 0.35mm width
- **Center lines**: Dash-dot red, 0.25mm width
- **Dimension lines**: Solid blue, 0.25mm width
- **Section lines**: Solid black, 0.35mm width at 45°

## Text Standards

- **Title text**: Arial Bold, 24pt
- **Subtitle text**: Arial, 14pt
- **Label text**: Arial, 12pt
- **Dimension text**: Arial, 10pt

## Title Block

All drawings must include a standard title block containing:
- Company logo/name (AMPEL360)
- Drawing title
- Drawing number (53-XX-XXXX format)
- Zone designation
- Drawing type
- Scale
- Revision level
- Date
- Status
- Sheet number
- Units

## Revision Control

- Revisions marked alphabetically (A, B, C...)
- Revision history maintained in drawing register
- Changes highlighted with revision cloud
