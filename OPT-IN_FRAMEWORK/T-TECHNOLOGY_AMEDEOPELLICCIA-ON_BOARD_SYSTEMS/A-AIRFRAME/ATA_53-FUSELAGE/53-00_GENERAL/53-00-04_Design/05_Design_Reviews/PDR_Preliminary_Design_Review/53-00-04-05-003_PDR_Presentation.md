## 2. Design Overview

### 2.1 BWB Fuselage Concept

The AMPEL360 BWB fuselage features:

- Blended wing-body configuration
- Pressurized multi-bubble centerbody
- Integrated center wing box
- CFRP primary structure

### 2.2 Zone Architecture

| Zone | Description | Weight Budget |
|------|-------------|---------------|
| 100 | Nose Section | 3,500 kg |
| 200 | Forward Cabin | 8,500 kg |
| 300 | Mid Cabin | 10,500 kg |
| 400 | Center Wing Box | 12,000 kg |
| 500 | Aft Cabin | 7,000 kg |
| 600 | Tail Section | 3,500 kg |
| **Total** | | **45,000 kg** |

---

## 3. Key Design Features

### 3.1 Structural Configuration

- Primary material: IM7/8552 CFRP
- Frame pitch: 508 mm
- Stringers: Omega profile, AFP laid
- Joints: Ti fasteners with CFRP-friendly design

### 3.2 Critical Areas

- Center wing box integration
- Main landing gear bay
- Pressure bulkheads
- Wing-body blend transition
