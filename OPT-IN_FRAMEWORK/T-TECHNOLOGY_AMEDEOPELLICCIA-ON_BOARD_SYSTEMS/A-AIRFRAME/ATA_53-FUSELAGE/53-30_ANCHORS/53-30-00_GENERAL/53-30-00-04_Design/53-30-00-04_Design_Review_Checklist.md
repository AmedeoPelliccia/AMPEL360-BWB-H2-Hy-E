## 1. Purpose

This checklist supports design reviews for ANCHORS systems at various development milestones.

---

## 2. Preliminary Design Review (PDR)

### System Requirements
- [ ] All requirements documented and traced to aircraft level
- [ ] Derived requirements identified and logged
- [ ] Safety requirements defined per FHA/PSSA

### Architecture
- [ ] System architecture defined and documented
- [ ] Interface definitions established
- [ ] Redundancy architecture defined for safety-critical functions

### Trade Studies
- [ ] Major technology trade studies complete
- [ ] Decisions documented with rationale
- [ ] Risk assessment for selected technologies

### Performance
- [ ] Preliminary mass budget established
- [ ] Preliminary power budget established
- [ ] Performance estimates documented

---

## 3. Critical Design Review (CDR)

### Detailed Design
- [ ] All component specifications complete
- [ ] Detailed drawings available
- [ ] Interface control documents finalized

### Safety
- [ ] PSSA complete with failure budgets
- [ ] CCA and ZSA complete
- [ ] Safety-critical software DAL assigned

### Verification
- [ ] Verification matrix complete
- [ ] Test procedures drafted
- [ ] Test facilities identified

### Manufacturing
- [ ] Manufacturing plan drafted
- [ ] Special processes identified
- [ ] Supplier qualification started

---

## 4. Final Design Review (FDR)

### Design Maturity
- [ ] All verification complete or planned
- [ ] SSA complete with compliance evidence
- [ ] No open critical findings

### Certification
- [ ] Compliance checklist complete
- [ ] MoC documents drafted
- [ ] Certification evidence package assembled
