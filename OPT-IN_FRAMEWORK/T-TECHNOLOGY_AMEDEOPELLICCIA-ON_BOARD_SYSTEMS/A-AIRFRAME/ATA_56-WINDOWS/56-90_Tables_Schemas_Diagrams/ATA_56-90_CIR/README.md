# ATA 56-90 CIR — Configuration Item References

## Overview

This folder contains **Configuration Item Reference (CIR)** assets for ATA Chapter 56 (Windows) subsystems. CIR assets include figures (SVG), tables (CSV), and schemas referenced by LRU and LRI documentation.

## Naming Convention

### Figures (FIG)

```text
56-90-XX_56-YY-FIG_NNN-[Description].svg
```

Where:
- `XX` = Subsystem code (21=Windshields, 22=SideWindows, etc.)
- `YY` = LRI sequence
- `NNN` = Figure sequence number

### Tables (TABLE)

```text
56-90-XX_56-YY-TABLE_NNN-[Description].csv
```
