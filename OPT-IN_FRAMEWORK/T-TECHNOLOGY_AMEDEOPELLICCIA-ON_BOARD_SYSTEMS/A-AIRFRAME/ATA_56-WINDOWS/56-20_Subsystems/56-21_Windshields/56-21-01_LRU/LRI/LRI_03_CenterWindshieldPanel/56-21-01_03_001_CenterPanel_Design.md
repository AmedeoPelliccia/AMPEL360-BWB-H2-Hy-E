## 1. Purpose

This document defines the design specifications for the Center Windshield Panel, which is **unique to the AMPEL360 BWB (Blended Wing Body) configuration**. This panel provides forward visibility in the center of the wider BWB cockpit.

## 2. Scope

The Center Windshield Panel provides:

- Central forward visibility for both flight crew
- Extended field of view for BWB cockpit geometry
- Structural pressure containment
- Bird strike resistance
- Anti-ice/anti-fog capability

---

## 3. Design Specifications

### 3.1 BWB-Specific Design Features

| Feature | Description |
|---------|-------------|
| **Geometry** | Compound curved panel conforming to BWB nose contour |
| **Field of View** | Extended horizontal FOV to compensate for wider cockpit |
| **Integration** | Seamless interface with left and right panels |
| **Structural** | Enhanced reinforcement for BWB aerodynamic loads |

### 3.2 Physical Properties

| Parameter | Value |
|-----------|-------|
| **Material** | Stretched acrylic with interlayer heating film |
| **Outer Ply** | Chemically strengthened glass, 8mm (enhanced for center position) |
| **Inner Ply** | Stretched acrylic, 10mm |
| **Interlayer** | PVB with embedded heating elements |
| **Overall Thickness** | 30mm nominal |
| **Optical Distortion** | ≤ 0.5 milliradians |
| **Light Transmission** | ≥ 70% (visible spectrum) |

### 3.3 Environmental Requirements

| Parameter | Requirement |
|-----------|-------------|
| **Operating Temperature** | -55°C to +70°C |
| **Pressure Differential** | 9.0 psi max |
| **UV Resistance** | Per MIL-STD-810G |

### 3.4 Structural Requirements

| Parameter | Requirement |
|-----------|-------------|
| **Bird Strike** | 1.8 kg at Vc per [FAR 25.775](https://www.ecfr.gov/current/title-14/chapter-I/subchapter-C/part-25) |
| **Hail Impact** | Per [CS-25.775](https://www.easa.europa.eu/en/document-library/certification-specifications/cs-25-amendment-28) |
| **Fatigue Life** | 60,000 flight cycles minimum |
