## 1. Purpose

This procedure defines the external and internal visual inspection sequence for all window and windshield components during pre-flight operations.

## 2. Scope

Applicable to all AMPEL360 Q100 aircraft equipped with:

- Cockpit windshields (ATA 56-21)
- Cockpit side windows (ATA 56-22)
- Passenger cabin windows (ATA 56-23)

## 3. Prerequisites

- Aircraft parked in well-lit area or portable lighting available
- Exterior access equipment available (if required for upper windows)
- Previous flight defect reports reviewed
- Cleaning equipment available for minor cleaning

## 4. Procedure

### 4.1 External Inspection

| Step | Action | Expected Result | Notes |
|------|--------|-----------------|-------|
| 1 | Inspect all windshield panels for cracks, chips, or delamination | No visible damage | All panels |
| 2 | Check windshield frame seals for condition | Seals intact, no gaps | Weatherstripping |
| 3 | Verify rain repellent coating appearance | Uniform, no bare spots | Visual check |
| 4 | Inspect side windows for scratches or crazing | No significant damage | Flight deck |
| 5 | Check cabin windows for cracks or seal damage | All windows serviceable | Walk-around |
| 6 | Verify no foreign object debris on window surfaces | Clean surfaces | Remove if found |

### 4.2 Internal Inspection

| Step | Action | Expected Result | Notes |
|------|--------|-----------------|-------|
| 7 | Check windshield interior for moisture or fogging | Clear, no condensation | May indicate seal failure |
| 8 | Verify heating element visibility | No arcing marks | If visible elements |
| 9 | Check sun visors operation | Smooth movement | Both positions |
| 10 | Inspect window shades / electrochromic controls | Functional | Cabin windows |

## 5. Acceptance Criteria

| Criterion | Limit | Action if Exceeded |
|-----------|-------|-------------------|
| Cracks in windshield | None allowed | MEL/CDL reference |
| Surface scratches | ≤ 3 mm depth, outside critical zone | Defer per AMM |
| Delamination | None in primary vision area | No dispatch |
| Seal condition | No visible gaps or deterioration | Maintenance action |

## 6. Completion Criteria

- All window panels inspected
- No unacceptable damage found
- Observations recorded in aircraft log if required
- Preflight inspection checklist signed
