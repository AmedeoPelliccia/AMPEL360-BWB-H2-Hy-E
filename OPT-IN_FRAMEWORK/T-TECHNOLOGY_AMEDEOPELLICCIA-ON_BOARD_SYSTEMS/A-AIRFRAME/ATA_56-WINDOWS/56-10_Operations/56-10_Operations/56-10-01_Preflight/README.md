# 56-10-01 Preflight — ATA 56 Windows/Windshields

## Purpose

This folder contains all pre-flight procedures related to ATA 56 (Windows/Windshields) for the AMPEL360 Q100 aircraft. These procedures ensure that all cockpit and cabin window systems are properly inspected, tested, and serviceable before each flight.

## Scope

The pre-flight procedures in this folder cover:

- **Window and windshield visual inspection**
- **Heating system functional checks**
- **Rain repellent system servicing and verification**
