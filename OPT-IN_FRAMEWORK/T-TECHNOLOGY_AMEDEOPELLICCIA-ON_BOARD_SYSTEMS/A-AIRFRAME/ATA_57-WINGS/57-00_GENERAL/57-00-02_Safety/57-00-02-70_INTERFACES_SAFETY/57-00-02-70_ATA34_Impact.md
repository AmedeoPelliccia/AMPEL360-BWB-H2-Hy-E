## 1. Purpose

This document defines the **safety interface** between ATA 57 (Wings) and ATA 34 (Navigation).

---

## 2. Interface Description

Navigation systems (ATA 34) interface with the wing structure through:

- Sensor mounting (pitot tubes, static ports, AOA sensors)  
- Antenna installations  
- Structural provisions for equipment
