## 4. FTA Wing Loss Notes

### 4.1 Top Event

**Loss of Wing Structural Integrity (H-57-STR-01)**

This is a catastrophic failure condition requiring probability < 10⁻⁹ per flight hour.

### 4.2 Primary Failure Paths

1. **Primary Structure Failure**
   - Spar failure (most critical)  
   - Skin panel failure  
   - Rib failure  

2. **Secondary Structure Failure**
   - Leading/trailing edge failure propagating to primary structure  
   - Fairing departure causing aerodynamic damage  

3. **Attachment Failure**
   - Wing-fuselage attachment  
   - Pylon attachment  

### 4.3 Key AND Gates

The design philosophy ensures that multiple independent failures are required:

- Fatigue failure requires: crack initiation AND undetected growth AND reaching critical size  
- Undetected crack requires: inspection missed AND SHM not triggered  
- Attachment failure requires: overload AND redundant path failure  

### 4.4 Mitigations Reflected

| Mitigation | Where Applied |
| :-- | :-- |
| Damage tolerance design | Spar, skin, rib structure |
| Multiple load paths | Attachments |
| Inspection program | Crack detection |
| SHM | Continuous monitoring |
