# 57-10-00-04 — Terminology

## Purpose

This glossary defines terms used throughout ATA 57-10 Wing Operations documentation.

## Glossary

| Term | Definition |
|------|------------|
| **AoA** | Angle of Attack – the angle between the wing chord line and the relative wind |
| **CAOS** | Cognitive Aerospace Operations System – AI-driven operations framework |
| **Exceedance** | Event where an operational parameter exceeds its defined limit |
| **FDR** | Flight Data Recorder – records flight parameters for post-flight analysis |
| **G-Load** | Gravitational load factor experienced by the aircraft structure |
| **Limit Load** | Maximum load expected during normal operations |
| **Margin** | Safety buffer between operational limits and structural capability |
| **Mission Segment** | Discrete phase of flight (e.g., takeoff, cruise, approach) |
| **MMIP** | Multi-Modal Integration Platform – context and memory management |
| **NDT** | Non-Destructive Testing – inspection methods that do not damage the structure |
| **OFEC** | Operational Flight Envelope Computing – envelope monitoring system |
| **SHM** | Structural Health Monitoring – continuous monitoring of structural integrity |
| **SHM Alert** | Notification triggered by SHM sensors detecting anomalies |
| **SRM** | Structural Repair Manual – authoritative repair guidance |
| **Ultimate Load** | Maximum load the structure must withstand without failure (typically 1.5× limit load) |
| **Usage Index** | Metric quantifying cumulative structural usage and fatigue consumption |
| **V&V** | Verification and Validation – processes to confirm requirements are met |
