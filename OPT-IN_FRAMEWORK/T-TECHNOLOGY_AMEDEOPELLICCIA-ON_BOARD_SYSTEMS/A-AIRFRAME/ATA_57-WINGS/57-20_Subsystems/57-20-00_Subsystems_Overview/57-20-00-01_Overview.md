## Purpose

This document provides an overview of the ATA 57 Wing Subsystems layer (57-20_Subsystems). It describes the rationale for replicating the 14-step lifecycle per physical subsystem and explains how this structure supports traceability, certification, and operational readiness.

---

## Overview

The `57-20_Subsystems` layer explicitly replicates the 14-step lifecycle for each physically distinct wing subsystem. Unlike the global 57-00_GENERAL layer (which governs the wing as a whole) and the 57-10_Operations layer (which is a lean operational chapter), the 57-20 layer focuses on subsystem-level documentation.

Each subsystem folder contains:
- A `GENERAL-<SUBSYSTEM-NAME>` folder with the full 14 lifecycle documents
- An `ASSETS` folder for diagrams, installations, and exports

---

## 14-Step Lifecycle Phases

Each subsystem follows this canonical lifecycle:

| Phase | Folder Suffix | Purpose |
|-------|---------------|---------|
| 01 | Overview | ATA domain description and global architecture |
| 02 | Safety | Safety framework and analysis |
| 03 | Requirements | Requirements and traceability |
| 04 | Design | Design specifications and patterns |
| 05 | Interfaces | Interface control documents |
| 06 | Engineering | Analysis, models, and simulation |
| 07 | V_AND_V | Verification and validation |
| 08 | Prototyping | Prototype development |
| 09 | Production_Planning | Manufacturing planning |
| 10 | Certification | Certification evidence |
| 11 | EIS_Versions_Tags | Configuration management |
| 12 | Services | Maintenance and service |
| 13 | Subsystems_Components | Component breakdown |
| 14 | Ops_Std_Sustain | Operational standards |

---

## Relationship to Other 57-XX Layers

| Layer | Purpose | Lifecycle Scope |
|-------|---------|-----------------|
| 57-00_GENERAL | Global wing governance | Full 14-folder lifecycle for the whole wing |
| 57-10_Operations | Operational chapter | Lean operational focus (no lifecycle repetition) |
| 57-20_Subsystems | Physical subsystems | Full 14-folder lifecycle per subsystem |

---

## Subsystems Covered

The following physical subsystems are documented in this layer:

1. **57-21_FLAPS** — High-lift devices for lift augmentation
2. **57-22_SPOILERS** — Lift-dump and air brake devices
3. **57-23_AILERONS** — Roll control surfaces
4. **57-24_SLATS** — Leading edge high-lift devices
5. **57-25_WING_STRUCTURE** — Primary wing structure
6. **57-26_FUEL_TANKS** — Wing fuel storage
7. **57-27_H2_WING_INTEGRATION** — Hydrogen integration with wing systems
8. **57-28_WING_ICE_PROTECTION** — Anti-ice and de-ice systems
9. **57-29_WING_SENSORS_ACTUATION** — Sensors and actuation systems
