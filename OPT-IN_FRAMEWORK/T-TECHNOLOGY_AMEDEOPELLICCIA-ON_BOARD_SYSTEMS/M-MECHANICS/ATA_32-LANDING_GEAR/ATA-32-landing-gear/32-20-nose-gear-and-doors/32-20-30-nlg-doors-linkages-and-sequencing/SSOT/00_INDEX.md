# SSOT — Single Source of Truth

## Overview

This directory contains the Single Source of Truth (SSOT) for NLG Doors, Linkages, and Sequencing (32-20-30).

## Lifecycle Structure (LC01–LC14)

| Folder | Lifecycle Phase | Description |
|:-------|:----------------|:------------|
| LC01_PROBLEM_STATEMENT | Problem Definition | Requirements genesis and problem definition |
| LC02_SYSTEM_REQUIREMENTS | Requirements | Requirements, traceability, ICDs (ATA 24, 29, 31, 45) |
| LC03_DESIGN_MODELS | Design | Architecture, schematics, EHPU/EHA/EHB selection |
| LC04_ENGINEERING_ANALYSIS | Analysis | Loads sizing, power budget, thermal, reliability |
| LC05_INTEGRATION_TESTING | Testing | Test procedures, reports, rigs |
| LC06_QUALITY | Quality | Inspection plans, NCR, supplier quality |
| LC07_SAFETY_SECURITY | Safety | FHA, PSSA, SSA, hazard logs |
| LC08_CERTIFICATION | Certification | Compliance matrix, MoC, flight test support |
| LC09_GREEN_BASELINES | Sustainability | Materials and emissions |
| LC10_INDUSTRIALIZATION | Manufacturing | MBOM/PBOM, CM baselines, work instructions |
| LC11_OPERATIONS | Operations | Operational limitations |
| LC12_SUPPORT_SERVICES | Support | Service bulletins |
| LC13_MRO_SUSTAINMENT | MRO | MSG-3 tasks |
| LC14_RETIREMENT | End of Life | Disposal and recycling |
