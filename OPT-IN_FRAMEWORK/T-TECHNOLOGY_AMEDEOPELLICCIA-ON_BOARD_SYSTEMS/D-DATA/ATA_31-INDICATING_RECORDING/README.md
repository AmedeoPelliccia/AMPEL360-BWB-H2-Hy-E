# ATA 31 — INDICATING RECORDING

## Overview

This is ATA Chapter 31: INDICATING RECORDING, part of the T — TECHNOLOGY AMEDEOPELLICCIA — ON BOARD SYSTEMS axis.

ATA Chapter 31 covers all indicating, recording, and related systems including:

- **31-00**: General — System architecture, HMI philosophy, time sync, interfaces, and baselines
- **31-10**: Instrument and Control Panels — Overhead, glareshield, pedestal, maintenance panels
- **31-20**: Independent Instruments — Standby displays, independent instruments, clocks
- **31-30**: Recorders — FDR, CVR, QAR, data acquisition and crash survivability
- **31-40**: Central Computers — Data concentrators, alert logic, display management, IMA hosting
- **31-50**: Central Warning Systems — CAS/ECAM/EICAS, aural warnings, master caution/warning
- **31-60**: Central Display Systems — PFD, ND, MFD, synoptics, source switching, HUD/EVS
- **31-70**: Automatic Data Reporting — ACMS, health monitoring, datalinks, cybersecurity
