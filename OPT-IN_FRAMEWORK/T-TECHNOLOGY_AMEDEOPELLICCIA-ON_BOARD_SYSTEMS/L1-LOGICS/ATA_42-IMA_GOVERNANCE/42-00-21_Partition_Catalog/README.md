# 42-00-21_Partition_Catalog

## Purpose

Registry of all software partitions for IMA (Integrated Modular Avionics) governance.

## Scope

This folder maintains the catalog of all software partitions including:

* Partition identifiers and descriptions
* DO-178C DAL (Design Assurance Level) assignments
* ARINC 653 partition configuration
* CAST-32A multi-core affinity assignments

## Partition Registry

| Partition ID | Description | DO-178C Level | Status |
|--------------|-------------|---------------|--------|
| P-FCS | Flight Control System | A | Active |
| P-GNC | Guidance, Navigation, Control | A | Active |
| P-ADS | Air Data System | B | Active |
| P-MAINT | Maintenance Functions | D | Active |
| P-DIAG | Diagnostics | C | Planned |
