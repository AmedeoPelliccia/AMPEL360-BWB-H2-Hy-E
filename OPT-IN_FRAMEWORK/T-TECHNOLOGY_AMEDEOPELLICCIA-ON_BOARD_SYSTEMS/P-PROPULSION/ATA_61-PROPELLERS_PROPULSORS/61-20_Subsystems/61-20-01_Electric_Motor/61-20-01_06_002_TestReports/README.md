## Naming Convention

Test reports shall follow the naming convention:

```
test-report-YYYYMMDD-TR-XX-XXX-REV.pdf
```

Where:
- `YYYYMMDD` = Test completion date
- `TR-XX-XXX` = Test report ID
- `REV` = Revision letter (A, B, C, ...)
