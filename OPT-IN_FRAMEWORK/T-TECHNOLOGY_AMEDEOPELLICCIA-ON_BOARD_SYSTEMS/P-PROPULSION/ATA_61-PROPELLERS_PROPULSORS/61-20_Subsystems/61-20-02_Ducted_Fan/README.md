# 61-20-02_Ducted_Fan — ATA 61 Subsystem

## Purpose

Ducted fan subsystem for EDF (Electric Ducted Fan) propulsors. Comprises the fan rotor and stator unit that generates thrust from the electric motor power.

## Scope

This subsystem covers the aerodynamic design, structural integration, and performance characteristics of the ducted fan assemblies used in the AMPEL360 Q100 propulsion system.

## Key Components

- **Fan Rotor**: Rotating blade assembly
- **Stator Vanes**: Fixed guide vanes for flow straightening
- **Nacelle Duct**: Annular duct surrounding fan
- **Spinner**: Nose cone assembly

## Contents

This folder should contain:
- Fan aerodynamic design specifications
- Rotor/stator blade geometry
- Nacelle integration drawings
- Performance maps (thrust, efficiency vs. flight conditions)
- Acoustic characteristics

## Interfaces

- **61-20-01_Electric_Motor**: Power input / mechanical coupling
- **61-20-03_Blade_System**: Blade subcomponents
- **61-50_Structures**: Nacelle frames and mounts
- **ATA 71**: Power plant integration
