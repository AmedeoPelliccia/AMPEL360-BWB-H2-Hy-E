# 61-20-03_Blade_System — ATA 61 Subsystem

## Purpose

Blade system subsystem for EDF propulsors. Covers the detailed design, materials selection, and aerodynamic profiling of fan blades.

## Scope

This subsystem addresses the blade-level design including airfoil selection, composite layup, structural analysis, and manufacturing specifications for the ducted fan blades.

## Key Aspects

- **Airfoil Profiles**: Optimized for cruise efficiency at Mach 0.78
- **Materials**: Advanced composites (CFRP) for weight reduction
- **Manufacturing**: Automated fiber placement (AFP)
- **Containment**: Blade-off event considerations

## Contents

This folder should contain:
- Blade geometry definitions (airfoil coordinates)
- Material specifications and layup schedules
- Structural analysis reports (stress, fatigue)
- Manufacturing process specifications
- Foreign Object Damage (FOD) tolerance analysis

## Interfaces

- **61-20-02_Ducted_Fan**: Integration with rotor hub
- **61-50_Structures**: Load paths to nacelle
- **61-30_ANCHORS**: Sustainability and recyclability of blade materials
- **ATA 05**: Maintenance and inspection procedures
