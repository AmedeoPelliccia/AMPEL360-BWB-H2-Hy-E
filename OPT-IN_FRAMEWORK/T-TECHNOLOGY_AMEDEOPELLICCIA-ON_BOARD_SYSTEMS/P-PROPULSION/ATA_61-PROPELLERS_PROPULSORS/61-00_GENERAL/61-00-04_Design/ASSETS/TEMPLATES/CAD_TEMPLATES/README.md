# CAD Templates

## Overview

This directory contains CAD template files and startup models for the AMPEL360-BWB-H2-Hy-E Q100 program propulsion components.

---

## Contents

| Subdirectory | Purpose | Typical Formats |
|--------------|---------|-----------------|
| `PART_TEMPLATES/` | Individual component templates | .sldprt, .step, .iges |
| `ASSEMBLY_TEMPLATES/` | Assembly structure templates | .sldasm, .step, .iges |
| `STARTUP_MODELS/` | Clean startup models | .sldprt, .sldasm |

---

## Naming Convention

```
Q100-61-TPL-[TYPE]-[NAME].[ext]
```

Where TYPE is:
- `PRT` — Part template
- `ASSY` — Assembly template
- `START` — Startup model

---

## Usage

1. Copy the appropriate template to your working directory
2. Rename following the AMPEL360 Assets naming convention
3. Configure custom properties and parameters
4. Begin design work
