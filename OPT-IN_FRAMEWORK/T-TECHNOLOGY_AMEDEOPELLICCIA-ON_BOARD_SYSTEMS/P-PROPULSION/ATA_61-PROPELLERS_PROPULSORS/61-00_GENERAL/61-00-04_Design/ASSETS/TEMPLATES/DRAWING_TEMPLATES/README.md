# Drawing Templates

## Overview

This directory contains engineering drawing templates including sheet formats, title blocks, symbol libraries, and drawing type templates.

---

## Contents

| Subdirectory | Purpose | Format |
|--------------|---------|--------|
| `SHEET_FORMATS/` | Standard sheet sizes (A0-A4) | .svg |
| `TITLE_BLOCKS/` | Title block, revision, approval blocks | .svg |
| `SYMBOL_LIBRARIES/` | GDT, weld, electrical, etc. | .svg |
| `DRAWING_TYPES/` | Templates by drawing type | .svg |

---

## Sheet Format Sizes

| Size | Dimensions (mm) | Orientation |
|------|-----------------|-------------|
| A0 | 1189 × 841 | Landscape |
| A1 | 841 × 594 | Landscape |
| A2 | 594 × 420 | Landscape |
| A3 | 420 × 297 | Landscape |
| A4 | 210 × 297 | Portrait |

---

## Naming Convention

```
Q100-61-TPL-DRW-[SIZE]-[ORIENTATION].svg
Q100-61-TPL-[TYPE]-[NAME].svg
Q100-61-TPL-SYM-[CATEGORY].svg
```

---

## Usage

1. Import the sheet format into your CAD/drawing application
2. Import required symbol libraries
3. Configure title block fields
4. Begin drawing creation
