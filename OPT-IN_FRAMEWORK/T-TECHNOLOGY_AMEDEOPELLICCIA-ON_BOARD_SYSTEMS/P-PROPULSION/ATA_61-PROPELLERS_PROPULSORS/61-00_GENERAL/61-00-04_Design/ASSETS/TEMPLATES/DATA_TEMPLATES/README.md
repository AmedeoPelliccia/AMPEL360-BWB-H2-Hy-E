# Data Templates

## Overview

This directory contains data structure templates including YAML schemas, CSV formats, and JSON schemas for consistent data definition.

---

## Contents

| Subdirectory | Purpose | Format |
|--------------|---------|--------|
| `YAML_SCHEMAS/` | YAML schema templates | .yaml |
| `CSV_FORMATS/` | CSV format templates | .csv |
| `JSON_SCHEMAS/` | JSON schema templates | .schema.json |

---

## Naming Convention

```
Q100-61-TPL-[TYPE]-[NAME].[ext]
```

Where TYPE is:
- `YAML` — YAML schema template
- `CSV` — CSV format template
- `JSON` — JSON schema template

---

## Usage

1. Select the appropriate data template
2. Copy to your target directory
3. Rename following the AMPEL360 naming convention
4. Customize fields for your specific use case
5. Validate data against schema
