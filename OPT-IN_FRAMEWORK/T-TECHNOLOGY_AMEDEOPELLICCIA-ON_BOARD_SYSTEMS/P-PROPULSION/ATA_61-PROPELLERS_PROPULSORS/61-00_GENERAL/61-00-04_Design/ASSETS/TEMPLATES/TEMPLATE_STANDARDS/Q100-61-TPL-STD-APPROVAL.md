# Template Approval Process

<!-- Template ID: Q100-61-TPL-STD-APPROVAL -->

## 1. Purpose

This document defines the approval process for new and modified templates.

---

## 2. Approval Categories

### 2.1 New Template

Required for creating new templates.

**Approvers:**
- Technical Lead
- Configuration Manager

### 2.2 Major Revision

Required for structural changes.

**Approvers:**
- Technical Lead
- Original Author (if available)

### 2.3 Minor Revision

Required for content updates.

**Approvers:**
- Peer Reviewer

---

## 3. Approval Workflow

```
┌─────────────────┐
│ 1. DRAFT        │ Author creates/modifies
└────────┬────────┘
         │
         ▼

│ 2. REVIEW       │ Peer review
└────────┬────────┘
         │
         ▼

         │
         ▼

│ 4. RELEASE      │ Configuration control
└─────────────────┘
```

---

## 4. Submission Requirements

### 4.1 New Template Submission

- [ ] Completed template
- [ ] Usage documentation
- [ ] Example(s) of use
- [ ] Justification for new template

### 4.2 Revision Submission

- [ ] Updated template
- [ ] Changelog updated
- [ ] Impact assessment
- [ ] Backward compatibility notes

---

## 5. Review Criteria

### 5.1 Technical Review

- [ ] Correct structure
- [ ] Consistent with standards
- [ ] Complete required fields
- [ ] Proper naming convention

### 5.2 Quality Review

- [ ] Clear instructions
- [ ] No ambiguous fields
- [ ] Examples provided
- [ ] Document Control complete
