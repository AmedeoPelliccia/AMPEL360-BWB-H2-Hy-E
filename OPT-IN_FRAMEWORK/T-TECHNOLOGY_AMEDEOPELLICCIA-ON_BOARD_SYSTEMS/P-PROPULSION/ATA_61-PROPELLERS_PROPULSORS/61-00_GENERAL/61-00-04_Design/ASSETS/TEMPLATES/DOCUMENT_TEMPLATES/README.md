# Document Templates

## Overview

This directory contains markdown templates for technical documentation including specifications, reports, procedures, checklists, and meeting notes.

---

## Contents

| Subdirectory | Purpose | File Format |
|--------------|---------|-------------|
| `SPECIFICATIONS/` | Performance, material, interface specifications | .md |
| `REPORTS/` | Analysis, test, review, trade study reports | .md |
| `PROCEDURES/` | Installation, maintenance, test procedures | .md |
| `CHECKLISTS/` | Design review, installation, quality checklists | .md |
| `MEETING_NOTES/` | Technical and review meeting templates | .md |

---

## Naming Convention

```
Q100-61-TPL-[TYPE]-[NAME].md
```

Where TYPE is:
- `SPEC` — Specification
- `RPT` — Report
- `PROC` — Procedure
- `CHK` — Checklist
- `MTG` — Meeting notes

---

## Usage

1. Copy the appropriate template to your target location
2. Rename following the AMPEL360 naming convention
3. Remove the template instructions section
4. Fill in required fields (marked with `*`)
5. Complete optional sections as needed
