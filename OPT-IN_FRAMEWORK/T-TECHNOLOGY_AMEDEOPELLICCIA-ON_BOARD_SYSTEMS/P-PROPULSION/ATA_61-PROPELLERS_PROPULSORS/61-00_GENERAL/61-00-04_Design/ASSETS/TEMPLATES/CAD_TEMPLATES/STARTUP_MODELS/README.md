## Usage

1. Open the startup model in your CAD application
2. Use "Save As" to create your new file
3. Rename following AMPEL360 naming convention
4. Verify units and tolerances
5. Begin design work

---

## Standard Settings

All startup models are configured with:

| Setting | Value |
|---------|-------|
| Units | Millimeters |
| Tolerance | ±0.1 mm (default) |
| Grid | 1 mm |
| Decimal Places | 3 |
| Material Library | AMPEL360 Standard |
