# Specification Templates

## Overview

Templates for engineering specifications including performance, material, interface, environmental, and test specifications.

---

## Available Templates

| Template | Purpose |
|----------|---------|
| Q100-61-TPL-SPEC-PERFORMANCE.md | Performance specifications |
| Q100-61-TPL-SPEC-MATERIAL.md | Material specifications |
| Q100-61-TPL-SPEC-INTERFACE.md | Interface control specifications |
| Q100-61-TPL-SPEC-ENVIRONMENTAL.md | Environmental requirements |
| Q100-61-TPL-SPEC-TEST.md | Test specifications |

---

## Usage

1. Select the appropriate specification template
2. Copy to your target directory
3. Rename following the AMPEL360 naming convention
4. Fill in all required sections
5. Link to related requirements and drawings
