## Usage

1. Copy template to your working directory
2. Rename following AMPEL360 naming convention
3. Configure custom properties:
   - Part Number
   - Description
   - Material
   - Revision
4. Set units (mm or inches)
5. Begin modeling

---

## Custom Properties

All part templates include these standard properties:

| Property | Type | Required |
|----------|------|----------|
| PartNumber | Text | Yes |
| Description | Text | Yes |
| Material | Text | Yes |
| Revision | Text | Yes |
| Author | Text | Yes |
