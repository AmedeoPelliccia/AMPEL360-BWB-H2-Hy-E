## GD&T Symbols (Q100-61-TPL-SYM-GDT.svg)

Includes ISO 1101 / ASME Y14.5 symbols:

- Form tolerances (straightness, flatness, circularity, cylindricity)
- Orientation tolerances (perpendicularity, angularity, parallelism)
- Location tolerances (position, concentricity, symmetry)
- Runout tolerances (circular runout, total runout)
- Profile tolerances (profile of line, profile of surface)
- Datum symbols and modifiers

---

## Welding Symbols (Q100-61-TPL-SYM-WELD.svg)

Includes AWS A2.4 symbols:

- Fillet welds
- Groove welds (V, U, J, etc.)
- Plug and slot welds
- Seam and spot welds
- Surfacing welds
- Weld contour symbols
- Supplementary symbols

---

## Surface Finish Symbols (Q100-61-TPL-SYM-SURFACE-FINISH.svg)

Includes ISO 1302 / ASME Y14.36 symbols:

- Surface roughness values (Ra, Rz)
- Lay direction symbols
- Machining allowance symbols
- Surface texture symbols

---

## Usage

1. Import the required symbol library
2. Copy symbols to your drawing
3. Scale and position as needed
4. Add values and dimensions
