## Standard Product Directory Layout

```
[PRODUCT_NUMBER]/
├── README.md                    # Product documentation
├── DEFINITION/
│   ├── [Product].yaml          # Product definition
│   ├── CONFIG.yaml             # Configuration data
│   └── BOM.yaml                # Top-level BOM
├── ASSEMBLIES/
│   └── [Assembly]/             # Assembly directories
├── DRAWINGS/
│   ├── INSTALLATION/           # Installation drawings
│   └── SYSTEM/                 # System drawings
├── SPECIFICATIONS/
│   ├── PERFORMANCE/            # Performance specs
│   ├── INTERFACE/              # Interface specs
│   └── ENVIRONMENTAL/          # Environmental specs
├── ANALYSIS/
│   └── REPORTS/
├── CERTIFICATION/
│   ├── COMPLIANCE/             # Compliance evidence
│   ├── TEST/                   # Test reports
│   └── SAFETY/                 # Safety analysis
├── MAINTENANCE/
│   └── PROCEDURES/
└── EXPORTS/
    └── RELEASED/
```
