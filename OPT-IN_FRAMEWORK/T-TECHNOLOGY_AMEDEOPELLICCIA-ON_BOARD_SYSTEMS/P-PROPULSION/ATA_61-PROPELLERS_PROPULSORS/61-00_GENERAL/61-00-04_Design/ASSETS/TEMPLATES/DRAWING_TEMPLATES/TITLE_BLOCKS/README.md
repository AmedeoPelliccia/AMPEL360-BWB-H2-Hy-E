# Title Blocks

## Overview

Standard title block, revision block, and approval block templates in SVG format.

---

## Available Templates

| Template | Purpose |
|----------|---------|
| Q100-61-TPL-TITLEBLOCK-STD.svg | Standard drawing title block |
| Q100-61-TPL-REVISION-BLOCK.svg | Revision history block |
| Q100-61-TPL-APPROVAL-BLOCK.svg | Approval signatures block |

## Title Block Fields

### Standard Title Block

| Field | Description | Example |
|-------|-------------|---------|
| Drawing Number | Unique drawing identifier | 61-00-04-A201 |
| Title | Drawing title | Propulsor Housing |
| Program | Program identifier | Q100 |
| Scale | Drawing scale | 1:5 |
| Sheet | Sheet number | 1 of 3 |
| Size | Sheet size | A3 |
| Revision | Current revision | B |
| Date | Revision date | 2025-12-05 |
| Drawn By | Author name | A. Pelliccia |
| Checked By | Checker name | — |
| Approved By | Approver name | — |

### Revision Block

| Column | Description |
|--------|-------------|
| Rev | Revision letter |
| Date | Revision date |
| By | Author initials |
| Description | Change description |

### Approval Block

| Field | Description |
|-------|-------------|
| Role | Approver role |
| Name | Approver name |
| Signature | Signature area |
| Date | Approval date |

---

## Usage

1. Import the title block into your sheet format
2. Position in the bottom-right corner
3. Add revision block above or to the left
4. Fill in required fields
