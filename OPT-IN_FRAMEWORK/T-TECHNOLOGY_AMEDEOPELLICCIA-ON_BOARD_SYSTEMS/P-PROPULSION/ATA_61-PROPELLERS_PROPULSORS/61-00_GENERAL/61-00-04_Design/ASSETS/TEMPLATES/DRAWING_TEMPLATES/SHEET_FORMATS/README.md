# Sheet Formats

## Overview

Standard engineering drawing sheet formats in SVG format for A0 through A4 sizes.

---

| Template | Size | Dimensions | Orientation |
|----------|------|------------|-------------|
| Q100-61-TPL-DRW-A0-LANDSCAPE.svg | A0 | 1189 × 841 mm | Landscape |
| Q100-61-TPL-DRW-A1-LANDSCAPE.svg | A1 | 841 × 594 mm | Landscape |
| Q100-61-TPL-DRW-A2-LANDSCAPE.svg | A2 | 594 × 420 mm | Landscape |
| Q100-61-TPL-DRW-A3-LANDSCAPE.svg | A3 | 420 × 297 mm | Landscape |
| Q100-61-TPL-DRW-A4-PORTRAIT.svg | A4 | 210 × 297 mm | Portrait |

---

## Sheet Features

All sheet formats include:

- **Border** — Standard drawing border with margin
- **Title Block Area** — Reserved space for title block
- **Revision Block Area** — Reserved space for revision history
- **Zone Grid** — Reference grid for locating features
- **Scale Reference** — Standard scale block

---

## Usage

1. Import the appropriate sheet format
2. Add title block from `TITLE_BLOCKS/`
3. Import required symbols from `SYMBOL_LIBRARIES/`
4. Begin drawing creation
