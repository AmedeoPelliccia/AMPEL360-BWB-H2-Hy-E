# Report Templates

## Overview

Templates for engineering reports including analysis reports, test reports, review reports, and trade study reports.

---

## Available Templates

| Template | Purpose |
|----------|---------|
| Q100-61-TPL-RPT-ANALYSIS.md | Analysis and simulation reports |
| Q100-61-TPL-RPT-TEST.md | Test execution and results reports |
| Q100-61-TPL-RPT-REVIEW.md | Design and technical review reports |
| Q100-61-TPL-RPT-TRADE-STUDY.md | Trade study and decision reports |

---

## Usage

1. Select the appropriate report template
2. Copy to your target directory
3. Rename following the AMPEL360 naming convention
4. Complete all sections with actual data
5. Include supporting data and references
