## Usage

1. Copy template to your working directory
2. Rename following AMPEL360 naming convention
3. Configure assembly properties:
   - Assembly Number
   - Description
   - Revision
   - BOM Configuration
4. Add component references
5. Apply constraints and relationships

---

## Custom Properties

All assembly templates include these standard properties:

| Property | Type | Required |
|----------|------|----------|
| AssemblyNumber | Text | Yes |
| Description | Text | Yes |
| Revision | Text | Yes |
| Author | Text | Yes |
| DateCreated | Date | Yes |
| ATAChapter | Text | Yes |
| Program | Text | Yes |
| BOMLevel | Integer | Yes |
