# Step 03 — Coupling

## Purpose

Engage motor spline coupling with gearbox input.

## Instructions

1. Apply grease to spline teeth
2. Align motor shaft with gearbox input
3. Slowly engage splines (no forcing)
4. Verify full engagement
5. Check axial position

## Verification

- [ ] Splines greased
- [ ] Full engagement confirmed
- [ ] Axial position correct
