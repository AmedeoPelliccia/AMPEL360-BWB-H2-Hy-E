# INSTALLATION_PROCEDURES — Step-by-Step Installation Procedures

## Purpose

This directory contains detailed step-by-step installation procedures for all major propulsion system components. Each procedure includes:

- Prerequisites and safety requirements
- Required tools and equipment
- Detailed installation steps
- Verification checklists
- Visual references

## Contents

| Directory | Description |
|-----------|-------------|
| Q100-61-INST-PROC-PROPULSOR-INSTALL | Complete propulsor unit installation |
| Q100-61-INST-PROC-MOTOR-INSTALL | Electric motor installation |
| Q100-61-INST-PROC-GEARBOX-INSTALL | Reduction gearbox installation |
| Q100-61-INST-PROC-FAN-INSTALL | Fan/blade assembly installation |
| Q100-61-INST-PROC-CONTROLLER-INSTALL | Motor controller installation |

## Procedure Structure

Each installation procedure directory contains:

```
Q100-61-INST-PROC-[NAME]/
├── README.md           # Overview and scope
├── procedure.md        # Master procedure document
├── steps/              # Individual step documents
│   ├── 01_preparation.md
│   ├── 02_xxx.md
│   └── ...
├── checklists/         # Verification checklists
│   ├── pre_installation_checklist.md
│   ├── installation_checklist.md
│   └── post_installation_checklist.md
└── VISUALS/            # Diagrams and photos
    └── .gitkeep
```

## Procedure Format

### Step Numbering

Steps are numbered sequentially within each phase:
- `01_xxx.md` — First phase
- `02_xxx.md` — Second phase
- etc.

### Step Content

Each step document includes:
1. **Purpose** — What this step accomplishes
2. **Safety Warnings** — Hazards and precautions
3. **Tools Required** — Specific tools for this step
4. **Parts/Materials** — Consumables and hardware
5. **Instructions** — Detailed procedural steps
6. **Verification** — How to confirm correct execution
7. **Notes** — Additional guidance

## Safety Requirements

All procedures require:
- Appropriate PPE (per job safety analysis)
- Lockout/tagout of energy sources
- Two-person verification for critical steps
- Supervisor sign-off at hold points

## Qualification Requirements

Technicians performing these procedures must:
- Hold appropriate A&P certification
- Complete Q100 propulsion system training
- Be current on recertification requirements
