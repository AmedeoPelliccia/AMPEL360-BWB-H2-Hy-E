# Q100-61-INST-DEF-MOTOR-TO-GEARBOX — Motor to Gearbox Installation Definition

## Overview

This definition specifies the interface and mounting requirements for coupling the electric motor to the reduction gearbox. This interface transfers power from the motor to the fan through precise alignment.

## Scope

- Motor flange mounting
- Spline coupling interface
- Alignment requirements
- Cooling interface
- Sensor connections

## Key Interfaces

| Interface | Type | Description |
|-----------|------|-------------|
| Motor Flange | Mechanical | Bolted flange connection |
| Spline Coupling | Mechanical | Power transmission |
| Cooling Jacket | Fluid | Motor cooling circuit |
| Temperature Sensors | Electrical | Thermal monitoring |
| Speed Sensors | Electrical | RPM and position |
