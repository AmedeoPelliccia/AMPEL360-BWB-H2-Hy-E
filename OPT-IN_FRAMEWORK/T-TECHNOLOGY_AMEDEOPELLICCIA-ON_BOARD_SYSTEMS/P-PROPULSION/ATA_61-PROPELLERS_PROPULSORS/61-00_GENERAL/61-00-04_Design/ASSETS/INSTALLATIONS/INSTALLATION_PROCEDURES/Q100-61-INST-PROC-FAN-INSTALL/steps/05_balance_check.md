# Step 05 — Balance Check

## Purpose

Verify fan assembly balance.

## Instructions

1. Install balance equipment
2. Spin to 1500 RPM
3. Record imbalance readings
4. Calculate correction weights
5. Install balance weights
6. Re-spin and verify

## Verification

- [ ] Static imbalance ≤10 g·mm
- [ ] Dynamic imbalance ≤50 g·mm²
- [ ] Balance weights secured
