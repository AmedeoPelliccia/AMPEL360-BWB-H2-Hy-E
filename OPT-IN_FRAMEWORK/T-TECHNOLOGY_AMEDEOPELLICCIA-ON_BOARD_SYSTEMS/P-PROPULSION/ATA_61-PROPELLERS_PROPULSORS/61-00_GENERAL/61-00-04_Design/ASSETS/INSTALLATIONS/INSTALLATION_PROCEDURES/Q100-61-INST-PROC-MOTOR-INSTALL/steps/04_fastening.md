# Step 04 — Fastening

## Purpose

Install and torque motor mount fasteners.

## Instructions

1. Install all mount bolts hand-tight
2. Torque in cross pattern:
   - Pass 1: 28 Nm (50%)
   - Pass 2: 44 Nm (80%)
   - Pass 3: 55 Nm (100%)
3. Mark bolts after final torque
4. Install safety wire

## Verification

- [ ] All fasteners torqued
- [ ] Torque marks applied
- [ ] Safety wire installed
