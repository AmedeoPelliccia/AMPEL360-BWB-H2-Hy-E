# Q100-61-INST-PROC-FAN-INSTALL — Fan Installation Procedure

## Overview

This procedure covers the installation of the open-fan blade assembly onto the gearbox output shaft, including blade installation, pitch mechanism setup, and balance verification.

## Scope

- Hub installation on gearbox output
- Individual blade installation
