# Step 07 — Verification

## Purpose

Complete all post-installation checks to verify correct installation and readiness for operational testing.

## Safety Warnings

⚠️ **WARNING**: Do not remove lockout until all checks complete and documented.

⚠️ **CAUTION**: Ground run testing is a separate procedure—do not attempt here.

## Tools Required

- Dial indicators
- Feeler gauges
- Multimeter
- Pressure test equipment
- Leak detection fluid
- Inspection mirror and light

## Instructions

### 7.1 Visual Inspection

1. Inspect all mount fasteners for proper installation
2. Verify all safety wire is correctly installed
3. Inspect all electrical connections
4. Inspect all fluid connections
5. Verify no foreign objects or debris in installation area
6. Check for any visible damage or discrepancies

### 7.2 Clearance Verification

1. Measure blade tip clearance (minimum 50mm)
2. Measure nacelle-to-pylon clearance (minimum 25mm)
3. Measure cable clearances from hot zones (minimum 50mm)
4. Record all measurements

### 7.3 Alignment Verification

1. Install dial indicator on propulsor shaft
2. Rotate shaft by hand (one full revolution)
3. Record total indicator runout (TIR)
4. TIR must be ≤0.15mm
5. If out of tolerance, investigate and correct

### 7.4 Electrical Checks

**With lockout still in place:**

1. Verify continuity of power umbilical (phase to phase)
2. Verify continuity of control circuits per schematic
3. Measure insulation resistance (megohm test)
4. Record all readings

**Minimum insulation resistance: 50 MΩ @ 500V**

### 7.5 Fluid System Checks

1. Pressurize cooling system to 6 bar (test pressure)
2. Hold for 5 minutes
3. Check for leaks at all connections
4. Apply leak detection fluid to all joints
5. No visible leaks allowed
6. Depressurize system
7. Repeat for lubrication system at 10 bar

### 7.6 Documentation Completion

1. Complete installation traveler (all signatures)
2. Complete torque log
3. Complete electrical test log
4. Complete pressure test log
5. Photograph as-installed configuration
6. Update aircraft configuration record

### 7.7 Lockout Removal

1. Verify all checks complete and passed
2. Obtain supervisor authorization
3. Remove lockout tags
4. Remove lockout devices
5. Notify operations of installation complete
