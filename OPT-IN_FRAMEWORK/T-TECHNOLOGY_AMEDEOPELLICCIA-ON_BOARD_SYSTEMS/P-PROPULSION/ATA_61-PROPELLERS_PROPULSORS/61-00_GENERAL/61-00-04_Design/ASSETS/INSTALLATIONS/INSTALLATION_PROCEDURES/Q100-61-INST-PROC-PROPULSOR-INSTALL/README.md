# Q100-61-INST-PROC-PROPULSOR-INSTALL — Propulsor Installation Procedure

## Overview

This procedure covers the complete installation of the open-fan propulsor unit onto the pylon structure, including mechanical attachment, electrical connections, and fluid system hookup.

## Scope

- Propulsor rigging and positioning
- Mount attachment and torquing
- Electrical umbilical connection
- Cooling and lubrication hookup
- Post-installation verification
