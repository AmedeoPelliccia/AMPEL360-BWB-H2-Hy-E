# Q100-61-INST-PROC-FAN-INSTALL — Master Procedure

## 1. Purpose

Install the open-fan blade assembly onto the gearbox output shaft.

## 2. Prerequisites

- [ ] Gearbox and motor installed
- [ ] All blades inspected and matched
- [ ] Hub receiving inspection complete
- [ ] Balance equipment available

## 3. Procedure Summary

1. Inspect all blades for damage
2. Prepare hub and install on gearbox
3. Install blades in matched positions
4. Set initial blade pitch
5. Perform balance check
6. Install spinner

## 4. Acceptance Criteria

| Parameter | Limit |
|-----------|-------|
| Static imbalance | ≤10 g·mm |
| Dynamic imbalance | ≤50 g·mm² |
| Blade track variation | ≤5 mm |
