# Q100-61-INST-DEF-FAN-TO-GEARBOX — Fan to Gearbox Installation Definition

## Overview

This definition specifies the interface and mounting requirements for installing the open-fan assembly onto the reduction gearbox output shaft. This interface must accommodate blade pitch actuation while maintaining precise balance.

## Scope

- Hub mounting interface
- Blade attachment
- Pitch mechanism interface
- Balance requirements
- Spinner installation

## Key Interfaces

| Interface | Type | Description |
|-----------|------|-------------|
| Hub Spline | Mechanical | Power transmission from gearbox |
| Hub Flange | Mechanical | Axial retention |
| Blade Roots | Mechanical | Blade attachment points |
| Pitch Actuator | Mechanical/Hydraulic | Blade pitch control |
| Spinner Mount | Mechanical | Aerodynamic fairing |
