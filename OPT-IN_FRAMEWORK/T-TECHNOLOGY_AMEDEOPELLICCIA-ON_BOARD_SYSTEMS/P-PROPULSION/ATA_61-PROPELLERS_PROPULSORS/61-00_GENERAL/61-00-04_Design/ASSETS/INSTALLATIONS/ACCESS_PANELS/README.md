# ACCESS_PANELS — Maintenance Access Panel Definitions

## Purpose

This directory contains definitions for all maintenance access panels on the propulsor nacelle, including location, opening requirements, and accessible components.

## Contents

| Document/Directory | Description |
|-------------------|-------------|
| Q100-61-ACC-PANEL-INDEX.yaml | Master index of all panels |
| Q100-61-ACC-NACELLE-FWD | Forward nacelle access |
| Q100-61-ACC-NACELLE-AFT | Aft nacelle access |
| Q100-61-ACC-GEARBOX | Gearbox inspection access |
| Q100-61-ACC-MOTOR | Motor access panel |
| Q100-61-ACC-CONTROLLER | Controller bay access |

## Panel Naming Convention

```
Q100-61-ACC-[LOCATION]-[POSITION]
```

## Panel Categories

### Quick Access (Latched)

No tools required, for routine inspections.

### Standard Access (Fastened)

Standard fasteners, for maintenance access.

### Structural Access (Bolted)

Structural fasteners, for major maintenance or R&R.
