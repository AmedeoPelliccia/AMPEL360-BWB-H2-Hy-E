# Q100-61-RTE-FLD-COOLING-SUPPLY — Cooling Supply Routing

## Overview

Defines the routing for motor and controller cooling supply from the aircraft thermal management system.

## Routing Path

```
Aircraft Cooling Skid
    ↓
Wing/Body Junction
    ↓
Pylon Passage
    ↓
    ├── Controller Cold Plate
    ↓
    └── Motor Cooling Jacket
```

## Line Specification

| Parameter | Value |
|-----------|-------|
| Material | Stainless steel, braided |
| ID | 25mm |
| Pressure rating | 10 bar |
| Temperature rating | -55°C to +100°C |
| Fittings | Quick-disconnect |

## Routing Requirements

- Support every 500mm
- Minimum bend radius: 125mm
- Thermal expansion allowance
- Drain provisions at low points
