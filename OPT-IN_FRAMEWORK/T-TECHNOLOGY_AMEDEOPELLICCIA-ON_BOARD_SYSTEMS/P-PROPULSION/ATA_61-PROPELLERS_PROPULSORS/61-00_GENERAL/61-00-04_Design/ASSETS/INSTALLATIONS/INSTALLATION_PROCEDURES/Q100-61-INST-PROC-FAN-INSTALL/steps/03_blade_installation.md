# Step 03 — Blade Installation

## Purpose

Install blades in matched positions.

## Instructions

1. Review blade position chart
2. Install blade installation tool
3. Insert blade root into hub socket
4. Engage dovetail retention
5. Install retention pin
6. Repeat for all 12 blades

## Verification

- [ ] All blades installed per position chart
- [ ] Dovetail engagement verified
- [ ] All retention pins installed
