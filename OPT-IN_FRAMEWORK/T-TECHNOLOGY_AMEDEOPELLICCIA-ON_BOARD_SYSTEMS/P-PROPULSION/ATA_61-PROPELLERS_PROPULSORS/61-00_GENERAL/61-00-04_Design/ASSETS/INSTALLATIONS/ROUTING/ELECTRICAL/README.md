# ELECTRICAL ROUTING

## Purpose

This directory contains routing specifications for all electrical connections in the propulsion system, including high-voltage power, control signals, and sensor wiring.

## Key Specifications

### High Voltage (>60 VDC)

- Orange color-coded conductors and conduit
- Double insulation required
- Arc-flash protection
- Dedicated grounding path

### EMI Protection

- Shielded cables for all power circuits
- Twisted pairs for control signals
- Ground planes at interface points
- 60 dB minimum shielding effectiveness
