# Q100-61-RTE-ELEC-CONTROL-BUS — Motor Control Bus Routing

## Overview

Defines the routing for motor controller to motor phase cables.

## Routing Path

```
Motor Controller AC Output
    ↓
Nacelle Internal Routing
    ↓
Motor Terminal Block
```

## Cable Specification

| Parameter | Value |
|-----------|-------|
| Conductor | 2/0 AWG, stranded copper |
| Insulation | Silicone, 1000V, high-temp |
| Phases | A, B, C (3 cables) |
| Shield | Individual + overall |
| Color coding | Per phase standard |

## Routing Requirements

- Keep cables parallel
- Maintain phase balance
- Minimum bend radius: 200mm
- Thermal rating: 150°C
- Secure every 200mm
