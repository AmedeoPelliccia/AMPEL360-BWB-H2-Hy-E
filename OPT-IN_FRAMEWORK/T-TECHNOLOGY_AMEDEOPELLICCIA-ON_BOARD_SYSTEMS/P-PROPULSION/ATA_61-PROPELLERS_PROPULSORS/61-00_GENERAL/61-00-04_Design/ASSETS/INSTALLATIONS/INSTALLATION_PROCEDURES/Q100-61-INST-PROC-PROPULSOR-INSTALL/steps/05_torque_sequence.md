# Step 05 — Torque Sequence

## Purpose

Torque all mount fasteners to specified values in the correct sequence.

## Safety Warnings

⚠️ **WARNING**: Use only calibrated torque wrenches.

⚠️ **CAUTION**: Follow torque sequence exactly to prevent distortion.

## Tools Required

- Torque wrench, 50-150 Nm range (calibrated)
- Torque wrench, 20-80 Nm range (calibrated)
- Torque multiplier Q100-61-TOOL-003 (if needed)
- Backup wrenches
- Marking pen (yellow)

## Torque Values

| Location | Part Number | Torque (Nm) | Tolerance |
|----------|-------------|-------------|-----------|
| Forward mount | NAS6604-24 | 95 | ±5% |
| Aft mount | NAS6606-28 | 135 | ±5% |
| Thrust link | NAS6604-20 | 75 | ±5% |

## Instructions

### 5.1 Torque Sequence Overview

Torque all fasteners in three passes:
- Pass 1: 50% of final torque
- Pass 2: 80% of final torque
- Pass 3: 100% of final torque

### 5.2 Forward Mount Torque

Sequence: Cross pattern (1-5-2-6-3-7-4-8)

```
    1       2
    
3       4       5
    
    6       7
    
        8
```

1. Pass 1: Torque all bolts to 48 Nm (50%)
2. Pass 2: Torque all bolts to 76 Nm (80%)
3. Pass 3: Torque all bolts to 95 Nm (100%)
4. Mark each bolt head with yellow stripe after final torque

### 5.3 Aft Mount Torque

Sequence: Cross pattern (1-5-2-6-3-7-4-8)

1. Pass 1: Torque all bolts to 68 Nm (50%)
2. Pass 2: Torque all bolts to 108 Nm (80%)
3. Pass 3: Torque all bolts to 135 Nm (100%)
4. Mark each bolt head after final torque

### 5.4 Thrust Link Torque

Sequence: Alternate left-right (L1-R1-L2-R2)

1. Pass 1: Torque all bolts to 38 Nm (50%)
2. Pass 2: Torque all bolts to 60 Nm (80%)
3. Pass 3: Torque all bolts to 75 Nm (100%)
4. Mark each bolt head after final torque

### 5.5 Torque Verification

1. Using a second calibrated torque wrench, verify torque on 25% of fasteners (minimum 2 per location)
2. Verify fasteners selected randomly
3. Record verification readings
4. All readings must be within tolerance

### 5.6 Safety Wire Installation

1. Install safety wire on all fasteners per MS33540
2. Use 0.032" stainless steel wire (MS20995C32)
3. Wire in direction to prevent loosening
4. Twist minimum 6 turns per inch
5. Secure pigtails (minimum 3 turns, cut end tucked)
