# Q100-61-INST-PROC-PROPULSOR-INSTALL — Master Procedure

## 1. Purpose

This procedure provides instructions for installing the open-fan propulsor assembly onto the pylon mount structure.

## 3. Prerequisites

### 3.1 Prior Tasks Complete

- [ ] Pylon installed and inspected
- [ ] All pylon systems tested
- [ ] Propulsor pre-installation inspection complete
- [ ] Work area cleared and prepared

### 3.2 Required Certifications

- A&P Mechanic with Powerplant rating
- Q100 Propulsion System Training (Course PRP-001)
- High-voltage electrical safety (>400V)

### 3.3 Required Approvals

- [ ] Shift supervisor authorization
- [ ] Quality inspector notification
- [ ] Safety officer briefing complete

## 4. Safety Requirements

### 4.1 Hazards

| Hazard | Risk | Control |
|--------|------|---------|
| Suspended load | Crushing | Exclusion zone, trained riggers |
| High voltage | Electrocution | Lockout/tagout, grounding |
| Pinch points | Injury | Guards, awareness |
| Hydraulic pressure | Injection | Depressurize, PPE |

### 4.2 Personal Protective Equipment

- Safety glasses
- Hard hat
- Steel-toe boots
- Cut-resistant gloves (Level A4)
- High-visibility vest

### 4.3 Lockout/Tagout

Before starting:
1. De-energize main power bus
2. Apply lockout on electrical disconnect
3. Depressurize hydraulic system
4. Install "DO NOT OPERATE" tags
5. Verify zero energy state
