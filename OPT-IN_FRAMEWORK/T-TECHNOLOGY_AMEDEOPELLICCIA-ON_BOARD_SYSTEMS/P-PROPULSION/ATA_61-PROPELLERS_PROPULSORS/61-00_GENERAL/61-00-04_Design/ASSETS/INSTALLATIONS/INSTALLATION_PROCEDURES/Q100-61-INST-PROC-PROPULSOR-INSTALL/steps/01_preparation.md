# Step 01 — Preparation

## Purpose

Prepare the work area, verify tools and equipment, and ensure all prerequisites are complete before beginning propulsor installation.

## Safety Warnings

⚠️ **WARNING**: Ensure all lockout/tagout procedures are complete before proceeding.

⚠️ **WARNING**: Verify crane capacity and rigging equipment inspection dates.

## Tools Required

- [ ] Calibration verification for all torque wrenches
- [ ] Crane with minimum 1000 kg capacity
- [ ] Lift fixture Q100-61-TOOL-001
- [ ] Standard tool kit

## Instructions

### 1.1 Work Area Preparation

1. Clear work area of all unnecessary equipment and debris
2. Establish exclusion zone around installation area (minimum 5m radius)
3. Position portable lighting for adequate visibility
4. Set up tool staging area
5. Position safety equipment (fire extinguisher, first aid kit)

### 1.2 Equipment Verification

1. Verify crane inspection is current
2. Inspect lift fixture for damage or wear
3. Verify all slings and shackles are rated and inspected
4. Check torque wrench calibration dates
5. Verify special tools are available and serviceable

### 1.3 Component Verification

1. Verify propulsor serial number matches work order
2. Inspect propulsor for shipping damage
3. Verify all protective covers are in place
4. Check that fluid ports are capped
5. Verify electrical connectors are protected

### 1.4 Documentation Review

1. Review current revision of installation procedure
2. Verify all engineering orders are incorporated
3. Check for any open discrepancies on propulsor or pylon
4. Review pre-installation inspection record

## Verification

- [ ] Work area cleared and exclusion zone established
- [ ] All tools verified and staged
- [ ] Propulsor inspected and documentation verified
- [ ] Pre-installation checklist complete
- [ ] Supervisor authorization obtained

## Notes

- If any discrepancy is found, stop and notify supervisor
- Photograph any pre-existing damage before installation
