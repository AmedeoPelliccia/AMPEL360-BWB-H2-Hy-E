# Q100-61-TOOL-BALANCE-FIXTURE — Operating Instructions

## Purpose

Verify fan assembly balance after installation.

## Procedure

1. Install balance sensors
2. Spin to test speed (1500 RPM)
3. Record imbalance readings
4. Calculate corrections
5. Install balance weights
6. Verify final balance

## Calibration

Annual calibration required per MIL-STD-45662.
