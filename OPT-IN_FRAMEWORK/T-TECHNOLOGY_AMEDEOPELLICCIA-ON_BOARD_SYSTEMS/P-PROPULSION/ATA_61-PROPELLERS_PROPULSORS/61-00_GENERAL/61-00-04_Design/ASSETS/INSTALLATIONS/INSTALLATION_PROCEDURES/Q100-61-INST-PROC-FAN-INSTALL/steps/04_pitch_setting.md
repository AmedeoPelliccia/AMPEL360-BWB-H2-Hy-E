# Step 04 — Pitch Setting

## Purpose

Set initial blade pitch angles.

## Instructions

1. Install pitch setting tool
2. Set all blades to flat pitch (0°)
3. Verify pitch mechanism operation
4. Cycle through full range
5. Return to flat pitch

## Verification

- [ ] All blades at 0° pitch
- [ ] Pitch mechanism operational
- [ ] Full range verified
