# Q100-61-INST-DEF-PYLON-TO-AIRFRAME — Pylon to Airframe Installation Definition

## Overview

This definition specifies the interface and mounting requirements for attaching the propulsion pylon to the BWB (Blended Wing Body) airframe structure. This is the primary structural interface transferring all propulsive and inertial loads to the aircraft.

## Scope

- Upper and lower attachment fittings
- Shear pins and tension bolts
- Load path distribution
- Fail-safe design provisions
- Inspection access requirements

## Key Interfaces

| Interface | Type | Description |
|-----------|------|-------------|
| Upper Attachment | Mechanical | Primary vertical/lateral load path |
| Lower Attachment | Mechanical | Thrust and vertical load reaction |
| Shear Pins | Mechanical | Lateral load transfer |
| Tension Bolts | Mechanical | Vertical load reaction |
| Electrical Routing | Through-structure | Power and signal conduits |
| Fluid Routing | Through-structure | Cooling and lube lines |
