# Step 06 — Spinner Install

## Purpose

Install spinner fairing.

## Instructions

1. Position spinner on hub
2. Align mounting holes
3. Install fasteners (24x)
4. Torque to 3.5 Nm
5. Verify gap around spinner

## Verification

- [ ] Spinner aligned and installed
- [ ] All fasteners torqued
- [ ] Gap uniform (5 mm ±1 mm)
