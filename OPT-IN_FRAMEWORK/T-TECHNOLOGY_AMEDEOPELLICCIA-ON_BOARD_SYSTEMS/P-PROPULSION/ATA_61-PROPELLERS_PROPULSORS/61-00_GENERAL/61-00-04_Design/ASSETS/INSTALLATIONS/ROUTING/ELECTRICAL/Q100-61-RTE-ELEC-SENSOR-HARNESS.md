# Q100-61-RTE-ELEC-SENSOR-HARNESS — Sensor Harness Routing

## Overview

Defines the routing for temperature, speed, and position sensors.

## Sensors Included

| Sensor | Quantity | Type |
|--------|----------|------|
| Motor temperature | 6 | PT1000 |
| Bearing temperature | 2 | PT1000 |
| Gearbox temperature | 4 | Thermocouple |
| Speed/position | 1 | Resolver |
| Vibration | 2 | Accelerometer |

## Harness Construction

| Parameter | Value |
|-----------|-------|
| Conductors | Twisted shielded pairs |
| Shield | Overall braid |
| Jacket | Silicone, flexible |
| Breakouts | Per sensor location |

## Routing Requirements

- Separate from power by 100mm
- Avoid heat sources
- Use strain relief at connectors
- Route through conduit where exposed
