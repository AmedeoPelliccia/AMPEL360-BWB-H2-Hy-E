# Q100-61-INST-PROC-MOTOR-INSTALL — Master Procedure

## 1. Purpose

This procedure provides instructions for installing the electric motor into the nacelle and coupling to the reduction gearbox.

## 2. Prerequisites

- [ ] Gearbox installed and inspected
- [ ] Motor pre-installation inspection complete
- [ ] Nacelle structure prepared
- [ ] Cooling system ready for connection

## 3. Safety Requirements

### Hazards

| Hazard | Risk | Control |
|--------|------|---------|
| Heavy lift | Crushing | Lift equipment, trained personnel |
| Pinch points | Injury | Guards, awareness |
| Electrical | Shock | Lockout/tagout |

### PPE Required

- Safety glasses
- Steel-toe boots
- Cut-resistant gloves

## 4. Tools Required

| Tool | Description |
|------|-------------|
| Q100-61-TOOL-003 | Motor alignment fixture |
| Laser alignment system | ±0.001 mm resolution |
| Torque wrenches | 20-60 Nm range |
| Dial indicators | 0.01 mm resolution |

## 5. Procedure Steps

### Step 1: Preparation
- Verify gearbox position and condition
- Set up alignment equipment
- Stage motor for lifting

### Step 2: Alignment Setup
- Install dial indicators on gearbox output
- Position motor approximately
- Perform rough alignment check

### Step 3: Coupling
- Apply coupling grease to splines
- Engage motor spline with gearbox
- Verify full spline engagement

### Step 4: Fastening
- Install motor mount fasteners
- Torque in cross pattern
- 50% → 80% → 100% passes

### Step 5: Verification
- Final laser alignment check
- Record alignment values
- Connect cooling and electrical

## 6. Acceptance Criteria

| Parameter | Limit |
|-----------|-------|
| Angular misalignment | ≤0.5 mrad |
| Parallel offset | ≤0.05 mm |
| Fastener torque | 55 Nm ±5% |
