# Step 06 — Connection

## Purpose

Connect all electrical, cooling, and lubrication systems between the propulsor and pylon.

## Safety Warnings

⚠️ **WARNING**: Verify electrical systems are de-energized (lockout active).

⚠️ **WARNING**: Depressurize fluid systems before connecting.

⚠️ **CAUTION**: Use only approved fluids and lubricants.

## Tools Required

- Connector wrenches (for MIL-DTL-38999)
- Quick-disconnect tools
- Torque wrench (small range)
- Clean rags
- Fluid catch containers

## Parts/Materials Required

| Item | Description | Qty |
|------|-------------|-----|
| Lubricant | MIL-PRF-81309 | As req'd |
| O-rings | Per fluid QD kit | As req'd |
| Caps | Protective, various | Retain |

## Instructions

### 6.1 Electrical Power Umbilical

1. Remove protective caps from propulsor and pylon connectors
2. Inspect connector pins/sockets for damage
3. Verify connector alignment marks
4. Apply light film of connector lubricant to O-ring
5. Align and mate connector straight-in (no rotation)
6. Thread coupling nut hand-tight
7. Torque coupling nut to 3 Nm
8. Verify backshell is secure
9. Apply moisture seal around connector (if specified)

### 6.2 Electrical Control Umbilical

1. Remove protective caps
2. Inspect connector for bent pins or debris
3. Clean connector faces with IPA if needed
4. Mate connector and thread coupling nut
5. Torque coupling nut to 2 Nm
6. Verify cable strain relief is secure

### 6.3 Cooling System Quick-Disconnects

1. Remove protective caps from QDs
2. Inspect O-rings—replace if damaged
3. Clean male QD surfaces
4. Align QD halves (note flow direction)
5. Push QD halves together until click is heard
6. Verify locking collar is engaged
7. Repeat for return line
8. Do NOT pressurize until Step 7 verification

### 6.4 Lubrication System Quick-Disconnect

1. Remove protective caps
2. Inspect O-ring—replace if damaged
3. Clean surfaces
4. Mate QD until locked
5. Verify connection

### 6.5 Cable Routing and Support

1. Route cables through designated paths
2. Secure cables at all clamp locations
3. Verify minimum bend radius maintained (150mm for power, 75mm for control)
4. Verify no chafing points
5. Install cable ties at specified intervals
6. Apply cable ID labels

### 6.6 Fluid Line Routing

1. Route cooling and lube lines per drawing
2. Secure at clamp locations
3. Verify no kinks or tight bends
4. Verify thermal clearances maintained
5. Install line ID labels

## Verification

- [ ] Power umbilical connected and torqued
- [ ] Control umbilical connected and torqued
- [ ] Cooling supply QD connected and locked
- [ ] Cooling return QD connected and locked
- [ ] Lube supply QD connected and locked
- [ ] All cables routed and clamped
- [ ] All fluid lines routed and clamped
- [ ] All ID labels installed
- [ ] No visible damage or chafing

## Notes

- Retain all protective caps for future use
- If any connector shows damage, do not install—report to engineering
- Photograph all connections for records
