# Step 01 — Blade Inspection

## Purpose

Inspect all fan blades before installation.

## Instructions

1. Verify blade serial numbers match work order
2. Inspect each blade for damage:
   - Leading edge nicks
   - Erosion
   - Cracks
   - Root damage
3. Verify blade moment weights are matched
4. Record inspection results

## Verification

- [ ] All blades identified and inspected
- [ ] No damage found (or documented)
- [ ] Moment weights within tolerance
