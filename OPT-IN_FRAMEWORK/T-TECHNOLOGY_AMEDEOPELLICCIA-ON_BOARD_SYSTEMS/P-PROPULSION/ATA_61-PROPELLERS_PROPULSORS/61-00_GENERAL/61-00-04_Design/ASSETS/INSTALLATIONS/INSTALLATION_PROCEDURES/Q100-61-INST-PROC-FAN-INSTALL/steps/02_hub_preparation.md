# Step 02 — Hub Preparation

## Purpose

Prepare hub and install on gearbox output shaft.

## Instructions

1. Inspect hub spline for damage
2. Apply grease to hub spline
3. Position hub on output shaft
4. Engage splines carefully
5. Install retention nut and torque

## Verification

- [ ] Splines inspected and greased
- [ ] Hub fully engaged on shaft
- [ ] Retention nut torqued (450 Nm)
