# Q100-61-INST-PROC-CONTROLLER-INSTALL — Master Procedure

## 1. Purpose

Install the motor controller into the nacelle equipment bay.

## 2. Prerequisites

- [ ] Nacelle equipment bay prepared
- [ ] Controller pre-installation inspection complete
- [ ] Cooling system ready
- [ ] Power cables routed

## 3. Safety Requirements

⚠️ **WARNING**: High voltage equipment (800 VDC). Follow lockout/tagout.

## 4. Procedure Summary

1. Install controller on mounting rails
2. Connect cooling system
3. Connect DC power input
4. Connect AC power output
5. Connect control signals
6. Verify EMI grounding
7. Complete checks

## 5. Acceptance Criteria

| Parameter | Limit |
|-----------|-------|
| Mounting secure | No movement |
| Cooling flow | ≥15 LPM |
| Insulation resistance | ≥50 MΩ |
| EMI ground impedance | ≤10 mΩ |
