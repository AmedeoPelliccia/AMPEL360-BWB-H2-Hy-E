# Q100-61-INST-PROC-MOTOR-INSTALL — Motor Installation Procedure

## Overview

This procedure covers the installation of the electric motor into the nacelle structure and coupling to the reduction gearbox.

- Motor positioning and mounting
- Motor-to-gearbox coupling
