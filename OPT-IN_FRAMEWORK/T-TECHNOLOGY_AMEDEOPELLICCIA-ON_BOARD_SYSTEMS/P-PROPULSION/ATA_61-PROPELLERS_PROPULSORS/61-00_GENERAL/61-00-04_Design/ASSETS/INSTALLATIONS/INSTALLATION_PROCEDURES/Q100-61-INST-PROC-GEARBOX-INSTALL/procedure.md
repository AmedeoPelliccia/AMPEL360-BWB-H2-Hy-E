# Q100-61-INST-PROC-GEARBOX-INSTALL — Master Procedure

## 1. Purpose

Install the reduction gearbox into the nacelle structure.

## 2. Prerequisites

- [ ] Nacelle structure prepared
- [ ] Gearbox pre-installation inspection complete
- [ ] Mount points verified

## 3. Procedure Summary

1. Stage gearbox on transport fixture
2. Rig for lifting
3. Position in nacelle
4. Install mount fasteners
5. Verify alignment and complete lube system prep

## 4. Acceptance Criteria

| Parameter | Limit |
|-----------|-------|
| Mount flatness | ≤0.1 mm |
| Fastener torque | Per torque table |
