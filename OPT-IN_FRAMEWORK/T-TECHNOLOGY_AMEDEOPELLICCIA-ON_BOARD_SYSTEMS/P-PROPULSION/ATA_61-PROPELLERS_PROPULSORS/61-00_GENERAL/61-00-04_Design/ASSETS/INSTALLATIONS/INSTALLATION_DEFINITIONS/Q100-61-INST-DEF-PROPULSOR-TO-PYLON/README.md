# Q100-61-INST-DEF-PROPULSOR-TO-PYLON — Propulsor to Pylon Installation Definition

## Overview

This definition specifies the interface and mounting requirements for installing the open-fan propulsor assembly onto the pylon structure. This is a critical structural interface supporting the full propulsive load transfer to the BWB airframe.

## Scope

- Forward and aft mount interfaces
- Thrust link attachments
- Electrical umbilical connections
- Fluid (cooling/lubrication) quick-disconnects
- Vibration isolation provisions

## Key Interfaces

| Interface | Type | Description |
|-----------|------|-------------|
| Forward Mount | Mechanical | Primary vertical load path |
| Aft Mount | Mechanical | Primary thrust reaction |
| Thrust Link | Mechanical | Lateral and thrust loads |
| Power Umbilical | Electrical | Main power connection |
| Control Umbilical | Electrical | FADEC and sensor signals |
| Cooling QD | Fluid | Motor cooling supply/return |
| Lube QD | Fluid | Gearbox lubrication |
