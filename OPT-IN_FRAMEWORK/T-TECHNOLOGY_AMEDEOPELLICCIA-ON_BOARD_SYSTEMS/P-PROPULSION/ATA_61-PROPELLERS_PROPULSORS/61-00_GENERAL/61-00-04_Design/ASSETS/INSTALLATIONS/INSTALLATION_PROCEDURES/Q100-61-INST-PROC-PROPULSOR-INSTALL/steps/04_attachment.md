# Step 04 — Attachment

## Purpose

Install all mechanical fasteners for the propulsor mount connections.

## Safety Warnings

⚠️ **WARNING**: Do not release crane until all fasteners are installed and hand-tight.

⚠️ **CAUTION**: Verify correct fastener part numbers before installation.

## Tools Required

- Fastener kit per BOM
- Socket wrenches
- Torque wrench (for hand-tight verification)
- Thread lubricant MIL-PRF-907
- Feeler gauges

## Parts Required

| Part Number | Description | Qty | Location |
|-------------|-------------|-----|----------|
| NAS6604-24 | Bolt, forward mount | 8 | Forward L/R |
| NAS6606-28 | Bolt, aft mount | 8 | Aft L/R |
| NAS6604-20 | Bolt, thrust link | 4 | Thrust links |
| AN960-816 | Washer | 20 | All bolts |
| MS21042-6 | Nut | 20 | All bolts |

## Instructions

### 4.1 Forward Mount Installation

1. Verify forward mount alignment
2. Apply thread lubricant to bolt threads
3. Install washers on bolts
4. Insert bolts through propulsor mount into pylon fittings
5. Install washers and nuts on back side
6. Hand-tighten all bolts (snug only)
7. Verify bolt engagement (minimum 3 threads showing)

### 4.2 Aft Mount Installation

1. Verify aft mount alignment
2. Apply thread lubricant to bolt threads
3. Install bolts with washers
4. Install washers and nuts
5. Hand-tighten all bolts
6. Verify bolt engagement

### 4.3 Thrust Link Installation

1. Position thrust links between propulsor and pylon brackets
2. Align thrust link clevises with mounting holes
3. Install bolts through clevises and brackets
4. Install washers and nuts
5. Hand-tighten all bolts

### 4.4 Gap and Alignment Check

1. Check gap between propulsor and pylon mounts with feeler gauge
2. Maximum gap: 0.1mm at any point
3. If gap exceeds limit, install shims as required
4. Record shim locations and thicknesses
5. Verify alignment within tolerance (see definition)

### 4.5 Release Crane

1. Verify all fasteners installed and hand-tight
2. Verify propulsor stable on mounts
3. Signal crane operator to slowly release tension
4. Observe for any movement or settling
5. Complete release of crane
6. Remove lift fixture
