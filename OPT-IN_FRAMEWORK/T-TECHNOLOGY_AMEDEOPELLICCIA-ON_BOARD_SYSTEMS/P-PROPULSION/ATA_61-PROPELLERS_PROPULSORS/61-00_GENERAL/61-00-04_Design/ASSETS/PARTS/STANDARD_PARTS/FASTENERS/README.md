# FASTENERS — Standard Parts

## Overview

This directory contains the index and specifications for standard aerospace fasteners used in ATA 61 propulsion system assemblies.

## Fastener Categories

| Category | Standards | Applications |
|----------|-----------|--------------|
| Bolts | AN3-AN20, NAS1303-1320 | Structural joints, flanges |
| Nuts | MS21042, AN363, AN365 | Bolt retention, self-locking |
| Screws | MS24693, AN526, AN507 | Panel attachment, access covers |
| Washers | AN960, AN970, NAS1149 | Load distribution, spacing |
| Rivets | MS20470, NAS1097 | Sheet metal joints |
| Pins | MS24665, AN416 | Alignment, locking |

## Material Specifications

- **Alloy Steel**: MIL-S-8879, Cadmium plated
- **Stainless Steel**: A-A-59441, CRES 300 series
- **Titanium**: MIL-T-9047, Ti-6Al-4V
- **Aluminum**: QQ-A-225
