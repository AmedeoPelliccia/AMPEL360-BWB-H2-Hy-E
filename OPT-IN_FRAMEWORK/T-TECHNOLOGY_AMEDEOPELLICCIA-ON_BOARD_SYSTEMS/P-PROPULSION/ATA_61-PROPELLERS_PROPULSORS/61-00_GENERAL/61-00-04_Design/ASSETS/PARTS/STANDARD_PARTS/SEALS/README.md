# SEALS — Standard Parts

## Overview

This directory contains the index and specifications for standard sealing elements used in ATA 61 propulsion system assemblies.

## Seal Categories

| Category | Standards | Applications |
|----------|-----------|--------------|
| O-Rings | AS568, MIL-PRF-83248 | Static and dynamic sealing |
| Gaskets | AMS 3195, MIL-G-21569 | Flange joints, covers |
| Lip Seals | MIL-S-8802 | Rotating shaft sealing |
| Face Seals | AS1895 | High-speed shaft sealing |
| Piston Seals | MIL-P-5514 | Hydraulic actuators |

## Material Specifications

- **Elastomers**: Fluorocarbon (FKM), Silicone, Nitrile (NBR)
- **PTFE**: Filled and unfilled grades
- **Metallic**: Spiral wound, C-rings

## Temperature Ranges

| Material | Min Temp | Max Temp |
|----------|----------|----------|
| FKM | -20°C | +200°C |
| Silicone | -60°C | +200°C |
| NBR | -40°C | +120°C |
| PTFE | -200°C | +260°C |
