# BEARINGS — Standard Parts

## Overview

This directory contains the index and specifications for standard bearings used in ATA 61 propulsion system assemblies.

## Bearing Categories

| Category | Standards | Applications |
|----------|-----------|--------------|
| Ball Bearings | ABEC 5/7, MIL-B-17931 | Motor shafts, gearbox |
| Roller Bearings | RBEC, ISO 492 | High load applications |
| Spherical Plain | MIL-B-81820, AS81820 | Mount linkages, articulating joints |
| Needle Bearings | INA, SKF standards | Planet gears, compact spaces |
| Angular Contact | ABEC 7, P4 precision | Main shafts, preloaded pairs |

## Material Specifications

- **Rings**: 52100 bearing steel, M50 tool steel
- **Rolling Elements**: 52100, ceramic (Si3N4)
- **Cages**: Bronze, steel, PEEK

## Lubrication

- Oil: MIL-PRF-23699
- Grease: MIL-PRF-23827
