# NACELLE_COMPONENTS — ATA 61 Parts

## Overview

This directory contains individual part definitions for nacelle system components used in the open-fan propulsor of the AMPEL360 BWB H2 Hy-E hybrid electric aircraft.

## Technical Overview

### Outer Barrel (Q100-61-PRT-NACELLE-OUTER-BARREL)

- **Material**: Carbon fiber reinforced polymer (CFRP) composite
- **Features**:
  - Aerodynamic external contour
  - Access panel cutouts
  - Lightning strike protection
  - Drainage provisions

### Inner Barrel (Q100-61-PRT-NACELLE-INNER-BARREL)

- **Material**: Composite with acoustic treatment
- **Features**:
  - Smooth internal flow path
  - Acoustic liner integration points
  - Thermal insulation

### Inlet Lip (Q100-61-PRT-NACELLE-INLET-LIP)

- **Material**: Aluminum alloy or titanium
- **Features**:
  - Optimized lip radius for flow efficiency
  - Anti-ice/de-ice system integration
  - Bird strike resistance
  - FOD tolerance

### Acoustic Liner (Q100-61-PRT-NACELLE-ACOUSTIC-LINER)

- **Material**: Perforated face sheet with honeycomb core
- **Features**:
  - Tuned acoustic impedance
  - Multi-degree-of-freedom (MDOF) design
  - Weather resistance
  - Easy replacement

### Thrust Reverser (Q100-61-PRT-NACELLE-THRUST-REVERSER)

- **Type**: Cascade or bucket reverser
- **Features**:
  - Actuation mechanism (hydraulic or electric)
  - Stow/deploy locking system
  - Blocker doors
  - Cascade vanes (if applicable)
