# CONNECTORS — Standard Parts

## Overview

This directory contains the index and specifications for standard electrical and fluid connectors used in ATA 61 propulsion system assemblies.

## Connector Categories

### Electrical Connectors

| Category | Standards | Applications |
|----------|-----------|--------------|
| Circular | MIL-DTL-38999 | Power, signal, data |
| Rectangular | MIL-DTL-83513 | High-density signal |
| High Power | SAE AS39029 | Motor power cables |
| Fiber Optic | MIL-DTL-83526 | High-speed data |
| RF/Coaxial | MIL-DTL-39012 | Sensor signals |

### Fluid Connectors

| Category | Standards | Applications |
|----------|-----------|--------------|
| AN Fittings | MIL-DTL-5541 | Fuel, oil, hydraulic |
| Quick Disconnect | SAE AS4395 | Coolant, service |
| Tube Fittings | MIL-DTL-18866 | Instrument lines |
| Hose Fittings | SAE AS1055 | Flexible connections |

## Material Specifications

- **Shells**: Aluminum, stainless steel, composite
- **Contacts**: Copper alloy, gold plated
- **Seals**: Silicone, fluorosilicone

## Environmental Ratings

- **Altitude**: 70,000 ft max
- **Temperature**: -65°C to +200°C
- **Vibration**: 20g, 10-2000 Hz
- **Fluid Resistance**: Per MIL-DTL specification
