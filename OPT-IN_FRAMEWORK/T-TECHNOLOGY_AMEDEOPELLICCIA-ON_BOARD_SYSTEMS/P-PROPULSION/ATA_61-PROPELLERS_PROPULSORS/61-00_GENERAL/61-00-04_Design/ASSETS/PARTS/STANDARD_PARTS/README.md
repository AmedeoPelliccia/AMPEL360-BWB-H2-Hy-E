# STANDARD_PARTS — ATA 61 Parts

## Overview

This directory contains catalogs and specifications for standard parts used in the propulsion system. Standard parts are commercially available components that conform to industry specifications and do not require custom design.

## Categories

### FASTENERS

Standard aerospace fasteners including:
- Bolts (MS, NAS, AN standards)
- Nuts (self-locking, floating, anchor)
- Screws (machine, self-tapping, panel)
- Washers (flat, spring, tab)
- Rivets (solid, blind, hi-lok)
- Pins (cotter, roll, spring)

### BEARINGS

Standard rolling element bearings:
- Ball bearings (deep groove, angular contact)
- Roller bearings (cylindrical, spherical, tapered)
- Needle bearings
- Spherical plain bearings
- Linear bearings

### SEALS

Standard sealing elements:
- O-rings (AS568, metric)
- Gaskets (metallic, non-metallic)
- Lip seals (rotary shaft seals)
- Face seals
- Piston seals
- Rod seals

### CONNECTORS

Standard electrical and fluid connectors:
- Electrical connectors (MIL-DTL-38999, etc.)
- Fluid quick-disconnects
- Pipe fittings (AN, JIC, SAE)
- Tube fittings (AN, MS)
- Hose fittings

## Specification Standards

All standard parts must conform to one or more of:

| Standard | Description |
|----------|-------------|
| AN | Air Force-Navy Aeronautical Standard |
| MS | Military Standard |
| NAS | National Aerospace Standard |
| AS | Aerospace Standard (SAE) |
| MIL-DTL | Military Detail Specification |

## Traceability

Standard parts are tracked via:
- Part number (manufacturer or specification)
- Quantity per assembly
- Location references (assembly callouts)
- Certification requirements (if applicable)
