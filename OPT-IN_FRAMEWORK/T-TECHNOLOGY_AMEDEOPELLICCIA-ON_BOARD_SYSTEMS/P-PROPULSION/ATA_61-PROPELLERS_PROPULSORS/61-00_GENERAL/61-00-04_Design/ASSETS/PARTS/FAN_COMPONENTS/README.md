## Technical Overview

### Fan Blade (Q100-61-PRT-FAN-BLADE)

- **Material**: Carbon fiber reinforced polymer (CFRP) composite
- **Count per fan**: TBD (typically 12-18 for open-fan designs)
- **Features**: 
  - Swept leading edge for noise reduction
  - Variable pitch root interface
  - Erosion-resistant leading edge protection

### Fan Hub (Q100-61-PRT-FAN-HUB)

- **Material**: Titanium alloy (Ti-6Al-4V)
- **Features**:
  - Blade retention slots
  - Pitch bearing housings
  - Spline coupling interface to gearbox

### Fan Spinner (Q100-61-PRT-FAN-SPINNER)

- **Material**: Aluminum alloy or composite
- **Features**:
  - Aerodynamic shaping for flow guidance
  - De-icing system integration
  - Quick-release attachment

### Blade Retention (Q100-61-PRT-FAN-RETENTION)

- **Material**: High-strength steel
- **Features**:
  - Dovetail or fir-tree root retention
  - Positive locking mechanism
  - Fatigue-rated design

### Pitch Mechanism (Q100-61-PRT-FAN-PITCH-MECHANISM)

- **Type**: Variable pitch actuation system
- **Features**:
  - Hydraulic or electric actuation
  - Pitch angle feedback sensors
  - Emergency feathering capability
