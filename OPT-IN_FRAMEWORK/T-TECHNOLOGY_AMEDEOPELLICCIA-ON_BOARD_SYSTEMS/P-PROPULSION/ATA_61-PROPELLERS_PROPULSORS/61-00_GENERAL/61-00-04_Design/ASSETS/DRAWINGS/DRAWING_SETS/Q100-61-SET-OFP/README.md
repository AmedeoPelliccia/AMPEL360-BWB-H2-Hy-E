# Q100-61-SET-OFP — Open Fan Propulsor Drawing Set

## Overview

This drawing set contains all engineering drawings for the Open Fan Propulsor (OFP) system components. The open-fan propulsor is a key technology for the AMPEL360-BWB-H2-Hy-E hybrid aircraft, providing high bypass ratios and improved fuel efficiency.

## Scope

**ATA Sections**: 61-10, 61-20

### Included Subsystems

- Fan blades (composite and metallic variants)
- Hub assembly
- Nacelle structure
- Pitch control mechanism
- Blade retention system
- De-icing provisions

### Excluded

- Electric motor components (see Q100-61-SET-EMD)
- Mounting structure (see Q100-61-SET-MNT)
- System integration drawings (see Q100-61-SET-FPS)

## Drawing Categories

| Type | Description | Typical Content |
|------|-------------|-----------------|
| DRW  | Engineering Drawing | Detailed part/assembly drawings |
| SCH  | Schematic | Pitch control system schematics |
| ICD  | Interface Control | Hub-to-motor interface |
| INST | Installation | Blade installation procedures |
