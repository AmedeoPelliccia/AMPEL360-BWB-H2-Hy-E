# Q100-61-SET-MNT — Mounting System Drawing Set

## Overview

This drawing set contains engineering drawings for the Mounting System (MNT), covering propulsor mounting, pylon structure, and structural integration for the AMPEL360-BWB-H2-Hy-E aircraft.

## Scope

**ATA Sections**: 61-50

### Included Subsystems

- Engine mounts and brackets
- Pylon structure
- Vibration isolation systems
- Structural attachments
- Load transfer elements

### Excluded

- Propulsor components (see Q100-61-SET-OFP, Q100-61-SET-EMD)
- Airframe primary structure (see ATA 53/57)

## Drawing Categories

| Type | Description | Typical Content |
|------|-------------|-----------------|
| DRW  | Engineering Drawing | Mount assemblies, brackets |
| SCH  | Schematic | Load path diagrams |
| ICD  | Interface Control | Pylon-to-airframe interface |
| INST | Installation | Mount installation procedures |

## Naming Convention

```
Q100-61-DRW-MNT-[COMPONENT]-[SEQ].[ext]
```

Examples:
- `Q100-61-DRW-MNT-MOUNT-001.svg`
- `Q100-61-DRW-MNT-PYLON-001.svg`
