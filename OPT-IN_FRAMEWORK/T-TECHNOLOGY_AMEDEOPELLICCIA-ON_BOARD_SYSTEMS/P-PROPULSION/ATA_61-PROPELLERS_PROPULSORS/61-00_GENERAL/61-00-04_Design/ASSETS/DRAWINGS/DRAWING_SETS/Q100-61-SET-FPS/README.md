# Q100-61-SET-FPS — Full Propulsor System Drawing Set

## Overview

This drawing set contains system-level engineering drawings for the Full Propulsor System (FPS), covering complete assembly, system integration, and interface control for the AMPEL360-BWB-H2-Hy-E aircraft propulsion system.

## Scope

**ATA Sections**: 61-00, 61-60

### Included Subsystems

- Complete propulsor assembly
- System integration drawings
- Interface control documents
- System schematics
- Overall installation drawings

### Excluded

- Individual component drawings (see component-specific sets)

## Drawing Categories

| Type | Description | Typical Content |
|------|-------------|-----------------|
| DRW  | Engineering Drawing | Assembly drawings |
| SCH  | Schematic | System-level schematics |
| ICD  | Interface Control | System interface definitions |
| INST | Installation | System installation drawings |
| DIAG | Diagram | Block diagrams, flow diagrams |

## Naming Convention

```
Q100-61-DRW-FPS-[CATEGORY]-[SEQ].[ext]
```

Examples:
- `Q100-61-DRW-FPS-ASSY-001.svg` (Assembly)
- `Q100-61-SCH-FPS-SYS-001.svg` (System schematic)
- `Q100-61-ICD-FPS-INT-001.svg` (Interface control)
