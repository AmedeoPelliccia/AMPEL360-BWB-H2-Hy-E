# DRAWING_STANDARDS — ATA 61 Propellers/Propulsors

## Overview

This directory contains drawing standards and procedures for ATA 61 engineering drawings. All drawings must comply with these standards to ensure consistency, traceability, and certification readiness.

| Document | Title | Description |

## Applicable Standards

These documents implement requirements from:

- [ASME Y14.100](https://www.asme.org/) — Engineering Drawing Practices
- [ISO 128](https://www.iso.org/) — Technical Drawings — General Principles
- [AS9100D](https://www.sae.org/) — Quality Management Systems — Aerospace
- AMPEL360 Documentation Standards

## Usage

1. Review applicable standards before creating new drawings
2. Use standard templates from [TEMPLATES/](../TEMPLATES/)
3. Follow naming conventions for all files
4. Complete approval workflow before release
