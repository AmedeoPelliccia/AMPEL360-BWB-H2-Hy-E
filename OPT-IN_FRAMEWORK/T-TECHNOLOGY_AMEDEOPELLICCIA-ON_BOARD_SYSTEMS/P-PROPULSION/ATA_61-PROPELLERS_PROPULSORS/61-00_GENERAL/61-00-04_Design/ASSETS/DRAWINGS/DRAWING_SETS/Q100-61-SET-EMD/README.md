# Q100-61-SET-EMD — Electric Motor Drive Drawing Set

## Overview

This drawing set contains all engineering drawings for the Electric Motor Drive (EMD) system components. The electric motor drive is the primary propulsion power source for the AMPEL360-BWB-H2-Hy-E hybrid aircraft, powered by H₂ PEM fuel-cells.

## Scope

**ATA Sections**: 61-30

### Included Subsystems

- Electric motor (permanent magnet synchronous motor)
- Motor controller / inverter
- Power electronics
- Motor cooling system
- Sensors and instrumentation

### Excluded

- Fan blades and hub (see Q100-61-SET-OFP)
- Mounting structure (see Q100-61-SET-MNT)
- Energy storage (see ATA 80)

## Drawing Categories

| Type | Description | Typical Content |
|------|-------------|-----------------|
| DRW  | Engineering Drawing | Motor assembly, rotor, stator |
| SCH  | Schematic | Power and control schematics |
| ICD  | Interface Control | Motor-to-hub, electrical interfaces |
| INST | Installation | Motor installation procedures |
