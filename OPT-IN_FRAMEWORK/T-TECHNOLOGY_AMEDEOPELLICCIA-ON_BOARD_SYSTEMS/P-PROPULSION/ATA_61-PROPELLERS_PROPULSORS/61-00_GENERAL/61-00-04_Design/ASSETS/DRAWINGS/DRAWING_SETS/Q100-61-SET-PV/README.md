# Q100-61-SET-PV — Propeller Variants Drawing Set

## Overview

This drawing set contains engineering drawings for Propeller Variants (PV), documenting different blade configurations, materials, and performance specifications for the AMPEL360-BWB-H2-Hy-E aircraft.

## Scope

**ATA Sections**: 61-40

### Included Subsystems

- Standard blade variants
- High-efficiency blade configurations
- Material specification variants (composite, metallic)
- Performance-optimized designs
- Regional/mission-specific configurations

### Excluded

- Fan hub and nacelle (see Q100-61-SET-OFP)
- Motor components (see Q100-61-SET-EMD)

## Drawing Categories

| Type | Description | Typical Content |
|------|-------------|-----------------|
| DRW  | Engineering Drawing | Blade profiles, dimensions |
| DIAG | Diagram | Performance comparison charts |
| ICD  | Interface Control | Blade-to-hub interface specifications |

## Naming Convention

```
Q100-61-DRW-PV-[VARIANT]-[SEQ].[ext]
```

Examples:
- `Q100-61-DRW-PV-STD-001.svg` (Standard variant)
- `Q100-61-DRW-PV-HE-001.svg` (High-efficiency variant)
- `Q100-61-DRW-PV-COMP-001.svg` (Composite variant)
