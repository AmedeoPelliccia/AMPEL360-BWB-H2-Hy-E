# DRAWING_TYPES — ATA 61 Drawing Type Definitions

## Overview

This directory contains definitions for each drawing type used in ATA 61 engineering documentation. Each type has specific requirements, purposes, and content guidelines.

## Available Types

| Type | Code | Description |
|------|------|-------------|
| [Engineering Drawing](./Q100-61-TYPE-DRW.md) | DRW | Detailed part and assembly drawings |
| [Schematic](./Q100-61-TYPE-SCH.md) | SCH | Electrical, hydraulic, pneumatic diagrams |
| [Interface Control Drawing](./Q100-61-TYPE-ICD.md) | ICD | Interface definitions between systems |
| [Installation Drawing](./Q100-61-TYPE-INST.md) | INST | Installation and routing drawings |
| [Diagram](./Q100-61-TYPE-DIAG.md) | DIAG | Block diagrams, flow diagrams |

## Type Selection Guide

| Need | Recommended Type |
|------|------------------|
| Part dimensions and tolerances | DRW |
| Assembly instructions | DRW |
| Wiring/piping layout | SCH |
| Control logic | SCH |
| System-to-system interface | ICD |
| Component mounting location | INST |
| System overview | DIAG |
| Data flow | DIAG |
