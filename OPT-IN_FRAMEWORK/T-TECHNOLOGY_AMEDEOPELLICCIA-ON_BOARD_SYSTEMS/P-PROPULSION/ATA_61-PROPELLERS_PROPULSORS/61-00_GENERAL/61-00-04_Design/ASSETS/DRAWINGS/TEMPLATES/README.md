# TEMPLATES — ATA 61 Drawing Templates

## Overview

This directory contains standard drawing templates for ATA 61 engineering drawings. All drawings should be created using these templates to ensure consistency.

## Template Content

Each template includes:

- Drawing border with fold marks
- Title block area
- Revision block area
- Grid reference system
- Zone markings
- Scale reference

## Usage

1. Copy the appropriate template for your drawing size
2. Rename following the naming convention
3. Fill in the title block information
4. Create your drawing content
5. Update revision block as needed

## Customization

Templates may be customized for specific needs, but must retain:
- AMPEL360 branding
- Required title block fields
- Revision tracking area
