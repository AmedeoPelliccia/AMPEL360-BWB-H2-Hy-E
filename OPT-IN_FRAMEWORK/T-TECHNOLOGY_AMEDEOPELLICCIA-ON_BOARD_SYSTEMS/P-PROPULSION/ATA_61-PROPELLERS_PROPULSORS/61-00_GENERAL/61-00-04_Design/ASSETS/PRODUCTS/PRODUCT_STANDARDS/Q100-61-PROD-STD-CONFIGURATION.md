# Q100-61-PROD-STD-CONFIGURATION — Configuration Management Standard

## 1. Purpose

This document defines the configuration management standard for Q100 program ATA 61 products.

## 2. Configuration Items

### 2.1 Baseline Management

- All products shall have a defined configuration baseline
- Baselines are identified with revision numbers (R01, R02, etc.)
- Master index tracks all configurations

### 2.2 Configuration Control

- All changes require Engineering Change Order (ECO)
- Configuration Control Board (CCB) approval required
- Full traceability maintained

## 3. Documentation

- Each configuration documented in YAML format
- Effectivity matrix maintained for each baseline
- Customer configurations tracked separately
