# OPTIONS — Product Options

**Purpose**: This directory contains the optional feature packages available for the ATA 61 propulsion system products.

## Available Options

| Option ID | Name | Description |
|-----------|------|-------------|
| Q100-61-OPT-HIGH-POWER | High Power | Increased motor power for MTOW variants |
| Q100-61-OPT-EXTENDED-RANGE | Extended Range | Optimized for long-range cruise efficiency |
| Q100-61-OPT-REDUCED-NOISE | Reduced Noise | Enhanced acoustic treatment |
| Q100-61-OPT-SAF-OPTIMIZED | SAF Optimized | Optimized for SAF fuel operation |

## Option Selection Process

1. Customer specifies desired options
2. Compatibility check with baseline and variants
3. Configuration generation with selected options
4. BOM update with option-specific parts
5. Documentation update

## Option Compatibility

Not all options are compatible with all variants. See individual option files for compatibility information.
