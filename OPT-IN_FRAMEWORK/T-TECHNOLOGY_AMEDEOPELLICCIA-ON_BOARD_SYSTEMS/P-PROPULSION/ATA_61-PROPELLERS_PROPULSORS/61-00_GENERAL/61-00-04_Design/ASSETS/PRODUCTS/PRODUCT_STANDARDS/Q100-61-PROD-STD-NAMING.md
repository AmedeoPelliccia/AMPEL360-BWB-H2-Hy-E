# Q100-61-PROD-STD-NAMING — Product Naming Convention

## 1. Purpose

This document defines the product naming convention for the Q100 program ATA 61 propulsion system.

## 2. Naming Pattern

```
Q100-61-[TYPE]-[PRODUCT/SYSTEM]-[VARIANT]
```

## 3. Type Codes

| Code | Meaning | Description |
|------|---------|-------------|
| PROD | Product Definition | Core product definition |
| VAR | Product Variant | Position/application variants |
| CFG | Configuration | Configuration baselines and options |
| OPT | Option | Customer-selectable options |
| BOM | Bill of Materials | Material and component lists |
| SPEC | Specification | Performance/environmental specs |
| CERT | Certification | Certification evidence |
| LC | Lifecycle | Lifecycle management data |
| STD | Standard | Product standards and procedures |

## 4. Examples

- `Q100-61-PROD-PROPULSOR-SYSTEM` — Top-level product
- `Q100-61-VAR-PROPULSOR-LH` — Left-hand variant
- `Q100-61-CFG-BASELINE-R01` — Baseline configuration
- `Q100-61-OPT-HIGH-POWER` — High power option
- `Q100-61-BOM-OPEN-FAN-UNIT` — Bill of materials
- `Q100-61-SPEC-PERF-THRUST` — Thrust specification
