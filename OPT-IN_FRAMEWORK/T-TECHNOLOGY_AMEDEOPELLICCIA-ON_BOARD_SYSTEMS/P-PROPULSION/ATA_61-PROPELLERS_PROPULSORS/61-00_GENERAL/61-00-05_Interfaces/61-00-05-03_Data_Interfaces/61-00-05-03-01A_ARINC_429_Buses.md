# 61-00-05-03-01A - ARINC 429 Buses Interface

**Document ID:** 61-00-05-03-01A

## 1. Purpose

This document defines the ARINC 429 data bus interface for propulsor health monitoring data, maintenance data, and non-critical parameter transmission to the aircraft avionics systems.

---

## 2. Scope

This specification covers:
- ARINC 429 physical layer specifications
- Data word formats and label definitions
- Bus loading and timing requirements
- Redundancy and fault tolerance
- Integration with Central Maintenance Computer (CMC)

### 2.1 Applicable Units
- All four Q100 propulsor units
- Dual redundant ARINC 429 buses per propulsor

### 4.3 ARINC 429 Word Format

Standard ARINC 429 32-bit word structure:
```
Bit 32 (MSB): Parity (odd)
Bits 31-30: Sign/Status Matrix (SSM)
Bits 29-11: Data (19 bits)
Bits 10-9: Source/Destination Identifier (SDI)
Bits 8-1: Label (Octal)
```
