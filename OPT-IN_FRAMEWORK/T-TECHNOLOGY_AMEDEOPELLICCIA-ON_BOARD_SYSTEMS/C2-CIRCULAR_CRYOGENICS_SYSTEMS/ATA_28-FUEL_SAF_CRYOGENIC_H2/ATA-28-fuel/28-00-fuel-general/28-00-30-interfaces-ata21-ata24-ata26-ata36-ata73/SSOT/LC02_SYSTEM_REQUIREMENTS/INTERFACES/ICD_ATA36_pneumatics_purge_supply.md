# ICD — ATA 36 Pneumatics Purge Supply Interface

## 1. Purpose

This Interface Control Document defines the interface between ATA 28 Fuel System and ATA 36 Pneumatic System for inert gas purge supply.

## 2. Interface Description

| Interface | Direction | Description |
|-----------|-----------|-------------|
| N2 Purge Supply | ATA 36 → ATA 28 | Nitrogen for fuel system inerting |
| Purge Pressure | ATA 36 → ATA 28 | Regulated purge gas pressure |
| Purge Valve Control | ATA 28 → ATA 36 | Purge valve open/close commands |

## 3. Performance Requirements

| Parameter | Value | Units |
|-----------|-------|-------|
| N2 Purity | ≥ 99.5 | % |
| Supply Pressure | 200-400 | kPa |
| Flow Rate | 0-100 | kg/h |
| Temperature | -40 to +60 | °C |
