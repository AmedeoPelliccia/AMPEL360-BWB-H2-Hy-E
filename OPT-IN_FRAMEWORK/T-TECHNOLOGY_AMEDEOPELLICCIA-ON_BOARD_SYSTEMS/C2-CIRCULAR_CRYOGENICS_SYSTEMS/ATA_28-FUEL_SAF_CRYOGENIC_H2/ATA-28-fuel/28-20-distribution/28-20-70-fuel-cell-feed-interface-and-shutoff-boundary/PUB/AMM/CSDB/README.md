# CSDB — Common Source Database

## 28-20-70

This directory contains S1000D-compliant data modules for ATA 28 sub-subject 28-20-70.

## Structure

| Directory | Content |
|-----------|---------|
| DM/ | Data Modules (description, procedures, fault isolation) |
| PM/ | Publication Modules |
| DML/ | Data Module Lists |
| ICN/ | Information Control Numbers (graphics) |
| BREX/ | Business Rules Exchange |
| COMMON/ | Common elements (warnings, cautions) |
| APPLICABILITY/ | Applicability cross-reference |

## Data Module Naming Convention

```
DMC-AMPEL360AT-28-20-70-XXXA-A-A_XXX_00_EN-US_001-00.XML
```

Where XXX indicates the info code:
- 040A: Description/Overview
- 520A: Test/Checkout
- 720A: Removal/Installation
- 730A: Fault Isolation
- 940A: Software Configuration
