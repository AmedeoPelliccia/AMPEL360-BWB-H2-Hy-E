## 1. Overview

The Regional OFEC Aggregator (R-OFEC) aggregates envelope data from multiple aircraft and ground stations within a region, providing fleet-wide analytics and uplink to fleet core.

---

## 2. Components

| Component | Purpose |
|-----------|---------|
| Multi-Aircraft Aggregation | Combine data from multiple aircraft |
| Fleet Analytics | Generate regional statistics |
| Uplink to Fleet Core | Forward aggregated data |

---

## 3. Capabilities

- Aggregate data from 50+ aircraft per region
- Generate real-time fleet statistics
- Identify fleet-wide trends and anomalies
- Forward summary data to fleet core
