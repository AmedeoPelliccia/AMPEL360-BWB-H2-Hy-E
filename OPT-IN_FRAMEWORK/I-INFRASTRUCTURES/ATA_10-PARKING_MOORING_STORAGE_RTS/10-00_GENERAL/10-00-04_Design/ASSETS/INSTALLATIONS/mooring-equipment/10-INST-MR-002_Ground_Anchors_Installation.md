# 10-INST-MR-002 - Ground Anchors Installation

## 1. Purpose

Installation procedures for ground anchor systems used to secure mooring and tiedown equipment for the AMPEL360-BWB-H2 aircraft.

## 2. Scope

- Permanent ground anchor installation in concrete surfaces
- Portable anchor systems for unprepared surfaces
- Load capacity verification and testing
- Soil condition requirements

**Effectivity**: All ground facilities supporting AMPEL360-BWB-H2 operations

## 3. Applicable Documents

- **ACI 318** - Building Code Requirements for Structural Concrete
- **ASTM F1554** - Standard Specification for Anchor Bolts
- **MIL-STD-970** - Tiedown provisions for aircraft

## 4. Safety Precautions

⚠️ **WARNINGS**
- Ground anchors must be load-tested before operational use
- Never exceed rated capacity of anchor system
- Soil conditions significantly affect portable anchor capacity
- Failed anchor may cause whiplash hazard to personnel

## 5. Anchor Types and Specifications

### 5.1 Permanent Concrete Anchors

**Type**: Cast-in-place anchor bolts or post-installed expansion anchors
**Load Capacity**: 20,000 lb minimum per anchor
**Material**: ASTM F1554 Grade 105 or higher
**Installation**: Embedded minimum 12" in 4,000 psi concrete
**Spacing**: Minimum 5 ft between anchors for BWB configuration

### 5.2 Portable Screw Anchors

**Type**: Helical screw anchor with drive head
**Load Capacity**: 15,000 lb in competent soil
**Installation Depth**: 5 ft minimum
**Soil Requirements**: Clay or dense sand, no rock or groundwater

### 5.3 Mobile Weight Anchors

**Type**: Equipment-based ballast system
**Load Capacity**: 12,000 lb minimum
**Weight**: 15,000 lb minimum dead weight
**Application**: Temporary operations, paved surfaces

## 6. Installation Procedures

### 6.1 Permanent Concrete Anchor Installation

#### Cast-in-Place Method

1. **Prepare anchor layout**
   - Mark anchor locations per BWB mooring diagram (ref 10-INST-MR-003)
   - Minimum 5 ft spacing for multiple anchors
   - Verify no interference with underground utilities

2. **Install anchor template**
   - Position template at marked locations
   - Level and align with aircraft parking position
   - Secure template to prevent movement during concrete pour

3. **Place concrete**
   - Minimum 4,000 psi compressive strength
   - Minimum 12" embedment depth for anchor bolts
   - Vibrate concrete around anchors to eliminate voids
   - Cure per ACI 318 requirements (minimum 7 days)

4. **Remove template and finish**
   - Remove template after concrete cure
   - Clean anchor threads
   - Apply protective coating to exposed portions
   - Install protective caps when not in use

#### Post-Installed Expansion Anchor Method

1. **Drill hole in existing concrete**
   - Drill diameter per anchor manufacturer specifications
   - Minimum 12" depth in 4,000 psi concrete
   - Clean hole thoroughly (compressed air, wire brush)

2. **Install expansion anchor**
   - Insert anchor into prepared hole
   - Torque to manufacturer specification
   - Verify expansion mechanism engaged

3. **Load test anchor**
   - Apply 150% of design load for 5 minutes
   - Inspect for movement or concrete cracking
   - Document test results

### 6.2 Portable Screw Anchor Installation

1. **Verify soil conditions**
   - Perform soil survey or probe test
   - Confirm soil load-bearing capacity (min 2,000 psf)
   - Check for groundwater or rock (not suitable)

2. **Install screw anchor**
   - Position anchor at marked location
   - Drive anchor to 5 ft depth minimum
   - Monitor torque during installation (indicates soil capacity)
   - Anchor should rotate smoothly with increasing resistance

3. **Load test**
   - Apply test load equal to 125% of expected working load
   - Measure anchor movement (max 0.5" acceptable)
   - If excessive movement, relocate or add additional anchors

4. **Mark and document**
   - Mark anchor location for future reference
   - Document installation torque and test results
   - Install protective cap or marker

### 6.3 Mobile Weight Anchor Setup

1. **Position anchor equipment**
   - Place on level, stable surface
   - Verify weight certification (min 15,000 lb)
   - Ensure equipment stability (wide base, low CG)

2. **Connect mooring equipment**
   - Attach mooring line to anchor attachment point
   - Verify connection security
   - Check for proper alignment with aircraft

3. **Safety verification**
   - Ensure anchor cannot tip or slide under load
   - Establish exclusion zone around anchor
   - Monitor anchor during operations

## 7. Load Testing Requirements

### 7.1 Acceptance Testing (New Installations)

- **Test Load**: 150% of design working load
- **Duration**: 5 minutes minimum
- **Acceptance**: No movement >0.25", no cracking, no deformation
- **Frequency**: Before first use

### 7.2 Periodic Testing

- **Test Load**: 125% of design working load
- **Frequency**: Annual for permanent anchors, before each use for portable
- **Documentation**: Test report with date, load, results

### 7.3 Visual Inspection

- Before each use: Check for visible damage, corrosion, loose hardware
- Annual: Detailed inspection including concrete condition, thread condition

## 8. H2/BWB Considerations

### 8.1 BWB Configuration

- **Anchor Spacing**: Wide wingspan requires anchors spaced farther apart (min 5 ft)
- **Load Distribution**: Multiple anchors may be required for symmetric load distribution
- **Clearance**: Ensure anchors do not interfere with aircraft maneuvering

### 8.2 H2 Safety

- **Bonding**: All metallic anchors must be electrically bonded to aircraft ground system
- **Distance from H2 Systems**: Minimum 15 ft from H2 vent outlets
- **Spark Prevention**: Use non-sparking tools near H2 fueling areas

## 9. Quality Assurance

- All anchors must have load test certification before use
- Annual inspection and load testing required
- Document anchor locations in facility ground plan
- Maintain anchor maintenance logs
