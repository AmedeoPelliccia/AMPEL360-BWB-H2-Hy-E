## Pre-Installation Checklist

### Documentation Review

- [ ] Installation procedure reviewed and understood
- [ ] Applicable drawings available and current revision
- [ ] Material certifications verified (traceability)
- [ ] Tools calibrated and within certification date
- [ ] Safety precautions reviewed with all personnel

### Materials and Tools

- [ ] All required materials available and inspected
- [ ] Part numbers verified against Bill of Materials
- [ ] All required tools available
- [ ] Special tools or equipment functional
- [ ] PPE available for all personnel

### Site Preparation

- [ ] Work area clean and free of FOD (Foreign Object Debris)
- [ ] Adequate lighting for installation
- [ ] Fall protection installed (if working at height)
- [ ] Electrical power available (if required)
- [ ] Safety equipment accessible (fire extinguisher, first aid, etc.)

### H2-Specific Pre-Checks (if applicable)

- [ ] H2 detection sensors functional and calibrated
- [ ] H2 safety zones established and marked
- [ ] Cryogenic PPE available and inspected
- [ ] Safety shower/eyewash tested and functional
- [ ] Emergency procedures reviewed
- [ ] Fire suppression equipment available

### BWB-Specific Pre-Checks (if applicable)

- [ ] Aircraft dimensions and clearances verified
- [ ] Center of gravity location confirmed
- [ ] Special access equipment available (platforms, etc.)
- [ ] Ground clearance verified for installation

## Post-Installation Checklist

### Visual Inspection

- [ ] All hardware installed and torqued per specification
- [ ] No missing washers, nuts, or fasteners
- [ ] Torque stripes applied and intact
- [ ] All connections secure and properly engaged
- [ ] No interference with adjacent systems or structure
- [ ] Safety wire installed where required
- [ ] All labels and placards installed

### Dimensional/Alignment Verification

- [ ] Installation dimensions checked against drawing
- [ ] Alignment within specified tolerances
- [ ] Clearances verified (minimum distances maintained)
- [ ] Level/plumb verified (if applicable)

### Functional Test

- [ ] System operates per specification
- [ ] All controls and indicators function correctly
- [ ] No binding or unusual resistance
- [ ] Safety systems operational (if applicable)
- [ ] Emergency shutdown tested (if applicable)

### Electrical/Bonding (if applicable)

- [ ] Electrical connections correct and secure
- [ ] Bonding verified (resistance < 0.003 ohms)
- [ ] Grounding connection verified
- [ ] No chafing or interference with wiring

### H2-Specific Post-Checks (if applicable)

- [ ] Leak test completed (no leaks detected)
- [ ] H2 detection system tested and operational
- [ ] Safety interlocks functional
- [ ] Emergency equipment accessible
- [ ] Safety signage installed

### Documentation

- [ ] Installation record completed
- [ ] Deviations/non-conformances documented
- [ ] Photographs taken (if required)
- [ ] Drawings marked "AS INSTALLED" (if changes)
- [ ] Maintenance logs updated

### Cleanliness and FOD

- [ ] Work area cleaned of all debris and tools
- [ ] No tools or materials left in/on aircraft or equipment
- [ ] FOD inspection completed
- [ ] Protective covers removed or installed as required
