## 15. Usage Instructions

This template should be used for creating new part specifications in the ATA 10 PARTS library.

### How to Use:

1. Copy this template to the appropriate category folder
2. Rename file following convention: `[Part_ID]_[ShortName].md`
3. Replace all bracketed placeholders with actual values
4. Complete all applicable sections
5. For H2 system parts, ensure Section 4 is thoroughly completed
6. Add to 00_INDEX.md after creation
7. Submit for review and approval

### Required Sections:

- Sections 1-3: Always required
- Section 4: Required for H2 system parts (10-PRT-H2-XXX), optional for others
- Section 8: Required only if part is hazmat
- All other sections: Recommended but may be marked N/A if not applicable
