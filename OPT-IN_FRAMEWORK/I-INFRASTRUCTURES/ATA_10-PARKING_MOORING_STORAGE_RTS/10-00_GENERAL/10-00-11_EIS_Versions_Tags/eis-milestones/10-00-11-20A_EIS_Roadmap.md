# 10-00-11-20A: EIS Roadmap

## Document Information
- **Document ID**: 10-00-11-20A

- **Version**: 1.0.0
- **Date**: 2025-12-11
- **Status**: DRAFT
- **Document Type**: roadmap

## Purpose

This document defines the Entry Into Service (EIS) roadmap for the AMPEL360-BWB-H2 aircraft, outlining the development phases, key milestones, version targets, and baseline evolution from initial development through certification and EIS.

## Scope

The EIS Roadmap covers:
- Development phases and timeline
- Engineering milestones (PDR, CDR, TRR, FAI, EIS)
- Version progression and release strategy
- Baseline establishment schedule
- H2 certification milestones
- BWB certification milestones
- Integration and testing timeline

## Development Phases

### Phase 1: Concept and Requirements (Months 1-12)

**Objective**: Establish system concept and complete requirements definition

**Key Activities**:
- Stakeholder requirements capture
- System architecture definition
- Preliminary H2 system design
- BWB configuration analysis
- Requirements baseline establishment

**Version Target**: v0.1.0 (Alpha)

**Deliverables**:
- System Requirements Specification
- Concept of Operations
- Preliminary Safety Assessment
- Technology readiness assessment

**Milestone**: Concept Design Review (CDR-0)

### Phase 2: Preliminary Design (Months 13-24)

**Objective**: Complete preliminary design and establish Functional Baseline

**Key Activities**:
- Detailed system design
- H2 safety system preliminary design
- BWB ground handling analysis
- Interface definition
- Preliminary Hazard Analysis

**Version Target**: v0.3.0 (Alpha)

**Deliverables**:
- Preliminary Design Documents
- Functional Baseline (FBL)
- Interface Control Documents
- PHA Report

**Milestone**: Preliminary Design Review (PDR)
- **Target Date**: Month 24
- **Baseline**: FBL (10-00-11-10A)

### Phase 3: Detailed Design (Months 25-42)

**Objective**: Complete detailed design and establish Allocated Baseline

**Key Activities**:
- Detailed component design
- H2 system detailed design and safety analysis
- BWB-specific equipment design
- Design verification planning
- Supplier selection

**Version Target**: v0.5.0 (Beta)

**Deliverables**:
- Detailed Design Documents
- Allocated Baseline (ABL)
- H2 System Baseline (H2BL)
- BWB Configuration Baseline (BWBBL)
- Design verification procedures

**Milestone**: Critical Design Review (CDR)
- **Target Date**: Month 42
- **Baseline**: ABL (10-00-11-11A), H2BL (10-00-11-13A), BWBBL (10-00-11-14A)

### Phase 4: Integration and Testing (Months 43-60)

**Objective**: Integrate systems, conduct ground testing, establish Product Baseline

**Key Activities**:
- Component manufacturing and assembly
- Ground integration testing
- H2 system ground testing
- BWB structural testing
- Safety validation testing

**Version Target**: v0.9.0 (Release Candidate)

**Deliverables**:
- Test Reports
- Product Baseline (PBL)
- System Safety Assessment
- Certification test evidence

**Milestone**: Test Readiness Review (TRR)
- **Target Date**: Month 54
- **Baseline**: PBL (10-00-11-12A)

### Phase 5: Flight Testing and Certification (Months 61-78)

**Objective**: Conduct flight testing and obtain Type Certificate

**Key Activities**:
- Flight test program execution
- H2 system flight validation
- BWB flight characteristics validation
- Certification compliance demonstration
- Authority inspections

**Version Target**: v1.0.0-rc.1 (Final Release Candidate)

**Deliverables**:
- Flight Test Reports
- Certification Evidence Package
- Type Certificate Data Sheet
- Flight Manual

**Milestone**: First Article Inspection (FAI)
- **Target Date**: Month 72
- **Baseline**: FAI Baseline (10-00-11-24A)

### Phase 6: Entry Into Service (Month 78+)

**Objective**: Achieve EIS and commence operations

**Key Activities**:
- Type Certificate issuance
- Production Certificate issuance
- Operator training completion
- Initial deliveries
- In-service monitoring

**Version Target**: v1.0.0 (EIS Release)

**Deliverables**:
- EIS Baseline (EISBL)
- Type Certificate
- Production Certificate
- Approved Maintenance Program
- Flight Operations documentation

**Milestone**: Entry Into Service (EIS)
- **Target Date**: Month 78
- **Baseline**: EIS Baseline (10-00-11-25A)

## Version Progression Strategy

### Development Versions (0.x.y)

**0.1.0 - 0.2.x**: Initial alpha releases
- Requirements refinement
- Concept validation
- Internal stakeholder review

**0.3.0 - 0.4.x**: PDR preparation and post-PDR updates
- FBL establishment
- Preliminary design completion
- Interface definition

**0.5.0 - 0.7.x**: Beta releases
- ABL, H2BL, BWBBL establishment
- Detailed design completion
- Early integration testing

**0.8.0 - 0.9.x**: Release candidates
- PBL establishment
- Ground testing completion
- Certification preparation

**1.0.0-rc.x**: Final release candidates
- Flight testing
- Certification compliance demonstration
- Authority review

### Production Versions (1.x.y)

**1.0.0**: Entry Into Service
- Type Certificate baseline
- Initial operator deliveries

**1.x.0**: Post-EIS enhancements
- Service bulletins
- Performance improvements
- Operational feedback incorporation

**2.0.0+**: Major updates
- Significant capability additions
- Certification amendments

## Risk Management Milestones

### Critical Path Risks

1. **H2 Safety Certification** (High Risk)
   - Mitigation: Early authority engagement
   - Contingency: +6 months schedule buffer

2. **BWB Flight Characteristics** (Medium Risk)
   - Mitigation: Wind tunnel testing, CFD validation
   - Contingency: +3 months schedule buffer

3. **Cryo System Performance** (Medium Risk)
   - Mitigation: Component testing, thermal modeling
   - Contingency: Alternate insulation design ready

### Schedule Buffers

- PDR to CDR: 2 months buffer
- CDR to TRR: 3 months buffer
- TRR to FAI: 6 months buffer
- FAI to EIS: 3 months buffer
