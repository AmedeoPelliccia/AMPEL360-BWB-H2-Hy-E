## 2. Purpose

Verify structural integrity and load carrying capacity of tiedown attachment points and systems for the AMPEL360-BWB-H2-Hy-E aircraft.

## 3. Scope

- Tiedown attachment point strength verification
- Load distribution validation  
- Safety factor demonstration
- Ultimate load testing

## 4. Requirements Verified

| Requirement ID | Description | Acceptance Criteria |
|----------------|-------------|---------------------|
| REQ-10-TD-001 | Ultimate load capacity | ≥ 1.5 × design limit load |
| REQ-10-TD-002 | Load distribution | No single point overload |
| REQ-10-TD-003 | Safety margins | Positive margin at all locations |

## 5. Test Procedure Summary

### 5.1 Limit Load Test
1. Apply design limit load incrementally
2. Hold for specified duration
3. Inspect for permanent deformation
4. Measure deflections

### 5.2 Ultimate Load Test  
1. Apply 1.5 × limit load
2. Hold for specified duration
3. Verify no structural failure

### 5.3 Instrumentation
- Load cells at each tiedown point
- Strain gauges at critical locations
- Displacement transducers

## 6. Acceptance Criteria

- No structural failure at ultimate load
- Permanent deformation ≤ allowable
- Actual capacity ≥ 1.5 × design limit load
