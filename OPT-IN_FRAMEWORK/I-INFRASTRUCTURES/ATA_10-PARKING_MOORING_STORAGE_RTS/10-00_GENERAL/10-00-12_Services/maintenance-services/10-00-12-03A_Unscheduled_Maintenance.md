# 10-00-12-03A - Unscheduled Maintenance

## 1. Purpose

This document defines unscheduled and corrective maintenance services for the AMPEL360-BWB-H2 aircraft, addressing defects, failures, and emergency repairs during parking, mooring, and storage operations.

## 2. Scope

- Unscheduled maintenance triggers and classification
- AOG (Aircraft on Ground) response procedures
- Defect rectification processes
- H2/Cryo emergency maintenance
- Component troubleshooting and replacement
- Documentation and airworthiness release

## 3. Unscheduled Maintenance Categories

### 3.1 Category 1: AOG - Safety Critical

**Response Time**: Immediate (within 1 hour)

**Triggers**:
- H2 system leak or safety concern
- Flight control system failure
- Structural damage affecting airworthiness
- Fire detection/suppression system failure

**Action**:
- Dispatch specialized technicians immediately
- 24/7 parts availability
- Continuous work until resolved
- Dual inspection required

### 3.2 Category 2: MEL Deferral Expired

**Response Time**: Within 4 hours

**Triggers**:
- MEL (Minimum Equipment List) deferred item reaching time limit
- System degradation affecting dispatch
- Component failure requiring rectification before next flight

**Action**:
- Priority scheduling
- Parts expedited if needed
- Complete repair before next dispatch

### 3.3 Category 3: Routine Defects

**Response Time**: Within 24 hours

**Triggers**:
- Minor system malfunctions
- Cosmetic damage
- Non-essential equipment failures
- Operational inconveniences

**Action**:
- Schedule during next available maintenance window
- Standard parts ordering
- Normal priority

## 4. H2/Cryo Emergency Maintenance

### 4.1 H2 Leak Response

**Immediate Actions**:
1. Evacuate H2 safety zone
2. Activate H2 leak response team
3. Verify ventilation and monitoring
4. Isolate H2 system if safe to do so
5. Deploy H2 detection equipment

**Repair Authorization**:
- Only H2-certified technicians
- Dual inspection mandatory
- Leak test before return to service

### 4.2 Cryogenic System Failures

**Common Issues**:
- Excessive boil-off rate
- Vacuum jacket integrity loss
- Thermal protection degradation
- Cryo valve malfunction

**Response**:
- Cryo-certified personnel required
- Special tooling for low-temperature work
- Thermal survey before and after repair
- System recertification may be required

## 5. Troubleshooting Process

### 5.1 Fault Isolation

1. **Symptom Analysis**: Review pilot/crew reports and system data
2. **System Tests**: Perform built-in test (BIT) and ground tests
3. **Fault Tree Analysis**: Follow AMM troubleshooting procedures
4. **Component Testing**: Isolate faulty component

### 5.2 H2 System Troubleshooting

Special considerations:
- Always verify system is purged before intrusive work
- Use H2 detection during all troubleshooting
- Follow lockout/tagout procedures strictly
- Document all H2 system work thoroughly

## 6. Component Replacement

### 6.1 Standard Components

- Verify part number and serviceability
- Record component serial numbers (removed and installed)
- Perform operational checks per AMM
- Update aircraft records

### 6.2 H2/Cryo Components

Additional requirements:
- Verify H2/Cryo certification of replacement part
- Special handling for cryogenic components
- Pre-installation leak testing
- Post-installation system integrity check
- Functional test under H2 conditions (if safe)

## 7. BWB-Specific Unscheduled Maintenance

### 7.1 Access Challenges

- May require specialized equipment for wide-body access
- Custom scaffolding for leading edge repairs
- Extended work platforms for upper surfaces

### 7.2 Structural Repairs

- BWB-specific repair data required
- Composite repair procedures for blended sections
- Load path considerations unique to BWB

## 8. Airworthiness Release

### 8.1 Certification Requirements

All unscheduled maintenance must be certified by:
- Licensed aircraft maintenance engineer (LAME/AMT)
- Part 145 approved organization (for major repairs)
- Dual inspection for safety-critical systems

### 8.2 Documentation

Required records:
- Work order with detailed task description
- Component removal/installation records
- Inspection findings and corrective actions
- Airworthiness release (EASA Form 1 or equivalent)
- Update of aircraft technical log

- Loaner/exchange programs for expensive components
