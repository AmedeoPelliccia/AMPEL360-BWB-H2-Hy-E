# 10-00-12-13A - Storage Services

## 1. Purpose

Define short-term and long-term storage procedures for AMPEL360-BWB-H2 aircraft with H2 system preservation.

## 2. Scope

- Short-term storage (up to 30 days)
- Long-term storage (30+ days)
- H2/Cryo system preservation
- Return-to-service procedures

## 3. Short-Term Storage (≤30 days)

### 3.1 Preparation

- Deplete LH2 to minimum safe level or transfer out
- Purge H2 system with GN2
- Apply external covers (pitot tubes, sensors)
- Inflate tires to storage pressure
- Install intake/exhaust plugs

### 3.2 Periodic Inspections

- Weekly: External visual inspection, H2 system check
- Bi-weekly: Tire pressure check
- Monthly: Full walk-around, systems check

## 4. Long-Term Storage (>30 days)

### 4.1 Preparation

- Complete LH2 removal and system purge
- Cryogenic system warm-up procedure
- Drain all fluids (except sealed systems)
- Apply preservation compounds
- Install full weather protection
- Remove batteries

### 4.2 Periodic Inspections

- Monthly: External inspection, desiccant check
- Quarterly: Internal systems inspection
- Annually: Full airworthiness review

## 5. H2 System Preservation

- Purge with dry GN2 to <1% H2
- Seal all openings
- Apply corrosion protection to fittings
- Monitor vacuum jacket pressure (if applicable)
- Document all preservation steps

## 6. Return-to-Service

- Inspection per AMM Chapter 10
- Functional tests of all systems
- H2 system leak test before refilling
- Airworthiness release required
