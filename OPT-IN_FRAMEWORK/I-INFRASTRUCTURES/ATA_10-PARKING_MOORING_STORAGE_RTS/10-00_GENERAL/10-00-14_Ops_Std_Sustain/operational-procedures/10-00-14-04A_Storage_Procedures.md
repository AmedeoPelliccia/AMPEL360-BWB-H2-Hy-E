## 1. Purpose

Procedures for placing the AMPEL360 BWB-H2-Hy-E aircraft in short-term or long-term storage and returning it to service.

---

## 2. Scope

- Short-term storage (7-30 days)
- Long-term storage (>30 days)
- Storage preparation procedures
- Storage monitoring and maintenance
- Return-to-service procedures

---

## 3. Storage Classification

### 3.1 Short-Term Storage (7-30 Days)

**Typical scenarios:**
- Seasonal demand reduction
- Awaiting maintenance parts
- Crew availability gaps

**Requirements:**
- Reduced preservation (some systems active)
- Regular monitoring (weekly)
- Quick return-to-service capability

### 3.2 Long-Term Storage (>30 Days)

**Typical scenarios:**
- Extended maintenance
- Fleet reduction
- Pending aircraft disposition

**Requirements:**
- Full preservation procedures
- Comprehensive monitoring (monthly)
- Extended return-to-service preparation

---

## 4. Storage Location Selection

### 4.1 Ideal Storage Location

- **Indoor (Hangar)**: Preferred for long-term storage
  - Climate-controlled environment
  - Protection from weather
  - Security
  - Reduced monitoring requirements

- **Outdoor (Hardstand)**: Acceptable with proper preparation
  - Paved surface, level, good drainage
  - Away from trees, buildings, other aircraft
  - Access to utilities (ground power for monitoring systems)
  - Secure perimeter

### 4.2 H₂ Aircraft Storage Considerations

For H₂-fueled aircraft:
- **H₂ Tank Status**: Determine if aircraft stored with or without H₂ fuel
  - **With H₂**: Active monitoring required, venting capability essential
  - **Without H₂**: Tank must be properly inerted and sealed
- **Ventilation**: Outdoor storage preferred for H₂-fueled aircraft (natural ventilation)
- **Safety Zones**: Establish and maintain H₂ safety zones during storage period
- **Fire Protection**: Fire suppression equipment accessible

## 5. Pre-Storage Preparation

### 5.1 General Aircraft Preparation

1. **Fluids and Systems**
   - [ ] Fuel: Top off conventional fuel tanks (prevent condensation) or defuel H₂ system
   - [ ] Oil: Service all oil systems to proper levels
   - [ ] Hydraulics: Service and preserve
   - [ ] Water/Waste: Drain water and waste systems completely
   - [ ] Lubrication: Apply preservative lubricants to landing gear, controls

2. **Engines and APU**
   - [ ] Perform storage preparation per engine manufacturer instructions
   - [ ] Install engine intake and exhaust covers
   - [ ] Preserve internal components (if long-term)
   - [ ] APU storage preparation

3. **H₂ System** (if stored with H₂)
   - [ ] Verify tank integrity and leak-free
   - [ ] Establish monitoring system (continuous pressure/temperature)
   - [ ] Connect to ground vent system (if available)
   - [ ] Document initial H₂ quantity and tank conditions
   - [ ] Set up automated venting if pressure exceeds limits
   - See [10-00-14-05A](10-00-14-05A_H2_Operations_Procedures.md) Section 7

4. **H₂ System** (if stored without H₂ — defueled)
   - [ ] Safely defuel and purge H₂ system per ATA 12 procedures
   - [ ] Inert tank with nitrogen or helium
   - [ ] Seal tank and verify inert atmosphere maintained
   - [ ] Disable H₂ monitoring systems

5. **Electrical Systems**
   - [ ] Batteries: Remove or maintain on trickle charge
   - [ ] Ground power: Connect if monitoring systems active
   - [ ] Isolate non-essential electrical systems
   - [ ] Maintain power to H₂ monitoring (if applicable)

6. **External Protection**
   - [ ] Install pitot/static covers
   - [ ] Install engine inlet/exhaust covers
   - [ ] Cover windows and windscreens (UV protection)
   - [ ] Protect external probes and sensors
   - [ ] Seal door and panel gaps (prevent moisture, insects, FOD)

7. **Landing Gear**
   - [ ] Inflate tires to storage pressure (typically 5-10% above normal)
   - [ ] Install wheel chocks
   - [ ] Consider jack stands for long-term storage (relieve tire/strut loads)

8. **Mooring** (outdoor storage)
   - [ ] Install tiedowns if winds >25 kt forecast
   - [ ] See [10-00-14-03A](10-00-14-03A_Mooring_Procedures.md)

## 6. Storage Monitoring

### 6.1 Short-Term Storage Monitoring (7-30 Days)

**Frequency**: Weekly inspection

**Inspection Items:**
- [ ] H₂ system status (if applicable): pressure, temperature, no leaks
- [ ] General visual inspection: no damage, no leaks, no animal/insect intrusion
- [ ] Tires: pressure check, no flat spots developing
- [ ] Covers: all in place and secure
- [ ] Security: aircraft secure, no unauthorized access
- [ ] Tiedowns: tension check (if installed)
- [ ] Batteries: charge state (if installed)

### 6.2 Long-Term Storage Monitoring (>30 Days)

**Frequency**: Monthly inspection (minimum)

**Inspection Items (in addition to short-term items):**
- [ ] Engine preservation: inspect for corrosion, manually rotate per schedule
- [ ] Hydraulic systems: check for leaks, operate actuators monthly
- [ ] Flight controls: exercise controls monthly (prevent seizing)
- [ ] Doors and hatches: open/close monthly
- [ ] Environmental control: check desiccant packs (if used), replace as needed
- [ ] Documentation: update storage log

### 6.3 H₂ System Monitoring During Storage

**If stored with H₂** (see [10-00-14-05A](10-00-14-05A_H2_Operations_Procedures.md) Section 7):

| Duration | Monitoring Frequency | Actions |
|----------|---------------------|---------|
| 0-7 days | Every 12 hours | Pressure/temp trending, vent if >4.5 bar |
| 7-30 days | Daily | Active boil-off management |
| >30 days | Daily | Consider defueling if storage extends indefinitely |

**Continuous automated monitoring** (if available):
- Tank pressure and temperature
- H₂ leak detection
- Automated venting if pressure exceeds limits
- Alerts to H₂ Safety Officer

## 7. Return-to-Service Procedure

### 7.1 Pre-Return Preparation (Planning)

**Lead Time**: Begin preparations [TBD] days before planned return-to-service

1. **Review Storage Records**
   - [ ] Review all storage inspection logs
   - [ ] Identify any issues or anomalies during storage
   - [ ] Verify all required inspections completed

2. **Scheduling**
   - [ ] Schedule personnel for return-to-service activities
   - [ ] Coordinate with maintenance (if inspections due)
   - [ ] Arrange for H₂ fueling (if defueled)
   - [ ] Schedule ground runs and functional tests

### 7.2 Return-to-Service Procedure

**Day 1-2: Removal of Storage Configuration**

1. **Remove External Protections**
   - [ ] Remove all covers (pitot, engine, windows)
   - [ ] Remove tiedowns (if installed)
   - [ ] Remove wheel chocks
   - [ ] Inspect for storage-related damage

2. **Systems Reactivation**
   - [ ] Restore electrical power (remove batteries from storage or disconnect trickle charge)
   - [ ] Restore hydraulic systems
   - [ ] Lubricate as required
   - [ ] Exercise flight controls

3. **H₂ System Reactivation** (if applicable)
   - [ ] See [10-00-14-05A](10-00-14-05A_H2_Operations_Procedures.md) Section 8
   - [ ] If defueled, coordinate H₂ fueling per ATA 12
   - [ ] If stored with H₂, verify system status and readiness

4. **Engine/APU Preparation**
   - [ ] Remove engine from storage preservation
   - [ ] Perform ground runs per engine manufacturer procedures
   - [ ] APU test run

**Day 3: Functional Checks**

- [ ] Perform pre-flight functional checks
- [ ] Test all systems (flight controls, electrical, hydraulic, pneumatic, H₂, etc.)
- [ ] Address any discrepancies found

**Day 4: Final Preparation**

- [ ] Complete all required inspections (per maintenance schedule)
- [ ] Update aircraft logbooks
- [ ] Brief flight crew on storage period and return-to-service activities
- [ ] Obtain release for flight

**Day 5: Test Flight (if required)**

- [ ] Conduct test flight per approved test plan
- [ ] Verify all systems operational
- [ ] Return to service

## 8. Special Considerations

### 8.1 Extended Storage (>6 Months)

For very long-term storage:
- Consider indoor storage (hangar) to minimize environmental degradation
- Increase inspection frequency
- Implement comprehensive preservation (engines, systems, structure)
- Plan for significant return-to-service effort (may require heavy maintenance)

### 8.2 Emergency Storage

If aircraft must be placed in storage with minimal preparation:
- Document "emergency storage" status
- Perform minimum safe preservation
- Plan for expedited full preservation within [TBD] days
- Monitor closely until full preservation completed

## 9. Documentation

### 9.1 Storage Log

Maintain comprehensive storage log including:
- Storage start/end dates
- Storage classification (short-term / long-term)
- Initial aircraft condition
- All inspections performed (dates, personnel, findings)
- H₂ system monitoring data (if applicable)
- Any maintenance actions during storage
- Return-to-service activities

### 9.2 Aircraft Logbook Entries

Record in aircraft logbooks:
- Entry into storage (date, reason)
- Exit from storage (date)
- Any maintenance performed during storage
- Return-to-service inspections and tests
