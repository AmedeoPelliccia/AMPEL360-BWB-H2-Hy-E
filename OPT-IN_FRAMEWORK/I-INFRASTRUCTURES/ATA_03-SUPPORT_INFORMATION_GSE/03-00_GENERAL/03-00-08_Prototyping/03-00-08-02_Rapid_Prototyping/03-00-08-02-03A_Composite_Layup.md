# 03-00-08-02-03A - Composite Layup

## 1. Purpose

This document defines composite material layup processes for prototype fabrication within the AMPEL360-BWB-H2-Hy-E program, supporting the development of the Blended Wing Body airframe.

## 2. Scope

This specification covers hand layup, vacuum bagging, autoclave curing, and other composite manufacturing processes for structural and non-structural prototype components.

## 4. Description

### 4.1 Overview

Composite layup is critical for the BWB aircraft structure, enabling lightweight, high-strength components with complex geometries. Prototype composite manufacturing validates materials, processes, and designs before full-scale production.

### 4.2 Requirements

**Composite Manufacturing Processes:**

**Hand Layup:**
- Applications: Large structural panels, low-rate prototypes
- Materials: Prepreg carbon fiber, fiberglass
- Ply count: Up to 50 layers
- Quality: Depends on operator skill and process control

**Vacuum Bagging:**
- Applications: Moderate complexity parts, secondary structures
- Pressure: 1 atmosphere (vacuum)
- Cure: Oven cure at specified temperature profile
- Quality: Good consolidation, low void content

**Autoclave Processing:**
- Applications: Primary structures, high-performance parts
- Pressure: Up to 6 bar (90 psi)
- Temperature: Up to 180°C (depending on resin system)
- Quality: Excellent consolidation, minimal voids (<1%)

**Resin Infusion (VARTM/RTM):**
- Applications: Complex shapes, integrated structures
- Process: Dry fabric + resin infusion under vacuum
- Advantages: Lower material cost, good fiber-to-resin ratio
- Quality: Good, requires careful process control

**Materials:**
- Carbon fiber prepreg (various modulus grades)
- E-glass and S-glass prepreg
- Aramid (Kevlar) prepreg
- Core materials (honeycomb, foam)
- Adhesives and sealants

### 4.3 Methodology

**Composite Layup Process:**

1. **Preparation**
   - Tool preparation and cleaning
   - Release agent application
   - Material conditioning (out-time management)
   - Ply cutting and kitting

2. **Layup**
   - Ply placement per layup schedule
   - Orientation verification (0°, 45°, 90°, etc.)
   - Debulking between plies/layers
   - Foreign object debris (FOD) control

3. **Vacuum Bagging**
   - Peel ply, release film, breather installation
   - Vacuum bag sealing
   - Leak check (vacuum hold test)
   - Thermocouple placement

4. **Curing**
   - Cure cycle execution per specification
   - Temperature and pressure monitoring
   - Data logging
   - Cool-down procedure

5. **Post-Cure**
   - Bag removal and inspection
   - Trimming and machining
   - Non-destructive inspection (NDI)
   - Dimensional inspection

**Quality Control:**
- Material certification and traceability
- Environmental monitoring (temperature, humidity)
- Ply orientation verification
- Cure cycle data recording
- NDI (ultrasonic, thermography)
- Mechanical testing (coupons)

## 6. Quality Criteria

**Composite Quality Standards:**
- Fiber volume fraction: 55-65% (typical for aerospace)
- Void content: < 1% for primary structures, < 2% for secondary
- Ply orientation accuracy: ±5°
- Cured thickness: ±0.1 mm per ply
- Surface quality: No wrinkles, bridging, or porosity

**Acceptance Criteria:**
- All NDI findings dispositioned
- Dimensional inspection passed
- Material certifications on file
- Cure cycle data within specification
- Visual inspection passed
