# 03-00-08-04-01A - CAD Models

## 1. Purpose

This document defines standards and processes for Computer-Aided Design (CAD) models used in digital prototyping within the AMPEL360-BWB-H2-Hy-E program.

## 2. Scope

This specification covers CAD modeling standards, file formats, version control, model validation, and integration with other digital tools for the BWB aircraft development.

- ATA 03-00-08-01-01A_Prototyping_Strategy

- ATA 03-00-06_Engineering
- ISO 10303 (STEP) - Product Data Exchange

## 4. Description

### 4.1 Overview

CAD models are the foundation of digital prototyping, enabling design visualization, interference checking, manufacturing planning, and analysis preparation. Standardized CAD practices ensure consistency, quality, and interoperability.

### 4.2 Requirements

**CAD Software Platforms:**
- **Primary**: CATIA V6 (for aircraft structures and systems)
- **Secondary**: Siemens NX (for specific components)
- **Viewer/Collaboration**: 3DEXPERIENCE platform
- **Lightweight**: CATIA Composer (for documentation)

**Model Types:**

**Conceptual Models (Early Design):**
- Simple geometry, low detail
- Focus on overall configuration and proportions
- Rapid iteration capability
- File format: Native CAD or STEP

**Detailed Design Models:**
- Full geometric definition
- Accurate dimensions and tolerances
- Material and surface finish specifications
- Assembly structure and hierarchy
- File format: Native CAD with STEP export

**Manufacturing Models:**
- Production-ready geometry
- Tooling and fixture interfaces
- Manufacturing annotations (GD&T)
- Bill of materials (BOM) integrated
- File format: Native CAD with PMI (Product Manufacturing Information)

**Analysis Models:**
- Simplified geometry for FEA/CFD
- Mid-surface extraction (for shells)
- Appropriate simplifications
- File format: Parasolid, IGES, STEP

### 4.3 Methodology

**CAD Modeling Standards:**

**Naming Conventions:**
- Part numbers: `AMPEL-XX-YYYY-ZZZ` (XX=ATA chapter, YYYY=system, ZZZ=part)
- Assembly names: Descriptive with revision suffix
- Drawing numbers: Aligned with part numbers

**Model Organization:**
- Top-level assembly structure follows ATA breakdown
- Sub-assemblies for major systems and zones
- Part-level components with attributes
- Reference planes and coordinate systems standardized

**Design Rules:**
- Units: Metric (mm, kg) throughout
- Tolerance: Per ISO 2768-m unless specified
- Coordinate system: Aircraft reference (nose=+X, right wing=+Y, up=+Z)
- Layer structure: Standardized for visibility control
- Parameters: Driven by design tables where applicable

**Model Quality:**
- No invalid geometry (self-intersections, gaps)
- Surfaces properly trimmed and joined
- Fillets and blends appropriate for manufacturing
- Assembly constraints properly defined
- Model validation checks passed

**Version Control:**
- PDM/PLM system (3DEXPERIENCE, Teamcenter)
- Check-in/check-out procedures
- Revision control (A, B, C, ...)
- Change notes and history
- Baseline management

**Interoperability:**
- STEP AP242 for neutral exchange
- Native format for internal collaboration
- Lightweight formats (3D PDF, JT) for review
- 2D drawings (PDF, DWG) for manufacturing

## 6. Quality Criteria

**Model Quality Standards:**
- Geometry validation: 100% clean (no errors)
- Drawing compliance: Dimensions match model
- BOM accuracy: 100% complete and correct
- Naming convention compliance: 100%
- File size optimization: < 500 MB per assembly

**Review and Approval:**
- Design review completed
- Interference check passed
- Manufacturability review passed
- PDM check-in completed
- Release approval obtained
