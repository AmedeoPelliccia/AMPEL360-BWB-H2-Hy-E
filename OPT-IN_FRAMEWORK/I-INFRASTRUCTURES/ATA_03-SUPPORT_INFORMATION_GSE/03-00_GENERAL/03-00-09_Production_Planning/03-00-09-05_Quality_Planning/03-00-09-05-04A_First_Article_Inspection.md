## 1. Purpose

This document defines the First Article Inspection (FAI) requirements for the AMPEL360 BWB-H2-Hy-E aircraft production program, ensuring initial production articles meet all design and specification requirements.

## 4. Description

### 4.1 Overview

First Article Inspection (FAI) is a comprehensive verification of a representative production article to ensure all design, specification, and process requirements are correctly implemented before full-scale production. FAI provides objective evidence of conformance per AS9102.

### 4.2 Requirements

**FAI Triggers:**
- New part number
- Design change affecting form, fit, or function
- Manufacturing process change
- New or modified tooling
- Production break >2 years
- Change in manufacturing location

**FAI Components (AS9102):**
- **Form 1:** Part Number Accountability
- **Form 2:** Product Accountability
- **Form 3:** Characteristic Accountability and Verification
- Supporting documentation (drawings, specs, test reports)

### 4.3 Methodology

**FAI Process:**

1. **FAI Planning**
   - FAI requirement identification
   - FAI schedule development
   - Resource allocation
   - Customer notification
   - Sampling plan (if applicable)

2. **Article Selection**
   - Random selection from production
   - Full traceability documentation
   - Material certifications
   - Process documentation
   - Test records

3. **Characteristic Verification**
   - All drawing dimensions
   - Material specifications
   - Surface finish requirements
   - Functional requirements
   - Special characteristics
   - Applicable workmanship standards

4. **Verification Methods**
   - Dimensional inspection
   - Material testing
   - Functional testing
   - Non-destructive testing
   - Visual inspection
   - Documentation review

5. **FAI Documentation**
   - AS9102 Forms 1, 2, 3 completion
   - Inspection data recording
   - Test results attachment
   - Material certifications
   - Process documentation
   - Photographic evidence

6. **FAI Review and Approval**
   - Internal quality review
   - Engineering review
   - Customer review (if required)
   - Regulatory authority review (if required)
   - Corrective action (if discrepancies found)
   - Final approval and release

7. **FAI Record Retention**
   - Permanent record storage
   - Electronic database entry
   - Traceability to production
   - Change control integration
