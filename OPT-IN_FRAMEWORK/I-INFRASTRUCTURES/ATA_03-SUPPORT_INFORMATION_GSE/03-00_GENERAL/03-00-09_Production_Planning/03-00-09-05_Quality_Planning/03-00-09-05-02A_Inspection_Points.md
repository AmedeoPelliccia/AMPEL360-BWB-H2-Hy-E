## 1. Purpose

This document defines the inspection points throughout the AMPEL360 BWB-H2-Hy-E aircraft production process, establishing where and how quality verification occurs.

## 2. Scope

This document addresses:
- Inspection point identification and classification
- Hold points and witness points
- Inspection methods and techniques
- Critical characteristics inspection
- Inspection documentation requirements
- Buy-off and sign-off procedures

## 4. Description

### 4.1 Overview

Inspection points are strategically placed verification activities throughout production to ensure conformance before work proceeds. Proper placement prevents defects from propagating and ensures early detection of nonconformances.

### 4.2 Requirements

**Inspection Point Types:**
- **Hold Points (H):** Mandatory inspection before proceeding; production stops
- **Witness Points (W):** Customer/authority inspection opportunity
- **Verification Points (V):** Standard production inspection
- **Surveillance Points (S):** Periodic audit/monitoring

**Inspection Point Criteria:**
- Critical characteristics
- Hard-to-access features after assembly
- Safety-critical items
- Regulatory requirements
- Customer requirements
- High-risk operations

### 4.3 Methodology

**Inspection Point Planning:**

1. **Critical Characteristic Review**
   - Design requirement analysis
   - Safety-critical feature identification
   - Regulatory requirement mapping
   - Customer special requirements
   - Lesson learned integration

2. **Inspection Point Definition**
   - Location in production sequence
   - Inspection type (H/W/V/S)
   - Characteristics to inspect
   - Inspection method
   - Acceptance criteria
   - Documentation requirements

3. **Inspection Method Selection**
   - Dimensional inspection
   - Visual inspection
   - Functional testing
   - Non-destructive testing
   - Attribute verification
   - Document review

4. **Inspection Documentation**
   - Inspection checklists
   - Inspection stamps/signatures
   - Photographic evidence
   - Test data records
   - Nonconformance reports
   - Buy-off records

5. **Inspection Point Management**
   - Work order integration
   - MES system integration
   - Electronic sign-off
   - Status tracking
   - Metrics and reporting
