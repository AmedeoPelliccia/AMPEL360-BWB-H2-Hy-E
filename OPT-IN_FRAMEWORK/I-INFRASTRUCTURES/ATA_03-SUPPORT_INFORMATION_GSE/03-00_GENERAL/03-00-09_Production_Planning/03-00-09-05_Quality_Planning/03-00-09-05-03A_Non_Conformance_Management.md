## 1. Purpose

This document establishes the non-conformance management system for the AMPEL360 BWB-H2-Hy-E aircraft production program, defining how defects and deviations are identified, documented, dispositioned, and resolved.

## 2. Scope

This document covers:
- Non-conformance identification and reporting
- Containment and quarantine procedures
- Disposition process (use-as-is, rework, repair, scrap)
- Root cause analysis and corrective action
- Supplier non-conformance management
- Metrics and trend analysis

## 4. Description

### 4.1 Overview

Non-conformance management ensures systematic identification, documentation, and resolution of products or processes that do not conform to requirements. Effective management prevents defect propagation and drives continuous improvement.

### 4.2 Requirements

**Non-Conformance Management Objectives:**
- Rapid identification and containment
- Systematic root cause analysis
- Effective corrective action
- Prevention of recurrence
- Continuous improvement
- Regulatory compliance

**Non-Conformance Types:**
- Material defects
- Manufacturing defects
- Assembly errors
- Documentation errors
- Supplier non-conformances
- Test failures

### 4.3 Methodology

**Non-Conformance Management Process:**

1. **Identification and Reporting**
   - Defect detection
   - Non-conformance report (NCR) initiation
   - Classification (major/minor/critical)
   - Part identification and tagging
   - System entry

2. **Containment**
   - Immediate quarantine
   - Suspect population identification
   - Hold tag application
   - Segregation in designated area
   - Work stoppage (if required)

3. **Investigation**
   - Preliminary assessment
   - Data collection
   - Affected quantity determination
   - Customer notification (if required)
   - Impact analysis

4. **Disposition**
   - Material Review Board (MRB) review
   - Disposition decision:
     - **Use-as-is:** Accept without change
     - **Rework:** Return to conform
     - **Repair:** Accept with approved repair
     - **Scrap:** Reject and dispose
   - Engineering approval (if required)
   - Customer approval (if required)

5. **Root Cause Analysis**
   - 5-Why analysis
   - Fishbone diagram
   - 8D methodology (for significant issues)
   - Failure mode analysis
   - Contributing factor identification

6. **Corrective Action**
   - Immediate correction
   - Corrective action planning
   - Implementation and verification
   - Effectiveness review
   - Documentation closure

7. **Trend Analysis and Prevention**
   - Pareto analysis
   - Trend monitoring
   - Preventive action identification
   - Process improvement initiatives
   - Lessons learned dissemination
