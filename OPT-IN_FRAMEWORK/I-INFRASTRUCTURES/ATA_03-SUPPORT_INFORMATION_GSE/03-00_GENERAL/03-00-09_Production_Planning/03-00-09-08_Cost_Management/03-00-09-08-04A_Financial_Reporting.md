## 1. Purpose

This document establishes the financial reporting requirements for the AMPEL360 BWB-H2-Hy-E aircraft production program, ensuring transparent and timely communication of financial performance.

## 2. Scope

This document covers:
- Financial reporting framework and requirements
- Report types and content
- Reporting frequency and distribution
- Key financial metrics and indicators
- Compliance and audit requirements
- Financial data governance

## 3. Applicable Documents

- **ATA 03:** Support Information/Ground Support Equipment

- **GAAP/IFRS:** Accounting Standards
- **SOX:** Sarbanes-Oxley Act (if applicable)

## 4. Description

### 4.1 Overview

Financial reporting provides structured communication of production program financial performance to management, investors, customers, and other stakeholders. Timely and accurate reporting enables informed decision-making and demonstrates fiscal responsibility.

### 4.2 Requirements

**Financial Reporting Objectives:**
- Transparent financial communication
- Accurate and timely information
- Compliance with accounting standards
- Support for decision-making
- Stakeholder confidence
- Audit trail and documentation

**Report Categories:**
- **Internal Management Reports:** Operational performance, variance analysis
- **Executive Reports:** Summary dashboards, key metrics
- **Customer Reports:** Program status, milestone billing
- **Regulatory Reports:** Compliance filings (if applicable)
- **Audit Reports:** Internal and external audit support

### 4.3 Methodology

**Financial Reporting Framework:**

1. **Reporting Structure**
   - Report hierarchy and relationships
   - Data sources and systems
   - Reporting calendar
   - Distribution lists
   - Access controls

2. **Key Financial Reports**
   
   **A. Cost Performance Report (Monthly)**
   - Budget vs. actual costs
   - Variance analysis
   - Forecast at completion
   - Cost performance index (CPI)
   - Explanation of significant variances

   **B. Program Financial Summary (Monthly)**
   - Revenue recognition
   - Cost of goods sold (COGS)
   - Gross margin
   - Program profitability
   - Cash flow

   **C. Executive Dashboard (Monthly/Quarterly)**
   - Key performance indicators
   - Financial metrics summary
   - Trend graphs and charts
   - Risk indicators
   - Action items

   **D. Milestone Billing Report (Per Milestone)**
   - Milestone achievement
   - Billing amounts
   - Payment status
   - Accounts receivable aging

   **E. Annual Program Review**
   - Year-end financial summary
   - Annual performance vs. plan
   - Lessons learned
   - Next year forecast
   - Strategic recommendations

3. **Financial Metrics**
   - Cost Performance Index (CPI)
   - Schedule Performance Index (SPI)
   - Estimate at Completion (EAC)
   - Variance at Completion (VAC)
   - Gross Margin %
   - Cash Flow
   - Return on Investment (ROI)

4. **Report Preparation**
   - Data collection and validation
   - Analysis and commentary
   - Review and approval workflow
   - Quality assurance checks
   - Distribution

5. **Compliance and Controls**
   - Accounting standard compliance
   - Revenue recognition policies
   - Internal controls
   - Audit trail maintenance
   - Document retention

6. **Continuous Improvement**
   - Report effectiveness surveys
   - Process efficiency improvements
   - Automation opportunities
   - Best practice adoption
