# 03-00-05-04-02A - Hydraulic Fluid Standards

## 1. Purpose
This document specifies the hydraulic fluid standards and requirements for the AMPEL360 BWB H₂ Hy-E aircraft hydraulic systems.

## 2. Scope
This specification covers fluid types, quality requirements, testing procedures, and handling standards for aircraft hydraulic systems.

## 3. Applicable Documents
- ATA iSpec 2200 (Information Standards for Aviation Maintenance)
- MIL-PRF-83282 (Hydraulic Fluid, Fire Resistant, Synthetic Hydrocarbon Base)
- SAE AS1241 (Air Start Units and Accessories)
- ASTM D4172 (Standard Test Method for Wear Preventive Characteristics)
- ISO 4406 (Hydraulic Fluid Power - Fluids - Method for Coding Level of Contamination)

## 4. Interface Description

### 4.1 Overview
The AMPEL360 aircraft uses Type IV fire-resistant synthetic hydrocarbon-based hydraulic fluid (MIL-PRF-83282) across all three hydraulic systems for enhanced safety, particularly critical for hydrogen-fueled aircraft.

### 4.2 Physical Characteristics
| Parameter | Specification | Tolerance |
|-----------|---------------|-----------|
| Fluid Type | MIL-PRF-83282 Type IV | Fire-resistant |
| Viscosity @ 40°C | 13.5-16.5 cSt | ASTM D445 |
| Flash Point | > 110°C | ASTM D92 |
| Pour Point | < -54°C | ASTM D97 |
| Specific Gravity | 0.85-0.95 @ 15°C | ASTM D4052 |
| Color | Purple | Visual identification |
| Cleanliness Code | ISO 4406: 16/14/11 | New fluid standard |
| Cleanliness Code | ISO 4406: 18/16/13 | In-service limit |
| Water Content | < 500 ppm | Karl Fischer method |
| Acid Number | < 0.3 mg KOH/g | ASTM D974 |

### 4.3 Connection Procedure
1. **Pre-Service Fluid Verification**
   - Verify fluid type matches aircraft specification
   - Check fluid batch certification
   - Inspect fluid for proper color (purple)
   - Verify cleanliness code meets ISO 4406: 16/14/11
   - Check expiration date on fluid containers
   - Review fluid analysis reports if available

2. **Fluid Handling Procedure**
   - Use only clean, dedicated hydraulic fluid containers
   - Filter all fluid through 3-micron absolute filter
   - Protect fluid from contamination during transfer
   - Do not mix fluid batches unnecessarily
   - Keep containers sealed when not in use
   - Store in cool, dry location away from sunlight

3. **Fluid Quality Monitoring**
   - Sample fluid every 100 flight hours minimum
   - Test for viscosity, water content, particle count
   - Monitor for color change (indicates oxidation)
   - Check for acidity increase
   - Perform wear metal analysis
   - Document all test results

4. **Fluid Disposal**
   - Never discharge hydraulic fluid to environment
   - Collect in approved waste containers
   - Label containers with contents and date
   - Follow local environmental regulations
   - Use certified waste disposal service
   - Maintain disposal records

## 6. Safety Requirements
- **Fluid Handling Safety**
  - Wear nitrile gloves and safety glasses
  - Avoid prolonged skin contact
  - Use in well-ventilated areas
  - Keep away from ignition sources despite fire resistance
  - Do not ingest or inhale vapors
  - First aid: flush skin/eyes with water for 15 minutes

- **Contamination Control**
  - Maintain strict cleanliness during all operations
  - Use only dedicated equipment for MIL-PRF-83282
  - Never reuse single-use filters
  - Protect all openings from contamination
  - Clean up spills immediately
  - Do not mix with other fluid types

- **Environmental Protection**
  - MIL-PRF-83282 is not biodegradable
  - Prevent discharge to ground or water
  - Use spill containment for all transfers
  - Report spills per environmental procedures
  - Proper disposal through certified handlers
  - Maintain spill response kit nearby

- **H2 Aircraft Specific**
  - Although fire-resistant, keep away from H2 areas
  - No fluid servicing during H2 fueling operations
  - Enhanced ventilation requirements
  - Fire-resistant does not mean fireproof
  - Position fire suppression equipment nearby
