# 03-00-05-04-03A - Pressure Requirements

## 1. Purpose
This document specifies hydraulic pressure requirements for the AMPEL360 BWB H₂ Hy-E aircraft hydraulic systems during ground operations.

## 2. Scope
This specification covers operating pressures, test pressures, and safety requirements for aircraft hydraulic systems.

## 3. Applicable Documents
- ATA iSpec 2200, MIL-PRF-83282, SAE AS1055, ISO 4406, ASME B31.3

## 4. Interface Description

### 4.1 Overview
Three independent hydraulic systems operate at 3000 psi nominal pressure with specific requirements for testing and servicing.

### 4.2 Physical Characteristics
| Parameter | Specification | Tolerance |
|-----------|---------------|-----------|
| Normal Operating Pressure | 3000 psi (207 bar) | ±150 psi |
| System Relief Pressure | 3600 psi (248 bar) | Relief valve setting |
| Test Pressure (Proof) | 4500 psi (310 bar) | 1.5 × operating |
| Low Pressure Warning | 2400 psi (165 bar) | Alert threshold |
| Accumulator Precharge | 1500 psi (103 bar) | Nitrogen gas |

### 4.3 Connection Procedure
Standard pressure verification and monitoring procedures per ATA 29.

## 5. GSE Equipment Requirements
High-pressure hydraulic test equipment, calibrated gauges, safety relief valves.

## 6. Safety Requirements
- Never exceed 4500 psi test pressure
- Depressurize before maintenance
- Use appropriate PPE
- H2 aircraft: enhanced safety protocols
