# 03-00-05-04-04A - Quick Disconnect Fittings

## 1. Purpose
This document specifies quick-disconnect fitting requirements for AMPEL360 BWB H₂ Hy-E aircraft hydraulic system servicing.

## 2. Scope
This specification covers quick-disconnect fitting types, installation, and maintenance procedures for hydraulic GSE connections.

## 3. Applicable Documents
- ATA iSpec 2200, SAE AS1055, MS33656 Standard, ISO 7241 Series

## 4. Interface Description

### 4.1 Overview
Quick-disconnect fittings enable rapid, safe connection/disconnection of hydraulic service equipment.

### 4.2 Physical Characteristics
| Parameter | Specification | Tolerance |
|-----------|---------------|-----------|
| Fitting Type | MS33656-8 (1/2 inch) | JIC compatible |
| Working Pressure | 3000 psi (207 bar) | Rated |
| Material | Stainless steel 316 | Corrosion resistant |
| Seal Type | Buna-N O-ring | MIL-PRF-83282 compatible |

### 4.3 Connection Procedure
Standard connect/disconnect procedures with leak checking and cleanliness verification.

## 5. GSE Equipment Requirements
Compatible quick-disconnect couplers, torque wrenches, inspection tools.

## 6. Safety Requirements
- Verify depressurized before disconnect
- Inspect fittings regularly
- Replace damaged seals immediately
- Maintain cleanliness
