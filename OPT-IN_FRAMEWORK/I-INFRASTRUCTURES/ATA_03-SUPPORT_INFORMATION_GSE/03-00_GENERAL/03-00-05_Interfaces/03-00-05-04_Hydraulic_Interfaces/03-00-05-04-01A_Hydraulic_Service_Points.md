# 03-00-05-04-01A - Hydraulic Service Points

## 1. Purpose
This document specifies the hydraulic service point locations and interface requirements for the AMPEL360 BWB H₂ Hy-E aircraft hydraulic systems.

## 2. Scope
This specification covers hydraulic service point design, access, servicing procedures, and safety requirements for all aircraft hydraulic systems.

## 3. Applicable Documents
- ATA iSpec 2200 (Information Standards for Aviation Maintenance)
- ARP4754A (Guidelines for Development of Civil Aircraft and Systems)
- SAE AS1241 (Air Start Units and Accessories)
- MIL-PRF-83282 (Hydraulic Fluid, Fire Resistant)
- SAE AS1055 (Hydraulic System, Aircraft, Design and Installation)

## 4. Interface Description

### 4.1 Overview
Hydraulic service points provide access for fluid fill, drain, and sampling operations for the aircraft's hydraulic systems. Multiple service points are strategically located for efficient maintenance operations.

### 4.2 Physical Characteristics
| Parameter | Specification | Tolerance |
|-----------|---------------|-----------|
| Service Point Locations | 3 systems: HYD1, HYD2, HYD3 | Per system |
| Connector Type | MS33656-8 (1/2 inch) | Quick-disconnect |
| Access Height | 1.5-2.5m from ground | Varies by location |
| Fill/Drain Flow Rate | 10-15 L/min | Maximum |
| Working Pressure | 3000 psi (207 bar) | Normal operating |
| Port Thread | MS33656-8 (7/8-14 UNF) | JIC standard |
| Protective Cap | Aluminum, tethered | Dust seal |
| Service Panel Size | 300mm x 300mm | Tool-free access |

### 4.3 Connection Procedure
1. **Pre-Service Checks**
   - Verify aircraft hydraulic system depressurized
   - Position drip tray under service point
   - Inspect service point for contamination
   - Check service equipment cleanliness
   - Verify correct hydraulic fluid type (MIL-PRF-83282)
   - Review aircraft maintenance log

2. **Fill Procedure**
   - Remove protective cap from fill port
   - Connect hydraulic service cart quick-disconnect
   - Verify connection secure
   - Fill at controlled rate (10 L/min maximum)
   - Monitor reservoir level indicator
   - Stop at maximum fill level
   - Disconnect service cart
   - Install protective cap

3. **Drain Procedure**
   - Position collection container (approved type)
   - Remove drain port cap
   - Connect drain hose with quick-disconnect
   - Open drain valve slowly
   - Collect fluid for proper disposal
   - Close drain valve when complete
   - Disconnect and cap drain port

4. **Sampling Procedure**
   - Use clean sampling equipment
   - Take sample from designated sample port
   - Fill sample bottle (100ml minimum)
   - Label with date, aircraft ID, system ID
   - Submit for fluid analysis
   - Document sampling in maintenance log

## 6. Safety Requirements
- **Hydraulic Fluid Safety**
  - Wear nitrile gloves and eye protection
  - Avoid skin contact with hydraulic fluid
  - Use only approved MIL-PRF-83282 fluid
  - Never mix different fluid types
  - Clean spills immediately with approved cleaner
  - Dispose of waste fluid per environmental regulations

- **Pressure Safety**
  - Always verify system depressurized before servicing
  - Never disconnect pressurized lines
  - Check for residual pressure before opening connections
  - Use pressure gauges to verify zero pressure
  - Follow lockout/tagout procedures

- **Contamination Control**
  - Keep all equipment scrupulously clean
  - Use only filtered hydraulic fluid
  - Protect open ports from contamination
  - Replace caps immediately after servicing
  - Filter all fluid through 3-micron filter minimum
  - Never reuse drained hydraulic fluid

- **H2 Aircraft Considerations**
  - Hydraulic equipment spark-resistant
  - Position service equipment away from H2 areas
  - No hydraulic servicing during H2 fueling
  - Enhanced fire watch requirements
  - Verify ventilation adequate
