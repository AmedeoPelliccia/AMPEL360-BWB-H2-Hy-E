# 03-00-05-08-01A - Cargo Door Dimensions

## 1. Purpose
Specifies cargo door dimensions and clearances for AMPEL360 BWB H₂ Hy-E aircraft cargo loading operations.

## 2. Scope
Covers cargo door sizes, locations, and operational requirements for freight handling.

## 3. Applicable Documents
- ATA iSpec 2200, IATA AHM Chapter 960, SAE AS36100 (Cargo Systems)

## 4. Interface Description

### 4.1 Overview
BWB design features three main cargo doors with dimensions optimized for standard Unit Load Devices (ULD).

### 4.2 Physical Characteristics
| Parameter | Specification | Tolerance |
|-----------|---------------|-----------|
| Forward Cargo Door | 3.4m (W) x 2.6m (H) | ±50mm |
| Aft Cargo Door | 3.4m (W) x 2.6m (H) | ±50mm |
| Bulk Cargo Door | 1.5m (W) x 1.8m (H) | ±50mm |
| Door Sill Height | 1.8m above ground | ±100mm |
| Door Type | Upward opening, hydraulic | Power-assisted |
| Opening Time | 45 seconds typical | Powered operation |

### 4.3 Connection Procedure
Cargo loader positioning, door opening, ULD loading/unloading, door closing, verification procedures.

## 5. GSE Equipment Requirements
Cargo loader (high-lift platform), ULD transporters, positioning guides, power supply.

## 6. Safety Requirements
- Verify aircraft secured before operations
- Proper loader positioning critical
- Monitor door clearances
- H2 aircraft: enhanced ventilation during cargo ops
