# 03-00-05-08-02A - Cargo Loading Heights

## 1. Purpose
Specifies cargo loading height requirements and GSE specifications for AMPEL360 BWB H₂ Hy-E aircraft cargo operations.

## 2. Scope
Covers cargo compartment floor heights, loader specifications, and vertical clearance requirements.

## 3. Applicable Documents
- ATA iSpec 2200, IATA AHM Chapter 960, SAE AS36100

## 4. Interface Description

### 4.1 Overview
Cargo floor heights and loader specifications ensure efficient, safe cargo handling operations.

### 4.2 Physical Characteristics
| Parameter | Specification | Tolerance |
|-----------|---------------|-----------|
| Forward Cargo Floor Height | 2.0m above ground | ±100mm |
| Aft Cargo Floor Height | 1.9m above ground | ±100mm |
| Bulk Cargo Floor Height | 1.7m above ground | ±100mm |
| Loader Platform Height | Adjustable 1.0-3.0m | Hydraulic |
| Vertical Clearance | 2.8m minimum | In cargo compartment |
| Loading Angle | 0-5 degrees | Platform tilt |

### 4.3 Connection Procedure
Loader positioning, height adjustment, platform leveling, ULD transfer procedures.

## 5. GSE Equipment Requirements
Cargo loader (10-ton capacity), ULD dollies, load distribution system.

## 6. Safety Requirements
- Verify loader height matches door sill
- Proper platform leveling critical
- Monitor clearances continuously
- H2 aircraft: standard cargo procedures
