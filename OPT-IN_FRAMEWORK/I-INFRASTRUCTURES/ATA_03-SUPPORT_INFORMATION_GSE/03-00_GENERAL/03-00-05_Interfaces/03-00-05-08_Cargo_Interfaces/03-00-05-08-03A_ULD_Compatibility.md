# 03-00-05-08-03A - ULD Compatibility

## 1. Purpose
Specifies Unit Load Device (ULD) compatibility requirements for AMPEL360 BWB H₂ Hy-E aircraft cargo system.

## 2. Scope
Covers compatible ULD types, restraint systems, and loading procedures for aircraft cargo compartments.

## 3. Applicable Documents
- ATA iSpec 2200, IATA Unit Load Device Regulations, SAE AS36100

## 4. Interface Description

### 4.1 Overview
Aircraft cargo system accommodates standard IATA ULD types with certified restraint systems.

### 4.2 Physical Characteristics
| Parameter | Specification | Tolerance |
|-----------|---------------|-----------|
| Compatible ULD Types | LD3, LD6, LD11, 96x125 pallets | IATA standard |
| Forward Cargo Capacity | 8x LD3 or 4x LD11 | Main deck |
| Aft Cargo Capacity | 6x LD3 or 3x LD11 | Main deck |
| Bulk Cargo Volume | 15 cubic meters | Loose cargo |
| ULD Restraint System | Ball mat + locks | Automatic |
| Maximum ULD Weight | 1,588 kg (LD3), 3,175 kg (LD11) | Per IATA |

### 4.3 Connection Procedure
ULD positioning, restraint engagement, weight distribution verification, tie-down check procedures.

## 5. GSE Equipment Requirements
ULD transporters, loading system, restraint locks, weight distribution calculator.

## 6. Safety Requirements
- Verify ULD weight within limits
- Proper restraint engagement mandatory
- Check load distribution per loading manual
- H2 aircraft: enhanced tie-down verification
