# 03-00-05-07-01A - Door Sill Heights

## 1. Purpose
Specifies door sill heights and access requirements for AMPEL360 BWB H₂ Hy-E aircraft passenger and service doors.

## 2. Scope
Covers all passenger and service door sill heights, access equipment requirements, and safety procedures.

## 3. Applicable Documents
- ATA iSpec 2200, FAA AC 25-17A (Passenger Door), IATA AHM

## 4. Interface Description

### 4.1 Overview
BWB design features multiple door locations with varying sill heights requiring compatible ground support equipment.

### 4.2 Physical Characteristics
| Parameter | Specification | Tolerance |
|-----------|---------------|-----------|
| Forward Entry (L1/R1) | 4.5m above ground | ±100mm |
| Forward Service (L2/R2) | 3.8m above ground | ±100mm |
| Aft Entry (L3/R3) | 4.2m above ground | ±100mm |
| Aft Service (L4/R4) | 3.5m above ground | ±100mm |
| Emergency Exits | Various, 2.0-4.5m | Per exit type |
| Door Width | 1.07m standard | Passenger doors |

### 4.3 Connection Procedure
Stairs/bridge positioning, height adjustment, secure attachment, and safety verification procedures.

## 5. GSE Equipment Requirements
Passenger stairs (adjustable), boarding bridges, service platforms, chocks.

## 6. Safety Requirements
- Verify aircraft secured before positioning GSE
- Proper height adjustment critical
- Monitor clearances continuously
- H2 aircraft: position upwind when possible
