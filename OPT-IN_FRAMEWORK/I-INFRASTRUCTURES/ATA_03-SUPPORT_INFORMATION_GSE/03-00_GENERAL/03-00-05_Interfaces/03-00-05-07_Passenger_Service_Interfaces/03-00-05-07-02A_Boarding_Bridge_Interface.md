# 03-00-05-07-02A - Boarding Bridge Interface

## 1. Purpose
Specifies boarding bridge interface requirements for AMPEL360 BWB H₂ Hy-E aircraft passenger boarding operations.

## 2. Scope
Covers boarding bridge design, positioning, and operational requirements for terminal gate operations.

## 3. Applicable Documents
- ATA iSpec 2200, IATA AHM Chapter 920, ISO 16100 (Passenger Boarding Bridges)

## 4. Interface Description

### 4.1 Overview
Fixed and mobile boarding bridges provide weather-protected passenger access to aircraft at terminal gates.

### 4.2 Physical Characteristics
| Parameter | Specification | Tolerance |
|-----------|---------------|-----------|
| Bridge Type | Apron drive bridge (ADB) | Height-adjustable |
| Height Range | 2.0m to 6.0m | Covers all door heights |
| Bridge Width | 3.0m internal | Passenger walkway |
| Approach Angle | ±15 degrees | From perpendicular |
| Door Contact Pressure | < 100 N | Soft docking |
| Bridge Extension | 15-40m | From terminal |

### 4.3 Connection Procedure
Bridge positioning, height/angle adjustment, soft docking, seal verification procedures.

## 5. GSE Equipment Requirements
Passenger boarding bridge (PBB), operator console, intercom, visual aids.

## 6. Safety Requirements
- Verify aircraft parked and secured
- Gradual approach to door
- Monitor clearances continuously
- H2 aircraft: verify ventilation adequate
