# 03-00-05-07-03A - Catering Door Interface

## 1. Purpose
Specifies catering door interface requirements for AMPEL360 BWB H₂ Hy-E aircraft galley servicing operations.

## 2. Scope
Covers catering door access, equipment requirements, and loading procedures for galley provisioning.

## 3. Applicable Documents
- ATA iSpec 2200, IATA AHM Chapter 940, ATLAS Standard (Airline Technical Logistics)

## 4. Interface Description

### 4.1 Overview
Four catering doors provide access to forward and aft galley areas for meal service provisioning.

### 4.2 Physical Characteristics
| Parameter | Specification | Tolerance |
|-----------|---------------|-----------|
| Door Locations | 2 forward, 2 aft | Port and starboard |
| Door Opening Size | 1.68m x 1.63m | ATLAS standard |
| Sill Height | 3.2m above ground | ±100mm |
| Cart Track Width | 0.52m | Standard airline cart |
| Door Type | Outward opening, hydraulic | Power-assisted |
| Load Capacity | 1000 kg per cart track | Maximum |

### 4.3 Connection Procedure
Catering truck positioning, height adjustment, door opening, cart loading/unloading procedures.

## 5. GSE Equipment Requirements
Catering truck (high-loader), food service carts, positioning guides, chocks.

## 6. Safety Requirements
- Verify aircraft secured and powered
- Proper truck positioning critical
- Load distribution within limits
- H2 aircraft: no hot food equipment during H2 ops
