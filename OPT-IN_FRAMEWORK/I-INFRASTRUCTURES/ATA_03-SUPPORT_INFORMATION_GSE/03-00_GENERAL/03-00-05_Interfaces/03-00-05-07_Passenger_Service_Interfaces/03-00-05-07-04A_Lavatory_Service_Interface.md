# 03-00-05-07-04A - Lavatory Service Interface

## 1. Purpose
Specifies lavatory service interface requirements for AMPEL360 BWB H₂ Hy-E aircraft waste system servicing.

## 2. Scope
Covers lavatory service panel access, connections, and procedures for waste tank servicing and water replenishment.

## 3. Applicable Documents
- ATA iSpec 2200, IATA AHM Chapter 950, EPA Regulations (Aircraft Waste)

## 4. Interface Description

### 4.1 Overview
Integrated lavatory service panel provides waste drain and potable water fill connections for aircraft sanitation systems.

### 4.2 Physical Characteristics
| Parameter | Specification | Tolerance |
|-----------|---------------|-----------|
| Service Panel Location | Aft fuselage, starboard side | FS 550 |
| Access Height | 1.5m from ground | ±200mm |
| Waste Drain Connection | 3-inch quick-disconnect | Sealed |
| Water Fill Connection | 1-inch quick-disconnect | Potable water rated |
| Panel Door Size | 400mm x 600mm | Hinged, lockable |
| Waste Tank Capacity | 200 liters | Total |
| Water Tank Capacity | 250 liters | Potable water |

### 4.3 Connection Procedure
Service truck positioning, panel opening, waste drain, system flush, water fill, leak check procedures.

## 5. GSE Equipment Requirements
Lavatory service truck, waste tank (300L), water tank (300L), hoses, sanitizer.

## 6. Safety Requirements
- Wear appropriate PPE (gloves, eye protection)
- Proper waste disposal procedures
- Use only potable water for fill
- H2 aircraft: standard servicing, no special requirements
