# 03-00-07-02-04A — H₂ Leak Detection Tests

## 1. Purpose

This document defines leak detection test procedures for hydrogen GSE systems, verifying system integrity and leak rates meet safety requirements.

## 2. Scope

Testing includes helium leak testing (< 1×10⁻⁶ mbar·L/s), pressure decay testing, bubble testing for connections, mass spectrometer leak detection, and operational leak verification.
