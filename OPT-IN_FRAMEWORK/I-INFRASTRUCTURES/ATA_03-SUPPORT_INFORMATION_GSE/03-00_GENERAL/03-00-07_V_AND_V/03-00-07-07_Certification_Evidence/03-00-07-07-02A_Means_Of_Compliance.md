# 03-00-07-07-02A - Means of Compliance

## 1. Purpose

This document defines the **Means of Compliance (MoC)** for demonstrating conformity of [ATA Chapter 03](https://www.ata.org/resources/specifications) GSE systems with certification requirements.

## 2. Scope

Means of compliance methods include:
- Test (laboratory and field)
- Analysis (calculation and simulation)
- Inspection (examination and review)
- Demonstration (operational showing)
- Similarity (comparison to certified designs)

## 3. Applicable Documents

| Document | Application |
|----------|-------------|
| [EASA AMC/GM](https://www.easa.europa.eu/) | Acceptable means of compliance |
| [FAA AC](https://www.faa.gov/) | Advisory circulars |

## 4. Description

Means of compliance identify specific methods by which each certification requirement is demonstrated to be satisfied.

## 5. Test/Verification Matrix

| Requirement Type | Primary MoC | Supporting MoC | Rationale |
|-----------------|------------|---------------|-----------|
| Safety-critical functions | Test | Analysis | Objective verification required |
| Interface compatibility | Inspection | Demonstration | Visual/physical verification |
| Performance parameters | Test | - | Measurement required |
| Documentation | Inspection | - | Review adequate |

## 6. Acceptance Criteria

- ✓ All requirements have assigned means of compliance
- ✓ Methods agreed with certification authority
- ✓ Supporting rationale documented
- ✓ Evidence plan defined
