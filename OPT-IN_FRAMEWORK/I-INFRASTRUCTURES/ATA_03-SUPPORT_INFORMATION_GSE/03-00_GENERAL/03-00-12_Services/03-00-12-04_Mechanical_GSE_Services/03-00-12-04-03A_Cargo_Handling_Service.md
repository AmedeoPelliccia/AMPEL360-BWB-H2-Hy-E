# 03-00-12-04-03A - Cargo Handling Service

## 1. Purpose
This document specifies cargo loading and unloading services for AMPEL360 BWB aircraft, including procedures, equipment, and safety requirements for efficient and safe cargo operations.

## 2. Scope
This service specification covers:
- Cargo loading and unloading operations
- Cargo loading equipment operation
- Load planning and weight distribution
- Containerized and bulk cargo handling
- Cargo documentation and tracking

- ATA iSpec 2200 (Information Standards for Aviation Maintenance)
- IATA Airport Handling Manual (AHM)
- IATA Dangerous Goods Regulations (DGR)
- ATA 50 (Cargo and Accessory Compartments)
- Aircraft Loading Instructions

## 4. Service Description

### 4.1 Overview
Cargo Handling Service provides efficient and safe loading/unloading of cargo for AMPEL360 aircraft, utilizing the BWB configuration's unique cargo volume and multiple loading doors.

### 4.2 Service Specifications
| Parameter | Specification | SLA Target |
|-----------|---------------|------------|
| Cargo Loading Rate | 2-4 tons per hour | Dependent on cargo type |
| Maximum Single Item Weight | Up to 5,000 lbs | Per aircraft limitations |
| Cargo Door Access | Multiple points | BWB configuration advantages |
| Loading Equipment | Conveyor belts, loaders, forklifts | Type-specific equipment |
| Load Planning Accuracy | 100% | Weight and balance compliance |
| Dangerous Goods Handling | IATA DGR compliant | Specialized procedures |
| Loading Time (Standard) | 45-90 minutes | Dependent on cargo volume |

### 4.3 Service Delivery Process
1. **Pre-Loading**: Cargo documentation review, load plan preparation, aircraft configuration check
2. **Equipment Positioning**: Cargo loaders, conveyors, and support equipment positioning
3. **Weight Verification**: Individual cargo items weighed and documented
4. **Loading Sequence**: Systematic loading per load plan, securing cargo in position
5. **Weight & Balance**: Real-time load sheet updates, CG verification
6. **Final Inspection**: Cargo securement verification, door closure checks
7. **Documentation**: Load sheet finalization, cargo manifest completion

## 6. Safety Requirements
- All cargo must be properly secured per aircraft loading manual
- Dangerous goods handling requires specialized training and procedures
- Maximum loading speeds enforced to prevent cargo/aircraft damage
- Personnel must maintain clear of pinch points during loading operations
- Cargo loaders must be properly positioned and secured before operation
- Weight and balance limits must be strictly observed
- Fire extinguishers and spill kits readily available during cargo operations
- Personal protective equipment (PPE) mandatory for all cargo handlers
