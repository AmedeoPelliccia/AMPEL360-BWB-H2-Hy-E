# 03-00-06-06-02A - FMEA/FMECA

## 1. Purpose
Define the methodology for conducting Failure Modes and Effects Analysis (FMEA) and Failure Modes, Effects, and Criticality Analysis (FMECA) for the AMPEL360 BWB-H2-Hy-E aircraft systems, systematically identifying potential failure modes and their impacts to support design improvements and safety assessments.

## 2. Scope
This document covers:
- FMEA/FMECA methodology and procedures
- Failure mode identification
- Effects analysis and severity assessment
- Criticality analysis and ranking
- Detection methods and design controls
- Mitigation recommendations
- Integration with safety assessment process

## 4. Description

### 4.1 Overview
FMEA/FMECA is a bottom-up analysis method that examines how individual component failures affect system and aircraft-level functions. For the BWB-H2-Hy-E, FMEA/FMECA identifies critical failure modes in hydrogen systems, electric propulsion, and novel BWB structural elements.

### 4.2 Requirements
**FMEA/FMECA Objectives:**
- Identify all reasonably foreseeable failure modes
- Determine effects of each failure mode on system and aircraft
- Assess severity and likelihood of each failure effect
- Identify detection methods and current design controls
- Recommend design improvements or mitigations
- Support quantitative safety assessment (failure rates)

**FMEA vs. FMECA:**
- **FMEA:** Qualitative analysis of failure modes and effects
- **FMECA:** Adds quantitative criticality analysis (failure rate × severity)

**Severity Ratings (per MIL-STD-1629A):**
- **Category I - Catastrophic:** Could cause death or system loss
- **Category II - Critical:** Could cause severe injury or major system damage
- **Category III - Marginal:** Could cause minor injury or minor system damage
- **Category IV - Minor:** Will not result in injury or significant system damage

**Likelihood/Probability Levels:**
- **Level A - Frequent:** Likely to occur frequently (>10^-3 per flight hour)
- **Level B - Probable:** Will occur several times (10^-3 to 10^-5)
- **Level C - Occasional:** Likely to occur sometime (10^-5 to 10^-7)
- **Level D - Remote:** Unlikely but possible (10^-7 to 10^-9)
- **Level E - Extremely Remote:** Extremely unlikely (<10^-9)

### 4.3 Methodology
**FMEA/FMECA Process:**

1. **Define System and Boundaries**
   - Identify system under analysis
   - Define interfaces and dependencies
   - Establish analysis level (component, subsystem, system)

2. **Identify Functions**
   - List all functions the system performs
   - Define performance requirements

3. **Identify Failure Modes**
   - Determine how each component can fail
   - Common failure modes: short, open, stuck, leakage, rupture, degraded output

4. **Analyze Effects (Local, Next Level, End Effects)**
   - **Local Effect:** Impact on the component itself
   - **Next Level Effect:** Impact on the subsystem
   - **End Effect:** Impact on aircraft-level function and safety

5. **Assess Severity**
   - Classify per Category I-IV (or Minor/Major/Hazardous/Catastrophic)

6. **Determine Detection Methods**
   - How is the failure detected? (BIT, crew observation, inspection)
   - Probability of detection

7. **Identify Current Controls**
   - Design features that prevent or mitigate failure
   - Redundancy, monitoring, fail-safe design

8. **Calculate Criticality (for FMECA)**
   - Criticality Number = Failure Rate × Severity × Mode Ratio
   - Rank failure modes by criticality

9. **Recommend Actions**
   - Design changes to eliminate or reduce failure likelihood
   - Improved detection or mitigation
   - Maintenance actions

**FMEA Table Format:**
| Item | Function | Failure Mode | Cause | Local Effect | Next Level Effect | End Effect | Severity | Detection | Current Controls | Recommendations |
|------|----------|--------------|-------|--------------|-------------------|------------|----------|-----------|------------------|-----------------|
| H2 Tank | Store LH2 | External rupture | Impact damage | LH2 released | H2 leak in fuselage | Fire/explosion | Catastrophic | Leak detector | Impact-resistant design, multiple tanks | Add secondary containment |

## 6. Verification & Validation
**Acceptance Criteria:**
- FMEA conducted for all critical systems
- All failure modes identified and analyzed
- Severity and likelihood assessed for each mode
- High-criticality failure modes have mitigations identified
- FMEA integrated with FHA and SSA
- Design improvements implemented or justified

**Verification Methods:**
- Peer review of FMEA worksheets
- Cross-check with hazard analysis
- Validation through testing (failure injection)
- Independent safety audit
