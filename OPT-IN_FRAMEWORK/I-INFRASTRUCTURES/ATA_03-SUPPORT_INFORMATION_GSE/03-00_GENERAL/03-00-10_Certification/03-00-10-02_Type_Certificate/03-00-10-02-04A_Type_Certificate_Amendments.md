# 03-00-10-02-04A - Type Certificate Amendments

## 1. Purpose

This document defines the process for **type certificate amendments** related to ATA Chapter 03 — Support Information and Ground Support Equipment (GSE) following initial certification.

## 2. Scope

This process applies to:

- Design changes to certified GSE
- Addition of new GSE models or variants
- Changes to operating limitations
- Interface modifications
- Documentation updates requiring certification

## 3. Applicable Documents

- **[EASA Part 21 Subpart D](https://www.easa.europa.eu/document-library/regulations/easa-part-21)** — Changes to Type Certificates
- **[FAA Part 21 Subpart D](https://www.ecfr.gov/current/title-14/chapter-I/subchapter-C/part-21/subpart-D)** — Changes to Type Certificates
- [03-00-10-02-03A_Type_Certificate_Data_Sheet](./03-00-10-02-03A_Type_Certificate_Data_Sheet.md)

## 4. Description

### 4.1 Overview

Type certificate amendments allow modifications to the certified type design. The amendment process depends on the classification of the change (minor, major, or special).

### 4.2 Regulatory Requirements

#### Change Classifications

- **Minor Change**: No appreciable effect on safety (DOA approval)
- **Major Change**: Appreciable effect on safety (authority approval required)
- **Special Change**: Requires special conditions or ELOS findings

### 4.3 Compliance Approach

Amendment process includes:
1. Change classification
2. Compliance determination
3. Design approval
4. TCDS update
5. Configuration control
