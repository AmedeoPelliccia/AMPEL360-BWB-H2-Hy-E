# 03-00-10-02-03A - Type Certificate Data Sheet

## 1. Purpose

This document defines the **Type Certificate Data Sheet (TCDS)** content for ATA Chapter 03 — Support Information and Ground Support Equipment (GSE).

## 2. Scope

The TCDS defines approved configuration and limitations for:

- Hydrogen refuelling systems
- Electrical ground power units
- Maintenance platforms and access equipment
- Ground handling equipment
- Support information systems

## 3. Applicable Documents

- **[EASA Part 21](https://www.easa.europa.eu/document-library/regulations/easa-part-21)** — Certification Procedures
- **[FAA Order 8110.4C](https://www.faa.gov/regulations_policies/orders_notices/)** — Type Certification
- [03-00-10-02-02A_Type_Design_Definition](./03-00-10-02-02A_Type_Design_Definition.md)

## 4. Description

### 4.1 Overview

The TCDS is the official record of the type certificate, containing essential design information, operating limitations, and certification requirements.

### 4.2 Regulatory Requirements

TCDS must include:
- Type certificate number
- Model designation
- Type design definition
- Operating limitations
- Certification basis
- Notes and special conditions

### 4.3 Compliance Approach

TCDS compliance demonstrated through:
- Approved type design
- Verified operating limitations
- Authority-approved documentation
