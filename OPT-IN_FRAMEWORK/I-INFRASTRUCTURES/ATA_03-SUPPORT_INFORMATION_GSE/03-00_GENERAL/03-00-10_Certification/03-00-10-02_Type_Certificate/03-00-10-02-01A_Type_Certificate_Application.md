# 03-00-10-02-01A - Type Certificate Application

## 1. Purpose

This document describes the **type certificate application** process for ATA Chapter 03 — Support Information and Ground Support Equipment (GSE) as part of the overall AMPEL360 BWB H₂ Hy-E aircraft type certification.

## 2. Scope

The type certificate application encompasses:

- Ground Support Equipment certification requirements
- Support information systems and documentation
- Interface requirements with aircraft systems
- Hydrogen-specific ground handling equipment
- Digital integration and data systems

## 3. Applicable Documents

- **[EASA Part 21](https://www.easa.europa.eu/document-library/regulations/easa-part-21)** — Certification Procedures for Aircraft
- **[FAA Order 8110.4C](https://www.faa.gov/regulations_policies/orders_notices/)** — Type Certification Process
- [03-00-10-01-02A_Certification_Basis](../03-00-10-01_Certification_Planning/03-00-10-01-02A_Certification_Basis.md)
- [03-00-10-02-02A_Type_Design_Definition](./03-00-10-02-02A_Type_Design_Definition.md)

## 4. Description

### 4.1 Overview

The type certificate application formally initiates the certification process with EASA and FAA for GSE systems supporting the AMPEL360 aircraft. The application includes definition of the type design, certification basis, and compliance demonstration approach.

### 4.2 Regulatory Requirements

#### 4.2.1 EASA Requirements (Part 21 Subpart B)

- Application for type certificate
- Description of the type design
- Proposed certification basis
- Compliance demonstration plan
- Design organisation approval (DOA) reference

#### 4.2.2 FAA Requirements

- Type certificate application (FAA Form 8110-12)
- Three-view drawing
- Preliminary type design definition
- Certification basis and special conditions
- Compliance checklist

### 4.3 Compliance Approach

The type certificate application demonstrates compliance through:

1. **Design Definition**: Complete description of GSE type design
2. **Certification Basis**: Applicable regulations and special conditions
3. **Compliance Plan**: Methods for demonstrating compliance
4. **Supporting Data**: Technical data and analysis supporting the application
