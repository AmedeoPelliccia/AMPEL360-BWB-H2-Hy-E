# 03-00-10-02-02A - Type Design Definition

## 1. Purpose

This document provides the **type design definition** for ATA Chapter 03 — Support Information and Ground Support Equipment (GSE) supporting the AMPEL360 BWB H₂ Hy-E aircraft.

## 2. Scope

The type design definition encompasses:

- Hydrogen refuelling equipment design
- Electrical ground power systems
- Maintenance access and servicing equipment
- Ground handling and towing equipment
- Support information systems and digital integration

- **[EASA Part 21](https://www.easa.europa.eu/document-library/regulations/easa-part-21)** — Certification Procedures

## 4. Description

### 4.1 Overview

The type design defines the configuration and characteristics of GSE systems that support the AMPEL360 aircraft. This includes physical design, functional specifications, interface definitions, and operational parameters.

### 4.2 Regulatory Requirements

Type design must include:
- Design drawings and specifications
- Material specifications
- Dimensions and weights
- Performance characteristics
- Operating limitations
- Interface requirements

### 4.3 Compliance Approach

Type design compliance is demonstrated through:
- Design data package
- Interface control documents
- Material and process specifications
- Performance test data
