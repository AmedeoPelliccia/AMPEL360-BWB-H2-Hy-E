# 03-50-07-01A - Visual Inspection

## 1. Purpose
Specification for visual inspection procedures for Ground Support Equipment (GSE) structures to detect damage, corrosion, deformation, and other structural anomalies.

## 2. Scope
- Visual inspection methods and procedures
- Inspection frequency and intervals
- Defect identification and classification
- Reporting and documentation
- Inspector qualifications

## 3. Applicable Documents
- ASME BPVC Section V Article 9 (Visual Examination)
- AWS D1.1 Section 6 (Inspection)
- ISO 17637 (Visual Testing of Fusion-Welded Joints)
- OSHA 1910 (Inspection Requirements for Powered Industrial Trucks)
- API 510 (Pressure Vessel Inspection Code)

## 4. Structural Description

### 4.1 Inspection Types
| Type | Frequency | Scope | Inspector |
|------|-----------|-------|-----------|
| Pre-Use Check | Daily (before operation) | Critical components, safety devices | Operator |
| Routine Inspection | Weekly/Monthly | General condition, visible damage | Technician |
| Periodic Inspection | Annual | Comprehensive structural evaluation | Certified Inspector |
| Post-Incident Inspection | After event | Damage assessment | Certified Inspector |
| In-Service Inspection | Per schedule (3-5 years) | Detailed examination, NDT | Certified Inspector + NDT Level II |

### 4.2 Critical Inspection Areas
| Component | Defects to Detect | Acceptance Criteria |
|-----------|------------------|---------------------|
| Welds | Cracks, incomplete penetration, undercut | Per AWS D1.1 |
| Structural Members | Cracks, corrosion, deformation | No visible cracks; corrosion < allowance |
| Fasteners | Missing, loose, corroded | All present, torqued, no excessive corrosion |
| Coatings | Peeling, blistering, damage | < 5% area damage |
| Load-Bearing Surfaces | Wear, galling, deformation | Within tolerance, no cracks |
| H2 Components | Cracks, corrosion (embrittlement) | No defects, special attention |

### 4.3 Visual Inspection Tools
- **Unaided Eye**: General inspection, large defects
- **Magnifying Glass (5-10×)**: Small cracks, weld details
- **Borescope/Endoscope**: Internal surfaces, confined spaces
- **Mirror**: Inaccessible areas
- **Flashlight/Spotlight**: Illuminate inspection area
- **Measuring Tools**: Calipers, rulers, pit gauges

### 4.4 Common Defects
| Defect | Appearance | Severity |
|--------|-----------|----------|
| Crack | Linear discontinuity, may be tight or open | Critical - reject |
| Corrosion (general) | Surface rust, pitting | Monitor - assess depth |
| Corrosion (localized) | Deep pits, crevices | Critical if > corrosion allowance |
| Deformation (permanent) | Bent, buckled, dented | Assess against limits |
| Weld Defects | Undercut, porosity, incomplete fusion | Per AWS acceptance |
| Loose Fasteners | Visible gap, rotation | Re-torque, inspect threads |

### 4.5 Defect Classification
| Class | Description | Action |
|-------|-------------|--------|
| Class 1 - Critical | Cracks, severe corrosion, structural damage | Immediate removal from service |
| Class 2 - Major | Significant defects, approaching limits | Repair before next use |
| Class 3 - Minor | Small defects, within tolerance | Monitor, repair at convenience |
| Class 4 - Observation | Noted but acceptable | Document, re-inspect next cycle |

## 5. Structural Requirements

### 5.1 Inspection Procedure
1. **Preparation**: Clean area, ensure adequate lighting, access
2. **Examination**: Systematic scan, focus on critical areas
3. **Measurement**: Quantify defects (length, depth, width)
4. **Documentation**: Record findings, take photos
5. **Evaluation**: Compare to acceptance criteria
6. **Reporting**: Complete inspection report
7. **Disposition**: Accept, monitor, repair, or reject

### 5.2 Acceptance Criteria (Structural Steel)
| Parameter | Limit | Notes |
|-----------|-------|-------|
| Crack Length | 0 mm (no cracks acceptable) | Any crack is reject condition |
| Corrosion Depth (general) | < corrosion allowance (3 mm typical) | Beyond allowance requires engineering eval |
| Pit Depth (localized) | < 2× corrosion allowance | Stress concentration concern |
| Permanent Deformation | < 5% of original dimension | Or engineering evaluation |
| Weld Undercut | < 1 mm depth, < 50 mm length | AWS D1.1 Table 6.1 |

### 5.3 H2 System Inspection
- **Special Attention**: Cracks near H2 exposure (embrittlement risk)
- **Leak Check**: Bubble test or sniffer on joints
- **Coating Integrity**: No damage to prevent corrosion under insulation
- **Fasteners**: Check for hydrogen embrittlement signs (sudden failure)

### 5.4 Inspector Qualifications
| Level | Qualification | Scope |
|-------|--------------|-------|
| Operator | Training + experience | Pre-use checks, obvious defects |
| Technician | Certified technician + 2 years experience | Routine inspections, minor defect assessment |
| Certified Inspector | ASNT Level II VT or equivalent | Periodic/comprehensive inspections |
| Engineer | P.E. or equivalent | Fitness-for-service evaluation, acceptance decisions |

### 5.5 Documentation
- **Inspection Report**: Date, inspector, equipment ID, findings
- **Photographs**: Document defects, overall condition
- **Defect Log**: Track defects over time (trending)
- **Corrective Actions**: Repairs performed, re-inspection date
- **Certification**: Sign-off by qualified inspector
