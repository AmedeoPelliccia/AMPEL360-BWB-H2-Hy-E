# 03-90-05-02A - H2 Transfer Process Flow Diagram

## 1. Purpose

Define process flow for hydrogen transfer operations between GSE storage systems, including LH2 tanker delivery and inter-tank transfers.

## 2. Scope

H2 transfer operations: tanker truck offloading, storage tank filling, inter-tank transfers, and associated safety systems.

## 3. Applicable Documents

- [NFPA 2](https://www.nfpa.org/) - Hydrogen Technologies Code
- [CGA P-12](https://www.cganet.com/) - Safe Handling of Cryogenic Liquids
- [DOT 49 CFR 173](https://www.ecfr.gov/) - Shippers - General Requirements for Shipments and Packagings

## 4. Documentation Description

### 4.1 Overview

Transfer PFD documents procedures for receiving LH2deliveries and redistributing between storage systems.

### 4.2 Content Requirements

#### 4.2.1 Tanker Truck Offloading

**Pre-Offload Checks:**
- Tanker positioned, brakes set, wheels chocked
- Bonding cable connected
- Transfer hose inspected and connected
- Receiver tank capacity verified
- All safety systems operational

**Offloading Sequence:**
1. Connect transfer hose (vacuum-insulated)
2. Cooldown hose and piping
3. Commence LH2 transfer (pump or pressure differential)
4. Monitor flow rate, pressures, levels
5. Complete transfer when target reached
6. Disconnect and secure

#### 4.2.2 Inter-Tank Transfer

Transfer between on-site LH2 storage tanks for balancing inventory or maintenance purposes.
