# 03-90-05-03A - Aircraft Turnaround Process Flow

## 1. Purpose

Define the complete aircraft turnaround process flow involving GSE operations, from arrival to departure, with emphasis on hydrogen fueling integration.

## 2. Scope

Turnaround process: aircraft arrival, passenger deplaning, servicing (including H2 fueling), cabin preparation, boarding, and departure.

## 3. Applicable Documents

- [ATA iSpec 2200](https://www.ata.org/resources/specifications) - Information Standards
- [IATA Ground Operations Manual (IGOM)](https://www.iata.org/) - Ground Handling Standards

## 4. Documentation Description

### 4.1 Overview

Turnaround PFD shows the coordinated sequence of GSE operations to prepare aircraft for next flight, with H2 fueling as a critical path activity.

### 4.2 Content Requirements

#### 4.2.1 Turnaround Timeline

**Typical 45-Minute Turnaround:**

| Time (min) | Activity | GSE Involved |
|------------|----------|--------------|
| 0 | Aircraft arrival, parking | Marshaller, chocks, GPU |
| 0-5 | Passenger deplaning | Jetway/stairs |
| 0-40 | LH2 fueling | Fueling truck/cart |
| 5-40 | Cargo/baggage offload/load | Belt loaders, tugs |
| 5-40 | Cabin cleaning | Cabin service cart |
| 5-40 | Potable water/lavatory service | Service trucks |
| 40-45 | Passenger boarding | Jetway/stairs |
| 45 | Aircraft departure | Pushback tug |

**Critical Path:** LH2 fueling (longest duration activity)

#### 4.2.2 GSE Coordination

Multiple GSE units must coordinate to avoid conflicts, maintain safety zones, and optimize turnaround time.
