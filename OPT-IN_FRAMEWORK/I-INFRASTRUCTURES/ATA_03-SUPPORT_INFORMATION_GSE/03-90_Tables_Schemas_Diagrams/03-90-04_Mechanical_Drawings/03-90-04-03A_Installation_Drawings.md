# 03-90-04-03A - Installation Drawings

## 1. Purpose

Establish standards for installation drawings showing the physical installation of hydrogen GSE equipment in its operational location.

## 2. Scope

Installation drawings for: foundation layouts, equipment placement, piping routing, clearance zones, access requirements, and site-specific installation details.

## 3. Applicable Documents

- [ACI 318](https://www.concrete.org/) - Building Code Requirements for Structural Concrete
- [AISC 360](https://www.aisc.org/) - Specification for Structural Steel Buildings
- Site-specific codes and standards

## 4. Documentation Description

### 4.1 Overview

Installation drawings provide information for site preparation, equipment placement, and installation activities ensuring proper fit and function.

### 4.2 Format and Structure

| Element | Format | Standard |
|---------|--------|----------|
| Site Plans | Scale drawings | 1:100 or 1:200 typical |
| Elevations | Side views showing heights | Critical dimensions |
| Foundation Details | Concrete pad specifications | ACI 318 |
| Anchor Bolt Plans | Bolt patterns and embedment | Structural calc reference |

### 4.3 Content Requirements

#### 4.3.1 Site Layout

- Equipment locations with coordinates
- Clearance zones (operational, maintenance, safety)
- Access routes (vehicle, personnel)
- Utilities (power, water, drains)
- Safety zones (H2 hazardous areas)

#### 4.3.2 Foundation Requirements

- Concrete pad dimensions and thickness
- Reinforcement details
- Anchor bolt locations and embedment depth
- Grounding electrode connections
- Drainage provisions

#### 4.3.3 Equipment Installation

- Lift points and rigging requirements
- Leveling requirements and methods
- Bolt torque specifications
- Grouting procedures (if applicable)
- Alignment tolerances
