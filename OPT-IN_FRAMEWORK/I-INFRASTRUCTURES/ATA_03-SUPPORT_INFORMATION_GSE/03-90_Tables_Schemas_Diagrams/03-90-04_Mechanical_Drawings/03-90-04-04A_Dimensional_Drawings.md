# 03-90-04-04A - Dimensional Drawings

## 1. Purpose

Define standards for dimensional drawings showing overall dimensions and envelope sizes of hydrogen GSE equipment for planning and layout purposes.

## 2. Scope

Dimensional drawings for: equipment envelopes, transportation clearances, maintenance access dimensions, and interface dimensions.

## 3. Applicable Documents

- [ISO 5457](https://www.iso.org/standard/11588.html) - Technical Product Documentation - Sizes and Layout of Drawing Sheets
- [ASME Y14.5](https://www.asme.org/codes-standards/find-codes-standards/y14-5-dimensioning-tolerancing) - Dimensioning and Tolerancing

## 4. Documentation Description

### 4.1 Overview

Dimensional drawings provide overall dimensions without internal details, used for space planning, transportation, and general arrangement.

### 4.2 Format and Structure

| Element | Format | Standard |
|---------|--------|----------|
| Overall Dimensions | Height, Width, Length | Primary dimensions highlighted |
| Envelope | Maximum extents | Including projections |
| Center of Gravity | Marked on drawing | For lifting and stability |
| Weight | Operating and empty weight | On title block or note |

### 4.3 Content Requirements

#### 4.3.1 Equipment Envelope

- Overall dimensions (H × W × L)
- Projections (valves, instruments, handles)
- Clearance required for operation
- Clearance required for maintenance

#### 4.3.2 Transportation Dimensions

- Shipping dimensions (may include crating)
- Shipping weight
- Center of gravity location
- Lift point locations
- Special handling requirements

#### 4.3.3 Interface Dimensions

- Connection point locations (piping, electrical)
- Mounting hole patterns
- Access door dimensions
- Platform or ladder requirements
