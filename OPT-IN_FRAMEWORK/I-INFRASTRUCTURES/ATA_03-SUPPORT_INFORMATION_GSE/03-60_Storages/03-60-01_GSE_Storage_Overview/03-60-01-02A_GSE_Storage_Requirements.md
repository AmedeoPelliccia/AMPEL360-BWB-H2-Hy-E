# 03-60-01-02A - GSE Storage Requirements

## 1. Purpose
This document defines the technical and operational requirements for GSE storage facilities supporting H2-hybrid aircraft operations, ensuring safe, efficient, and compliant storage of all ground support equipment.

## 2. Scope
This document covers:
- Technical specifications for storage facilities
- Environmental control requirements
- Structural and civil engineering requirements
- Utility and service requirements
- Operational performance criteria

## 4. Storage Description

### 4.1 Overview
GSE storage requirements encompass all technical, operational, and safety specifications necessary for the design, construction, and operation of storage facilities. Requirements are categorized by storage type and hazard classification.

### 4.3 Capacity and Requirements

#### Dimensional Requirements by Storage Type

**Indoor GSE Storage**
- Clear span: 30m minimum
- Bay spacing: 10m
- Door height: 5m minimum
- Column spacing: 20m grid

**Outdoor GSE Storage**
- Hardstand area: Minimum 5,000 m²
- Drainage: 1% slope minimum
- Pavement: Reinforced concrete, 300mm depth
- Perimeter fencing: 2.5m height, security-rated

**Climate-Controlled Storage**
- Insulation: R-30 minimum
- HVAC capacity: 100 W/m² cooling, 80 W/m² heating
- Backup power: 24-hour UPS for critical systems

**Hazmat Storage (H2/Cryogenic)**
- Separation distance: 15m from occupied buildings
- Containment: Secondary containment for all liquids
- Ventilation: Natural + mechanical redundancy
- Detection: Triple-redundant gas detection
